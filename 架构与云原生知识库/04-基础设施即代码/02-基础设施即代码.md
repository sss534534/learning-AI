## 1. IaC核心概念

### 1.1 不可变基础设施

传统（可变）→ 手动修复，配置漂移

IaC（不可变）→ 出问题直接重建，绝不手动修改

### 1.2 资源编排

资源定义 → 计划(plan) → 应用(apply) → 状态(state)

## 2. Terraform

### 2.1 示例

```hcl
provider "aws" {
  region = "cn-northwest-1"
}

resource "aws_vpc" "main" {
  cidr_block = "10.0.0.0/16"

  tags = {
    Name = "main-vpc"
  }
}

resource "aws_eks_cluster" "main" {
  name     = "main-cluster"
  role_arn = aws_iam_role.eks.arn

  vpc_config {
    subnet_ids = aws_subnet.private[*].id
  }
}

output "cluster_endpoint" {
  value = aws_eks_cluster.main.endpoint
}
```

### 2.2 模块化

```hcl
module "vpc" {
  source = "terraform-aws-modules/vpc/aws"
  version = "5.0.0"

  name = "my-vpc"
  cidr = "10.0.0.0/16"
  azs  = ["cn-northwest-1a", "cn-northwest-1b"]
}
```

## 3. Pulumi

使用通用编程语言定义基础设施：

```python
import pulumi
import pulumi_aws as aws

# AWS VPC
vpc = aws.ec2.Vpc("main",
    cidr_block="10.0.0.0/16",
    tags={"Name": "main-vpc"}
)

# EKS Cluster
cluster = aws.eks.Cluster("main",
    role_arn=iam_role.arn,
    vpc_config={"subnet_ids": subnet_ids}
)

pulumi.export("cluster_endpoint", cluster.endpoint)
```

## 4. Terraform vs Pulumi

| 维度 | Terraform | Pulumi |
|------|-----------|--------|
| 语言 | HCL | Python/TS/Go等 |
| 状态管理 | 原生 | 托管或自管 |
| 模块生态 | 丰富(Registry) | 发展中 |
| 调试 | 较难 | IDE支持 |
| 学习曲线 | 需学HCL | 用已有语言 |
| 多云 | ✅ | ✅ |
