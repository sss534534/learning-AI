## 1. 配置管理概述

### 1.1 核心职责

- 一致性：机器配置统一
- 自动化：无需手动操作
- 版本化：变更可追溯
- 可重现：随时重建环境

### 1.2 声明式 vs 命令式

| 方式 | 描述 | 例 |
|------|------|----|
| 命令式 | 描述"怎么做" | Shell脚本 |
| 声明式 | 描述"要什么" | Ansible Playbook |

## 2. Ansible

### 2.1 Playbook示例

```yaml
---
- name: Configure web servers
  hosts: webservers
  become: yes
  tasks:
  - name: Install nginx
    apt:
      name: nginx
      state: present

  - name: Ensure nginx is running
    service:
      name: nginx
      state: started
      enabled: yes

  - name: Copy config file
    template:
      src: nginx.conf.j2
      dest: /etc/nginx/nginx.conf
    notify: restart nginx

  handlers:
  - name: restart nginx
    service:
      name: nginx
      state: restarted
```

## 3. 配置管理工具对比

| 工具 | 架构 | 语言 | 特点 |
|------|------|------|------|
| Ansible | 无代理(SSH) | YAML+Python | 简单，无agent |
| Puppet | 主从(Agent) | Puppet DSL | 成熟，大规模 |
| Chef | 主从(Agent) | Ruby DSL | 灵活性高 |
| SaltStack | 主从(Agent/无代理) | YAML+Python | 速度快 |
| Terraform | 声明式API | HCL | IaC方向 |

## 4. Secret管理

| 方案 | 存储 | 特点 |
|------|------|------|
| HashiCorp Vault | 加密存储 | 动态Secret，自动轮转 |
