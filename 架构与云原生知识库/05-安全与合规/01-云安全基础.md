## 1. 共享责任模型

### 1.1 责任划分

| 层面 | 云厂商负责 | 客户负责 |
|------|-----------|---------|
| 物理安全 | ✅ | ❌ |
| 基础设施 | ✅ | ❌ |
| 虚拟化 | ✅ | ❌ |
| OS补丁 | ❌ | ✅ |
| 应用安全 | ❌ | ✅ |
| 数据安全 | ❌ | ✅ |
| 访问管理 | ❌ | ✅ |

### 1.2 云安全策略框架

```
身份安全 ─→ 基础设施安全 ─→ 数据安全 ─→ 应用安全 ─→ 合规审计
```

## 2. 身份与访问管理

### 2.1 最小权限原则

```json
{
    "Effect": "Allow",
    "Action": ["s3:GetObject"],
    "Resource": "arn:aws:s3:::my-bucket/logs/*"
}
```

### 2.2 IAM最佳实践

| 实践 | 说明 |
|------|------|
| 不使用根用户 | 启用MFA，创建管理用户 |
| 最小权限 | 只授予必需权限 |
| 角色而非用户 | EC2/S3等使用角色 |
| 定期审计 | IAM Credential Report |
| 临时凭证 | 用STS替代长期密钥 |

## 3. 数据保护

### 3.1 加密层次

| 层次 | 方法 | 管理 |
|------|------|------|
| 传输中 | TLS 1.3 | 证书管理 |
| 存储中 | KMS+SSE | 密钥轮转 |
| 使用中 | 机密计算 | 硬件TEE |

### 3.2 密钥管理

```python
# AWS KMS 加密/解密
import boto3

kms = boto3.client('kms')

# 加密
response = kms.encrypt(
    KeyId='alias/my-key',
    Plaintext=b'Sensitive data'
)
ciphertext = response['CiphertextBlob']

# 解密
response = kms.decrypt(
    CiphertextBlob=ciphertext
)
plaintext = response['Plaintext']
```
