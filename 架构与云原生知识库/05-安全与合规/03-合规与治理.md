# 合规与治理

> 合规确保系统满足法律法规要求，治理建立策略和控制框架。

---

## 1. 合规标准

| 标准 | 适用领域 | 核心要求 |
|------|---------|---------|
| SOC 2 | 服务商 | 安全、可用、保密 |
| ISO 27001 | 通用 | ISMS体系 |
| PCI DSS | 支付 | 信用卡数据保护 |
| HIPAA | 医疗 | 患者健康信息 |
| GDPR | 个人数据 | 数据隐私 |

## 2. 合规自动化

```python
# 合规扫描工具集成
def audit_compliance():
    results = {
        "encryption_at_rest": check_s3_encryption(),
        "tls_enabled": check_cloudfront_tls(),
        "logging_enabled": check_cloudtrail(),
        "iam_policies": scan_overly_permissive_policies()
    }
    return ComplianceReport(results)
```

**常用工具：**
- AWS Config / Azure Policy
- Open Policy Agent (OPA)
- Checkov / tfsec (IaC扫描)
- Falco (运行时安全)
