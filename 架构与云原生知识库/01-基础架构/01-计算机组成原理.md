# 基础架构 - 计算机组成原理

## 1. CPU架构

### 1.1 现代CPU架构

```
现代CPU核心组件
├── 控制单元 (CU)
├── 算术逻辑单元 (ALU)
├── 寄存器组
├── 缓存层次
├── 流水线
└── SIMD单元
```

### 1.2 指令集架构

| 架构 | 特点 | 代表 |
|------|------|------|
| **CISC** | 复杂指令，可变长度 | x86/x86-64 |
| **RISC** | 精简指令，固定长度 | ARM, MIPS, RISC-V |
| **EPIC/VLIW** | 显式并行性 | Itanium |

### 1.3 多核与多线程

```python
# 并发 vs 并行
# 并发: 多个任务轮换执行（单CPU）
# 并行: 多个任务同时执行（多CPU）

import concurrent.futures

def task(n):
    return n * n

with concurrent.futures.ThreadPoolExecutor(max_workers=4) as executor:
    results = executor.map(task, range(10))
```

## 2. 内存层次结构

### 2.1 存储金字塔

```
寄存器（最快，最小）
    ↓
L1缓存
    ↓
L2缓存
    ↓
L3缓存
    ↓
主内存 (RAM)
    ↓
固态硬盘 (SSD)
    ↓
机械硬盘 (HDD)
    ↓
网络存储（最慢，最大）
```

### 2.2 缓存原理

**局部性原理：**
- 时间局部性：最近访问的数据很快会再次访问
- 空间局部性：一个位置被访问，附近位置也可能被访问

**缓存映射策略：**
- 直接映射
- 全相联
- 组相联

## 3. 存储系统

### 3.1 存储层次

| 层级 | 介质 | 特点 | 用途 |
|------|------|------|------|
| **一级存储** | 寄存器/缓存 | 极快，最小 | CPU操作 |
| **二级存储** | 内存 | 快，较小 | 运行程序 |
| **三级存储** | SSD/HDD | 较慢，较大 | 持久存储 |
| **离线存储** | 磁带/光盘 | 慢，海量 | 备份归档 |

### 3.2 RAID技术

| RAID级别 | 特点 | 容错 | 性能 |
|---------|------|------|------|
| RAID 0 | 条带化 | 无 | 高 |
| RAID 1 | 镜像 | 高 | 低 |
| RAID 5 | 单校验 | 中 | 中 |
| RAID 6 | 双校验 | 高 | 中 |
| RAID 10 | 镜像+条带 | 高 | 高 |

## 5. 性能优化实践

### 5.1 缓存优化

```python
# 好的例子：顺序访问数组（利用空间局部性）
def sum_array(arr):
    total = 0
    for element in arr:
        total += element
    return total

# 差的例子：跳着访问（破坏局部性）
def sum_array_bad(arr):
    total = 0
    for i in range(0, len(arr), 2):
        total += arr[i]
    return total
```

### 5.2 并发优化

**Amdahl定律：**
```
加速比 = 1 / [(1-P) + P/N]
P = 可并行化部分比例
N = 处理器数量
```
