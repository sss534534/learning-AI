## 1. 操作系统概述

### 1.1 核心职责

| 功能 | 描述 |
|------|------|
| 进程管理 | 创建/销毁/调度进程和线程 |
| 内存管理 | 分配/回收/虚拟内存/页置换 |
| 文件系统 | 文件存储/目录管理/权限控制 |
| I/O管理 | 设备驱动/中断处理/DMA |
| 安全保护 | 用户权限/隔离/加密 |

### 1.2 内核类型对比

| 类型 | 特点 | 例 |
|------|------|----|
| 宏内核 | 所有服务在内核态 | Linux |
| 微内核 | 最小内核，服务在用户态 | QNX |
| 混合内核 | 宏内核+部分模块化 | Windows NT |

## 2. 进程与线程管理

### 2.1 进程状态转换

```
创建 → 就绪 ↔ 运行 → 终止
           ↑     ↓
         阻塞 ← 等待I/O
```

### 2.2 进程 vs 线程

| 维度 | 进程 | 线程 |
|------|------|------|
| 地址空间 | 独立 | 共享 |
| 切换开销 | 大 | 小 |
| 通信方式 | IPC（管道/消息队列） | 共享内存 |
| 故障隔离 | 相互隔离 | 一个崩溃影响全部 |

### 2.3 上下文切换开销

```python
# 模拟上下文切换的代价
import time, threading

def worker():
    for _ in range(1000000):
        pass

# 线程切换较多时的性能影响
threads = [threading.Thread(target=worker) for _ in range(100)]
start = time.time()
[t.start() for t in threads]
[t.join() for t in threads]
print(f"100线程耗时: {time.time() - start:.2f}s")
```

## 3. 内存管理

### 3.1 虚拟内存

每个进程拥有独立虚拟地址空间，通过MMU映射到物理内存：

```
虚拟地址 → 页表 → 物理地址
           ↓
        缺页中断 → 磁盘交换
```

### 3.2 页面置换算法

| 算法 | 策略 | 优缺点 |
|------|------|--------|
| FIFO | 最先进入的页面先换出 | 实现简单，可能Belady异常 |
| LRU | 最久未使用的换出 | 性能好，实现成本高 |
| Clock | 近似LRU的环形扫描 | 折中方案，实践中常用 |

### 3.3 分段与分页

| 维度 | 分段 | 分页 |
|------|------|------|
| 视角 | 用户视角（逻辑模块） | 系统视角（固定大小） |
| 大小 | 可变 | 固定（4KB通常） |
| 碎片 | 外部碎片 | 内部碎片 |
| 保护 | 按段保护 | 按页保护 |

## 4. 文件系统

### 4.1 文件系统对比

| 文件系统 | 特点 | 适用场景 |
|---------|------|---------|
| ext4 | Linux默认，成熟稳定 | 通用 |
| XFS | 大文件高性能 | 多媒体/大数据 |
| Btrfs | 快照/压缩/校验 | 高级存储需求 |
| ZFS | 存储池/数据完整性 | 企业级存储 |
| NTFS | Windows默认，ACL | Windows生态 |

### 4.2 文件系统层次

```
应用程序 → VFS（虚拟文件系统） → 具体文件系统 → 块设备层 → 磁盘
```

## 5. I/O管理

### 5.1 I/O模型对比

| 模型 | 描述 | 性能 | 复杂度 |
|------|------|------|--------|
| 阻塞I/O | 等待完成才返回 | 低 | 低 |
| 非阻塞I/O | 立即返回，轮询状态 | 中 | 中 |
| I/O多路复用 | select/epoll监听多fd | 高 | 高 |
| 异步I/O | 内核完成通知用户 | 最高 | 最高 |

### 5.2 零拷贝技术

```python
# 传统拷贝：read → 用户态 → write（4次拷贝）
# 零拷贝：sendfile（2次拷贝，或0次如果DMA支持）
```

**应用：** Kafka、Nginx、RocketMQ 均使用了零拷贝技术提升性能。

## 6. 调度算法

| 算法 | 策略 | 适用场景 |
|------|------|---------|
| FCFS | 先来先服务 | 批处理 |
| 短作业优先 | 最短CPU burst优先 | 交互少 |
| 优先级调度 | 优先权最高的先执行 | 实时系统 |
| 时间片轮转 | 每个进程固定时间片 | 分时系统 |
| CFS（Linux） | 红黑树维护vruntime | 通用 |

## 7. 并发与同步

### 7.1 锁机制对比

| 机制 | 作用域 | 开销 | 适用 |
|------|--------|------|------|
| 互斥锁(Mutex) | 进程/线程 | 高 | 短临界区 |
| 读写锁 | 读共享/写互斥 | 中 | 读多写少 |
| 自旋锁 | 忙等待 | 低（短时） | 极短临界区 |
| RCU | 读无锁 | 极低 | 读极多写极少 |

### 7.2 死锁四条件

1. **互斥**：资源一次只能一个进程使用
2. **持有并等待**：进程持有资源同时等待其他
3. **非剥夺**：资源不能被强制剥夺
4. **循环等待**：进程间形成循环等待链
