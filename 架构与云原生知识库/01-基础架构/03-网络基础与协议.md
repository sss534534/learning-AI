# 基础架构 - 网络基础与协议

## 1. 网络分层模型

### 1.1 OSI七层模型

```
┌─────────────────────────────────┐
│ 7. 应用层    (HTTP, FTP, DNS)     │
├─────────────────────────────────┤
│ 6. 表示层    (SSL/TLS)           │
├─────────────────────────────────┤
│ 5. 会话层    (RPC, Socket)       │
├─────────────────────────────────┤
│ 4. 传输层    (TCP, UDP)          │
├─────────────────────────────────┤
│ 3. 网络层    (IP, ICMP)          │
├─────────────────────────────────┤
│ 2. 数据链路层 (Ethernet, ARP)     │
├─────────────────────────────────┤
│ 1. 物理层    (网卡, 线缆)         │
└─────────────────────────────────┘
```

### 1.2 TCP/IP四层模型

```
应用层 (HTTP, FTP, DNS)
    ↓
传输层 (TCP, UDP)
    ↓
网际层 (IP, ICMP)
    ↓
网络接口层 (Ethernet, WiFi)
```

## 2. 核心协议详解

### 2.1 TCP协议

**三次握手：**
```
客户端 → SYN → 服务端
客户端 ← SYN+ACK ← 服务端
客户端 → ACK → 服务端
```

**四次挥手：**
```
客户端 → FIN → 服务端
客户端 ← ACK ← 服务端
客户端 ← FIN ← 服务端
客户端 → ACK → 服务端
```

**TCP特性：**
- 面向连接
- 可靠传输
- 流量控制
- 拥塞控制

### 2.2 UDP协议

**特点：**
- 无连接
- 不可靠
- 速度快
- 开销小

**应用场景：**
- 视频流
- 在线游戏
- DNS查询
- 实时通信

### 2.3 HTTP协议

```http
GET /index.html HTTP/1.1
Host: example.com
User-Agent: curl/7.68.0
Accept: */*

HTTP/1.1 200 OK
Content-Type: text/html
Content-Length: 123

<!DOCTYPE html>
<html>...</html>
```

**HTTP方法：**
| 方法 | 用途 | 幂等 |
|------|------|------|
| GET | 获取资源 | ✅ |
| POST | 创建资源 | ❌ |
| PUT | 更新资源 | ✅ |
| PATCH | 部分更新 | ❌ |
| DELETE | 删除资源 | ✅ |

**HTTP状态码：**
- 2xx: 成功
- 3xx: 重定向
- 4xx: 客户端错误
- 5xx: 服务端错误

## 3. 网络工具实践

### 3.1 常用命令

```bash
# 查看网络配置
ifconfig
ip addr

# 测试连通性
ping 8.8.8.8

# 查看路由表
route -n
ip route

# 端口检测
telnet example.com 80
nc -zv example.com 80

# 查看连接
netstat -tlnp
ss -tlnp
```

### 3.2 Wireshark抓包

**过滤器语法：**
```
tcp.port == 80
ip.addr == 192.168.1.1
http.request.method == "GET"
```

## 4. 网络安全基础

### 4.1 防火墙

**iptables示例：**
```bash
# 允许SSH
iptables -A INPUT -p tcp --dport 22 -j ACCEPT

# 允许HTTP/HTTPS
iptables -A INPUT -p tcp --dport 80 -j ACCEPT
iptables -A INPUT -p tcp --dport 443 -j ACCEPT

# 默认拒绝
iptables -P INPUT DROP
```

### 4.2 SSL/TLS

**HTTPS握手：**
```
1. Client: Client Hello (支持的加密套件)
2. Server: Server Hello + 证书
3. Client: 验证证书 + 生成Pre-master
4. Server: 确认
5. 双方: 生成会话密钥
6. 开始加密传输
```
