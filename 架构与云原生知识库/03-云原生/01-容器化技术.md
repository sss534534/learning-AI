# 云原生 - 容器化技术

## 1. Docker基础

### 1.1 核心概念

| 概念 | 说明 |
|------|------|
| **镜像 (Image)** | 只读模板，用于创建容器 |
| **容器 (Container)** | 镜像的运行实例 |
| **仓库 (Registry)** | 存储镜像的地方 |
| **Dockerfile** | 构建镜像的脚本 |

### 1.2 Dockerfile最佳实践

```dockerfile
# 多阶段构建
FROM golang:1.22 AS builder
WORKDIR /app
COPY go.mod go.sum ./
RUN go mod download
COPY . .
RUN CGO_ENABLED=0 go build -o myapp

# 最终镜像
FROM alpine:3.20
COPY --from=builder /app/myapp /usr/local/bin/
EXPOSE 8080
CMD ["myapp"]
```

### 1.3 常用命令

```bash
# 镜像操作
docker pull nginx:alpine
docker build -t myapp:v1 .
docker images
docker rmi myapp:v1

# 容器操作
docker run -d -p 80:80 nginx:alpine
docker ps
docker stop <container-id>
docker rm <container-id>
docker logs -f <container-id>
docker exec -it <container-id> sh

# 系统清理
docker system prune -a
```

## 2. Kubernetes基础

### 2.1 核心资源

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: nginx:1.25
        ports:
        - containerPort: 80
        resources:
          requests:
            memory: "256Mi"
            cpu: "250m"
          limits:
            memory: "512Mi"
            cpu: "500m"
```

### 2.2 常用kubectl命令

```bash
# 查看资源
kubectl get nodes
kubectl get pods -A
kubectl get deployments

# 查看详情
kubectl describe pod <pod-name>
kubectl logs -f <pod-name>
kubectl exec -it <pod-name> -- sh

# 应用配置
kubectl apply -f manifest.yaml
kubectl delete -f manifest.yaml

# 扩容
kubectl scale deployment nginx-deployment --replicas=5

# 端口转发
kubectl port-forward <pod-name> 8080:80
```

### 2.3 Service配置

```yaml
apiVersion: v1
kind: Service
metadata:
  name: nginx-service
spec:
  selector:
    app: nginx
  ports:
  - protocol: TCP
    port: 80
    targetPort: 80
  type: ClusterIP  # NodePort / LoadBalancer / ClusterIP
```

## 3. 实践项目

### 3.1 部署Web应用

```bash
# 1. 创建部署
kubectl apply -f deployment.yaml

# 2. 创建服务
kubectl apply -f service.yaml

# 3. 查看状态
kubectl get all

# 4. 访问应用
kubectl port-forward service/nginx-service 8080:80
```
