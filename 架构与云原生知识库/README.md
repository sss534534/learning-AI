## 🛠️ 核心技术栈

### 基础设施技术
- **虚拟化/容器**：Docker / Containerd / Kata
- **编排**：Kubernetes / K3s / OpenShift
- **服务网格**：Istio / Linkerd / Cilium
- **基础设施即代码**：Terraform / Pulumi / Crossplane
- **配置管理**：Ansible / Puppet / Chef

### 开发与交付技术
- **CI/CD**：GitLab CI / GitHub Actions / Jenkins / ArgoCD
- **监控**：Prometheus / Grafana / ELK Stack / Jaeger
- **日志**：Loki / Fluentd
- **追踪**：OpenTelemetry / Zipkin

### 平台与服务
- **公有云**：AWS / Azure / GCP / 阿里云
- **私有云**：OpenStack / OpenShift / Rancher
- **Serverless**：Lambda / Knative / Function Compute
