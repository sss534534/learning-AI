# 性能优化实践

> 性能优化从系统架构到代码级别，需系统性分析和持续改进。

---

## 1. 性能分析方法

| 阶段 | 方法 | 工具 |
|------|------|------|
| 分析 | 性能剖析 | pprof, JProfiler |
| 压测 | 负载模拟 | k6, wrk, ab |
| 监控 | 持续追踪 | Prometheus + Grafana |

## 2. 性能优化金字塔

```
应用代码优化
    ↑
缓存策略
    ↑
数据库优化
    ↑
网络优化
    ↑
基础设施优化
```

## 3. 常见优化策略

| 层面 | 策略 | 效果 |
|------|------|------|
| 缓存 | Redis/Memcached | 10-100x |
| CDN | 静态资源加速 | 地域加速 |
| 连接池 | 减少连接开销 | 30-50% |
| 异步 | MQ削峰 | 峰值吞吐 |
| 索引 | DB查询优化 | 100-1000x |
| 压缩 | 响应体压缩 | 减少50-80%带宽 |

```python
# 缓存策略示例
def get_user(user_id):
    # 1. 先查缓存
    user = cache.get(f"user:{user_id}")
    if user:
        return user
    # 2. 缓存miss，查DB
    user = db.query(User).filter(id=user_id).first()
    # 3. 回填缓存
    cache.set(f"user:{user_id}", user, ttl=3600)
    return user
```
