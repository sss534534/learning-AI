# 成本优化策略

> 云成本优化（FinOps）是持续管理云支出的过程，平衡速度、成本和质量。

---

## 1. 成本优化维度

| 维度 | 策略 | 节省潜力 |
|------|------|----------|
| 计算 | 按需→预留/Spot | 30-60% |
| 存储 | 分层存储，生命周期 | 30-50% |
| 网络 | CDN，压缩，内网通信 | 20-40% |
| 数据库 | 只读副本，自动扩缩 | 20-40% |
| K8s | 垂直/水平Pod自动扩缩 | 30-50% |

## 2. K8s成本优化

| 策略 | 说明 |
|------|------|
| HPA/VPA | 自动扩缩Pod |
| Cluster Autoscaler | 节点自动扩缩 |
| 资源请求/限制 | 合理设置 |
| 节点池 | Spot + 按需混合 |
| 命名空间配额 | 防止资源浪费 |

## 3. FinOps实践

```
可视（成本仪表盘）→ 优化（资源配置）→ 运营（持续改进）
```

| 角色 | 职责 |
|------|------|
| 工程师 | 资源打标签，合理资源配置 |
| 财务 | 预算制定，成本分析 |
| 管理层 | 优化目标制定 |
