# 监控与运维工具

> 监控运维是保障系统稳定性的基石，涵盖指标采集、可视化、告警和自动化运维。

---

## 1. 监控工具栈

| 层级 | 工具 | 说明 |
|------|------|------|
| 指标采集 | Prometheus | 拉模式，服务发现 |
| 可视化 | Grafana | 仪表盘，告警 |
| 日志 | Loki / ELK | 日志聚合 |
| 链路追踪 | Jaeger / Tempo | 分布式追踪 |
| 事件告警 | Alertmanager | 路由，静默，聚合 |

### 2.2 Runbook自动化

```python
# 自动化故障处理
def handle_high_cpu(instance_id):
    # 1. 采集诊断数据
    collect_thread_dump(instance_id)
    # 2. 分析
    if is_memory_leak(instance_id):
        restart_service(instance_id)
    elif is_traffic_spike(instance_id):
        auto_scale(instance_id)
    # 3. 通知
    notify_oncall("CPU告警已处理")
```
