## 1.1 样本空间与随机事件、概率的公理化定义

### 1.1.1 样本空间

**定义 1.1（样本空间）**：随机试验的所有可能结果组成的集合称为样本空间，记为 $\Omega$。样本空间的元素称为样本点，记为 $\omega$。

**示例 1.1**：
- 抛一枚硬币：$\Omega = \{H, T\}$，其中 $H$ 表示正面，$T$ 表示反面
- 抛两枚硬币：$\Omega = \{(H,H), (H,T), (T,H), (T,T)\}$
- 掷一颗骰子：$\Omega = \{1, 2, 3, 4, 5, 6\}$
- 记录某电话交换台一分钟内接到的呼唤次数：$\Omega = \{0, 1, 2, \cdots\}$

### 1.1.2 随机事件

**定义 1.2（随机事件）**：样本空间的子集称为随机事件，简称事件。通常用大写字母 $A, B, C, \cdots$ 表示。

- **基本事件**：单个样本点组成的事件
- **必然事件**：样本空间 $\Omega$ 本身，每次试验必然发生
- **不可能事件**：空集 $\varnothing$，每次试验都不发生

**事件的关系与运算**：
1. **包含关系**：若 $A \subset B$，则事件 $A$ 发生必然导致事件 $B$ 发生
2. **相等关系**：若 $A \subset B$ 且 $B \subset A$，则 $A = B$
3. **和事件**：$A \cup B$，表示事件 $A$ 与 $B$ 至少有一个发生
4. **积事件**：$A \cap B$ 或 $AB$，表示事件 $A$ 与 $B$ 同时发生
5. **差事件**：$A - B$，表示事件 $A$ 发生而事件 $B$ 不发生
6. **互斥事件**：若 $AB = \varnothing$，则事件 $A$ 与 $B$ 互不相容（互斥）
7. **对立事件**：若 $A \cup B = \Omega$ 且 $AB = \varnothing$，则 $B$ 是 $A$ 的对立事件，记为 $\overline{A}$

**事件运算的性质**：
- 交换律：$A \cup B = B \cup A$，$AB = BA$
- 结合律：$(A \cup B) \cup C = A \cup (B \cup C)$，$(AB)C = A(BC)$
- 分配律：$A(B \cup C) = AB \cup AC$，$A \cup (BC) = (A \cup B)(A \cup C)$
- 德摩根律：$\overline{A \cup B} = \overline{A} \overline{B}$，$\overline{AB} = \overline{A} \cup \overline{B}$

### 1.1.3 概率的公理化定义（柯尔莫哥洛夫）

**定义 1.3（概率的公理化定义）**：设 $\Omega$ 是样本空间，$\mathcal{F}$ 是 $\Omega$ 的子集族，称为 $\sigma$-代数。若对于任意 $A \in \mathcal{F}$，存在实数 $P(A)$ 与之对应，且满足以下三条公理：

1. **非负性**：对于任意 $A \in \mathcal{F}$，有 $P(A) \geq 0$
2. **规范性**：$P(\Omega) = 1$
3. **可列可加性**：若 $A_1, A_2, \cdots$ 是两两互斥事件，即 $A_iA_j = \varnothing$（$i \neq j$），则
   $$P\left(\bigcup_{i=1}^{\infty}A_i\right) = \sum_{i=1}^{\infty}P(A_i)$$

则称 $P(A)$ 为事件 $A$ 的概率。

**概率的性质**：

**性质 1**：$P(\varnothing) = 0$

**性质 2（有限可加性）**：若 $A_1, A_2, \cdots, A_n$ 两两互斥，则
$$P\left(\bigcup_{i=1}^{n}A_i\right) = \sum_{i=1}^{n}P(A_i)$$

**性质 3**：对于任意事件 $A$，有 $P(\overline{A}) = 1 - P(A)$

**性质 4（减法公式）**：若 $A \subset B$，则 $P(B - A) = P(B) - P(A)$

**性质 5**：对于任意事件 $A$，有 $P(A) \leq 1$

**性质 6（加法公式）**：对于任意两个事件 $A, B$，有
$$P(A \cup B) = P(A) + P(B) - P(AB)$$

**证明思路（加法公式）**：
将 $A \cup B$ 分解为三个互斥事件的和：$A \cup B = (A - B) \cup AB \cup (B - A)$，利用有限可加性即可证明。

**示例 1.2**：从一副52张的扑克牌中随机抽取一张，求抽到红桃或K的概率。

设 $A$ 表示"抽到红桃"，$B$ 表示"抽到K"，则
$$P(A) = \frac{13}{52}, \quad P(B) = \frac{4}{52}, \quad P(AB) = \frac{1}{52}$$
由加法公式：
$$P(A \cup B) = P(A) + P(B) - P(AB) = \frac{13}{52} + \frac{4}{52} - \frac{1}{52} = \frac{16}{52} = \frac{4}{13}$$

## 1.2 古典概型、几何概型、条件概率

### 1.2.1 古典概型

**定义 1.4（古典概型）**：若随机试验满足：
1. 样本空间 $\Omega$ 只包含有限个样本点，即 $\Omega = \{\omega_1, \omega_2, \cdots, \omega_n\}$
2. 每个样本点发生的可能性相等，即 $P(\{\omega_1\}) = P(\{\omega_2\}) = \cdots = P(\{\omega_n\}) = \frac{1}{n}$

则称此试验为古典概型。

**定理 1.1（古典概型的概率计算公式）**：在古典概型中，事件 $A$ 的概率为
$$P(A) = \frac{k}{n} = \frac{A\text{ 中包含的样本点个数}}{\Omega\text{ 中样本点总数}}$$

**示例 1.3**：将一枚硬币抛掷3次，求恰好出现2次正面的概率。

样本空间 $\Omega$ 包含8个样本点：
$$\Omega = \{HHH, HHT, HTH, THH, HTT, THT, TTH, TTT\}$$
事件 $A$ = "恰好出现2次正面" 包含3个样本点：$A = \{HHT, HTH, THH\}$
因此，$P(A) = \frac{3}{8}$

**示例 1.4（超几何分布）**：设有 $N$ 件产品，其中有 $M$ 件次品，从中任取 $n$ 件，求恰好取到 $k$ 件次品的概率。

样本点总数为 $\binom{N}{n}$，事件 $A$ = "恰好取到 $k$ 件次品" 包含的样本点数为 $\binom{M}{k}\binom{N-M}{n-k}$，因此
$$P(A) = \frac{\binom{M}{k}\binom{N-M}{n-k}}{\binom{N}{n}}$$

### 1.2.2 几何概型

**定义 1.5（几何概型）**：若随机试验满足：
1. 样本空间 $\Omega$ 是某个可度量的几何区域（如线段、平面区域、空间区域等）
2. 样本点落在 $\Omega$ 内任一子区域 $A$ 的可能性大小与 $A$ 的度量（长度、面积、体积等）成正比，而与 $A$ 的位置和形状无关

则称此试验为几何概型。

**定理 1.2（几何概型的概率计算公式）**：在几何概型中，事件 $A$ 的概率为
$$P(A) = \frac{m(A)}{m(\Omega)}$$
其中 $m(A)$ 表示区域 $A$ 的度量。

**示例 1.5（会面问题）**：甲、乙两人约定在上午8点到9点之间在某地会面，先到者等候20分钟，过时就离开，求两人能会面的概率。

设甲到达的时间为 $x$，乙到达的时间为 $y$，则样本空间为
$$\Omega = \{(x,y) \mid 0 \leq x \leq 60, 0 \leq y \leq 60\}$$
事件 $A$ = "两人能会面" 为
$$A = \{(x,y) \in \Omega \mid |x - y| \leq 20\}$$
样本空间面积为 $60^2 = 3600$，事件 $A$ 的面积为 $60^2 - 2 \times \frac{1}{2} \times 40^2 = 2000$，因此
$$P(A) = \frac{2000}{3600} = \frac{5}{9}$$

### 1.2.3 条件概率

**定义 1.6（条件概率）**：设 $A, B$ 是两个事件，且 $P(B) > 0$，则称
$$P(A|B) = \frac{P(AB)}{P(B)}$$
为在事件 $B$ 发生的条件下事件 $A$ 发生的条件概率。

**条件概率的性质**：
1. 非负性：$P(A|B) \geq 0$
2. 规范性：$P(\Omega|B) = 1$
3. 可列可加性：若 $A_1, A_2, \cdots$ 两两互斥，则
   $$P\left(\bigcup_{i=1}^{\infty}A_i|B\right) = \sum_{i=1}^{\infty}P(A_i|B)$$

因此条件概率也是一种概率，具有概率的一切性质。

**示例 1.6**：某家庭有两个孩子，已知其中一个是女孩，求另一个也是女孩的概率。

样本空间 $\Omega = \{(男,男), (男,女), (女,男), (女,女)\}$，每个样本点概率为 $\frac{1}{4}$。
设 $A$ = "两个都是女孩"，$B$ = "至少有一个女孩"，则
$$AB = \{(女,女)\}, \quad B = \{(男,女), (女,男), (女,女)\}$$
因此
$$P(A|B) = \frac{P(AB)}{P(B)} = \frac{\frac{1}{4}}{\frac{3}{4}} = \frac{1}{3}$$

## 1.3 乘法公式、全概率公式、贝叶斯公式

### 1.3.1 乘法公式

**定理 1.3（乘法公式）**：
- 若 $P(B) > 0$，则 $P(AB) = P(B)P(A|B)$
- 若 $P(A) > 0$，则 $P(AB) = P(A)P(B|A)$

**推广（n个事件的乘法公式）**：设 $P(A_1A_2\cdots A_{n-1}) > 0$，则
$$P(A_1A_2\cdots A_n) = P(A_1)P(A_2|A_1)P(A_3|A_1A_2)\cdots P(A_n|A_1A_2\cdots A_{n-1})$$

**证明思路**：利用条件概率的定义，数学归纳法可证推广情形。

**示例 1.7**：袋中有5个白球和3个黑球，不放回地取球3次，求三次都取到白球的概率。

设 $A_i$ = "第 $i$ 次取到白球"，$i = 1, 2, 3$，则
$$P(A_1) = \frac{5}{8}, \quad P(A_2|A_1) = \frac{4}{7}, \quad P(A_3|A_1A_2) = \frac{3}{6}$$
由乘法公式：
$$P(A_1A_2A_3) = P(A_1)P(A_2|A_1)P(A_3|A_1A_2) = \frac{5}{8} \times \frac{4}{7} \times \frac{3}{6} = \frac{5}{28}$$

### 1.3.2 全概率公式

**定义 1.7（样本空间的划分）**：设 $B_1, B_2, \cdots, B_n$ 是一组事件，若满足：
1. $B_iB_j = \varnothing$（$i \neq j$）
2. $\bigcup_{i=1}^{n}B_i = \Omega$

则称 $B_1, B_2, \cdots, B_n$ 是样本空间 $\Omega$ 的一个划分（或完备事件组）。

**定理 1.4（全概率公式）**：设 $B_1, B_2, \cdots, B_n$ 是 $\Omega$ 的一个划分，且 $P(B_i) > 0$（$i = 1, 2, \cdots, n$），则对任意事件 $A$，有
$$P(A) = \sum_{i=1}^{n}P(B_i)P(A|B_i)$$

**证明思路**：将 $A$ 分解为 $A = A\Omega = A(\bigcup_{i=1}^{n}B_i) = \bigcup_{i=1}^{n}AB_i$，利用有限可加性和乘法公式即可证明。

**示例 1.8**：某工厂有三个车间生产同一种产品，第一车间的次品率为0.05，第二车间的次品率为0.03，第三车间的次品率为0.02。三个车间的产量分别占总产量的25%、35%、40%。现从全厂产品中任取一件，求它是次品的概率。

设 $A$ = "取到次品"，$B_i$ = "取到第 $i$ 车间的产品"，$i = 1, 2, 3$，则
$$P(B_1) = 0.25, \quad P(B_2) = 0.35, \quad P(B_3) = 0.40$$
$$P(A|B_1) = 0.05, \quad P(A|B_2) = 0.03, \quad P(A|B_3) = 0.02$$
由全概率公式：
$$P(A) = P(B_1)P(A|B_1) + P(B_2)P(A|B_2) + P(B_3)P(A|B_3)$$
$$= 0.25 \times 0.05 + 0.35 \times 0.03 + 0.40 \times 0.02 = 0.0315$$

### 1.3.3 贝叶斯公式

**定理 1.5（贝叶斯公式）**：设 $B_1, B_2, \cdots, B_n$ 是 $\Omega$ 的一个划分，且 $P(B_i) > 0$（$i = 1, 2, \cdots, n$），则对任意事件 $A$（$P(A) > 0$），有
$$P(B_i|A) = \frac{P(B_i)P(A|B_i)}{\sum_{j=1}^{n}P(B_j)P(A|B_j)}$$

**证明思路**：由条件概率定义 $P(B_i|A) = \frac{P(AB_i)}{P(A)}$，分子用乘法公式，分母用全概率公式即可得证。

**说明**：$P(B_i)$ 称为先验概率，$P(B_i|A)$ 称为后验概率，贝叶斯公式是从先验概率推向后验概率的公式。

**示例 1.9**：在示例1.8中，若已知取到的是次品，求它是第一车间生产的概率。

由贝叶斯公式：
$$P(B_1|A) = \frac{P(B_1)P(A|B_1)}{P(A)} = \frac{0.25 \times 0.05}{0.0315} \approx 0.3968$$

## 1.4 事件的独立性、伯努利概型

### 1.4.1 事件的独立性

**定义 1.8（两个事件的独立性）**：设 $A, B$ 是两个事件，若
$$P(AB) = P(A)P(B)$$
则称事件 $A$ 与 $B$ 相互独立，简称独立。

**性质**：
- 若 $P(A) > 0$，则 $A$ 与 $B$ 独立当且仅当 $P(B|A) = P(B)$
- 若 $A$ 与 $B$ 独立，则 $\overline{A}$ 与 $B$、$A$ 与 $\overline{B}$、$\overline{A}$ 与 $\overline{B}$ 也独立

**定义 1.9（三个事件的独立性）**：设 $A, B, C$ 是三个事件，若满足：
1. $P(AB) = P(A)P(B)$
2. $P(AC) = P(A)P(C)$
3. $P(BC) = P(B)P(C)$
4. $P(ABC) = P(A)P(B)P(C)$

则称 $A, B, C$ 相互独立。若只满足前三个条件，则称它们两两独立。

**注意**：两两独立不能推出相互独立。

**定义 1.10（n个事件的独立性）**：设 $A_1, A_2, \cdots, A_n$ 是 $n$ 个事件，若对任意 $k$（$1 < k \leq n$）和任意 $1 \leq i_1 < i_2 < \cdots < i_k \leq n$，都有
$$P(A_{i_1}A_{i_2}\cdots A_{i_k}) = P(A_{i_1})P(A_{i_2})\cdots P(A_{i_k})$$

则称 $A_1, A_2, \cdots, A_n$ 相互独立。

**示例 1.10**：三人独立地去破译一份密码，他们能译出的概率分别为 $\frac{1}{5}, \frac{1}{3}, \frac{1}{4}$，求密码被译出的概率。

设 $A_i$ = "第 $i$ 人译出密码"，$i = 1, 2, 3$，则
$$P(A_1) = \frac{1}{5}, \quad P(A_2) = \frac{1}{3}, \quad P(A_3) = \frac{1}{4}$$
事件 $A$ = "密码被译出" = $A_1 \cup A_2 \cup A_3$，利用对立事件：
$$P(A) = 1 - P(\overline{A_1}\overline{A_2}\overline{A_3}) = 1 - P(\overline{A_1})P(\overline{A_2})P(\overline{A_3})$$
$$= 1 - \frac{4}{5} \times \frac{2}{3} \times \frac{3}{4} = 1 - \frac{2}{5} = \frac{3}{5}$$

### 1.4.2 伯努利概型

**定义 1.11（伯努利试验）**：只有两个可能结果 $A$ 与 $\overline{A}$ 的试验称为伯努利试验。通常记 $P(A) = p$，$P(\overline{A}) = 1 - p = q$。

**定义 1.12（n重伯努利试验）**：将伯努利试验独立地重复进行 $n$ 次，称为n重伯努利试验。

**定理 1.6（二项概率公式）**：在n重伯努利试验中，事件 $A$ 恰好发生 $k$ 次的概率为
$$P_n(k) = \binom{n}{k}p^kq^{n-k}, \quad k = 0, 1, 2, \cdots, n$$

**证明思路**：事件 $A$ 在指定的 $k$ 次试验中发生，其余 $n-k$ 次不发生的概率为 $p^kq^{n-k}$，而这样的指定方式有 $\binom{n}{k}$ 种，由有限可加性即得。

**示例 1.11**：某人进行射击，设每次射击的命中率为0.02，独立射击400次，求至少命中2次的概率。

设命中次数为 $X$，则 $X \sim B(400, 0.02)$，
$$P(X \geq 2) = 1 - P(X = 0) - P(X = 1)$$
$$= 1 - (0.98)^{400} - \binom{400}{1}(0.02)(0.98)^{399}$$
利用泊松近似（$\lambda = np = 8$）：
$$P(X = k) \approx \frac{e^{-8}8^k}{k!}$$
因此
$$P(X \geq 2) \approx 1 - e^{-8} - 8e^{-8} = 1 - 9e^{-8} \approx 0.99698$$

## 1.5 概率论在AI中的应用

### 1.5.1 贝叶斯网络

**定义 1.13（贝叶斯网络）**：贝叶斯网络是一个有向无环图（DAG），其中：
1. 每个节点表示一个随机变量
2. 每条有向边表示变量之间的概率依赖关系
3. 每个节点附有一个条件概率表（CPT），表示该变量在给定父节点条件下的概率分布

**贝叶斯网络的核心思想**：利用条件独立性来简化联合概率分布的表示。

**链式法则**：对于任意 $n$ 个随机变量 $X_1, X_2, \cdots, X_n$，其联合概率分布可表示为
$$P(X_1, X_2, \cdots, X_n) = P(X_1)P(X_2|X_1)P(X_3|X_1, X_2)\cdots P(X_n|X_1, \cdots, X_{n-1})$$

**贝叶斯网络的因式分解**：设 $Parents(X_i)$ 表示节点 $X_i$ 的父节点集合，则联合概率分布可表示为
$$P(X_1, X_2, \cdots, X_n) = \prod_{i=1}^{n}P(X_i|Parents(X_i))$$

**示例 1.12（简单的贝叶斯网络）**：考虑一个描述"草湿"的贝叶斯网络，包含以下变量：
- Cloudy（多云）：取值为True/False
- Sprinkler（洒水器开）：取值为True/False
- Rain（下雨）：取值为True/False
- WetGrass（草湿）：取值为True/False

网络结构：Cloudy → Sprinkler，Cloudy → Rain，Sprinkler → WetGrass，Rain → WetGrass

条件概率表示例：
$$P(Sprinkler|Cloudy) = \begin{cases} 0.1, & Cloudy = True \\ 0.5, & Cloudy = False \end{cases}$$
$$P(Rain|Cloudy) = \begin{cases} 0.8, & Cloudy = True \\ 0.2, & Cloudy = False \end{cases}$$

联合概率分布可表示为：
$$P(C, S, R, W) = P(C)P(S|C)P(R|C)P(W|S, R)$$

### 1.5.2 朴素贝叶斯分类器

**问题描述**：给定一个样本的特征向量 $\mathbf{x} = (x_1, x_2, \cdots, x_n)$，预测其所属类别 $c \in \{c_1, c_2, \cdots, c_k\}$。

**贝叶斯决策规则**：选择使后验概率 $P(c|\mathbf{x})$ 最大的类别：
$$\hat{c} = \arg\max_{c} P(c|\mathbf{x})$$

由贝叶斯公式：
$$P(c|\mathbf{x}) = \frac{P(c)P(\mathbf{x}|c)}{P(\mathbf{x})}$$

由于分母 $P(\mathbf{x})$ 与类别 $c$ 无关，因此只需最大化分子 $P(c)P(\mathbf{x}|c)$。

**朴素贝叶斯的条件独立性假设**：假设在给定类别 $c$ 的条件下，各特征相互独立，即
$$P(\mathbf{x}|c) = P(x_1, x_2, \cdots, x_n|c) = \prod_{i=1}^{n}P(x_i|c)$$

**朴素贝叶斯分类器**：
$$\hat{c} = \arg\max_{c} \left[ P(c) \prod_{i=1}^{n}P(x_i|c) \right]$$

**算法步骤**：

1. **学习阶段**：从训练数据中估计先验概率 $P(c)$ 和条件概率 $P(x_i|c)$
   - 先验概率：$P(c) = \frac{\text{类别 } c \text{ 的样本数}}{\text{总样本数}}$
   - 对于离散特征：$P(x_i|c) = \frac{\text{类别 } c \text{ 中特征 } i \text{ 取值为 } x_i \text{ 的样本数}}{\text{类别 } c \text{ 的样本数}}$
   - 对于连续特征：通常假设服从高斯分布 $N(\mu_{ci}, \sigma_{ci}^2)$

2. **预测阶段**：对新样本 $\mathbf{x}$，计算各类别的 $P(c)\prod P(x_i|c)$，选择最大值对应的类别

**示例 1.13（垃圾邮件分类）**：
- 类别：垃圾邮件（Spam）、正常邮件（Ham）
- 特征：邮件中是否包含某些关键词（如"免费"、"中奖"等）

假设训练数据如下：
- 总邮件数：1000封，其中垃圾邮件400封，正常邮件600封
- 在垃圾邮件中，"免费"出现300次，"中奖"出现200次
- 在正常邮件中，"免费"出现50次，"中奖"出现10次

先验概率：
$$P(Spam) = 0.4, \quad P(Ham) = 0.6$$

条件概率：
$$P(免费|Spam) = \frac{300}{400} = 0.75, \quad P(中奖|Spam) = \frac{200}{400} = 0.5$$
$$P(免费|Ham) = \frac{50}{600} \approx 0.083, \quad P(中奖|Ham) = \frac{10}{600} \approx 0.017$$

对一封同时包含"免费"和"中奖"的邮件：
$$P(Spam)P(免费|Spam)P(中奖|Spam) = 0.4 \times 0.75 \times 0.5 = 0.15$$
$$P(Ham)P(免费|Ham)P(中奖|Ham) \approx 0.6 \times 0.083 \times 0.017 \approx 0.00085$$

由于 $0.15 > 0.00085$，因此该邮件被分类为垃圾邮件。

**朴素贝叶斯的优缺点**：
- 优点：算法简单、计算高效、对缺失数据鲁棒
- 缺点：条件独立性假设在实际中往往不成立，可能影响分类精度
