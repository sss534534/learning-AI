## 4.1 常微分方程的基本概念

### 4.1.1 微分方程与解

**定义 4.1.1** 含有未知函数及其导数（或微分）的方程称为**微分方程**。如果未知函数是一元函数，则称为**常微分方程**（Ordinary Differential Equation, ODE）；如果未知函数是多元函数，则称为**偏微分方程**。

**定义 4.1.2** 微分方程中出现的未知函数导数的最高阶数称为微分方程的**阶**。n阶微分方程的一般形式为：
$$F(x, y, y', y'', \dots, y^{(n)}) = 0$$

**定义 4.1.3** 设函数 $y = \varphi(x)$ 在区间 $I$ 上具有连续的 $n$ 阶导数，如果将 $y = \varphi(x)$ 代入微分方程后，方程在 $I$ 上成为恒等式，则称 $y = \varphi(x)$ 为微分方程在区间 $I$ 上的**解**。

### 4.1.2 通解与特解

**定义 4.1.4** 如果n阶微分方程的解中含有 $n$ 个相互独立的任意常数，则称此解为该微分方程的**通解**。通解的一般形式为：
$$y = \varphi(x, C_1, C_2, \dots, C_n)$$

**定义 4.1.5** 确定了通解中任意常数的解称为**特解**。

**例 4.1.1** 验证 $y = Cx^2$ 是微分方程 $xy' = 2y$ 的通解，并求满足 $y(1) = 2$ 的特解。

**解**：求导得 $y' = 2Cx$，代入方程左边得：
$$xy' = x \cdot 2Cx = 2Cx^2 = 2y$$
因此 $y = Cx^2$ 是解，且含有一个任意常数，故为通解。
代入初始条件 $y(1) = 2$，得 $2 = C \cdot 1^2 \implies C = 2$，故特解为 $y = 2x^2$。

### 4.1.3 初始条件与初值问题

**定义 4.1.6** 用于确定通解中任意常数的条件称为**定解条件**，最常见的是**初始条件**：
$$y(x_0) = y_0, \quad y'(x_0) = y_0', \quad \dots, \quad y^{(n-1)}(x_0) = y_0^{(n-1)}$$

**定义 4.1.7** 求微分方程满足初始条件的特解的问题称为**初值问题**。

## 4.2 一阶微分方程解法

### 4.2.1 可分离变量的微分方程

**定义 4.2.1** 形如
$$\frac{dy}{dx} = f(x)g(y)$$
的微分方程称为**可分离变量的微分方程**。

**解法步骤**：
1. 分离变量：$\frac{dy}{g(y)} = f(x)dx \quad (g(y) \neq 0)$
2. 两边积分：$\int \frac{dy}{g(y)} = \int f(x)dx + C$

**例 4.2.1** 求解微分方程 $\frac{dy}{dx} = 2xy$。

**解**：分离变量得：
$$\frac{dy}{y} = 2x dx \quad (y \neq 0)$$
两边积分：
$$\int \frac{dy}{y} = \int 2x dx + C \implies \ln|y| = x^2 + C$$
整理得：
$$y = \pm e^{x^2 + C} = \pm e^C e^{x^2} = C_1 e^{x^2}$$
其中 $C_1 = \pm e^C$ 为任意常数。当 $C_1 = 0$ 时，$y = 0$ 也是解，故通解为 $y = C e^{x^2}$。

### 4.2.2 齐次方程

**定义 4.2.2** 形如
$$\frac{dy}{dx} = f\left(\frac{y}{x}\right)$$
的微分方程称为**齐次方程**。

**解法步骤**：
1. 作变量代换 $u = \frac{y}{x}$，即 $y = ux$
2. 求导得 $\frac{dy}{dx} = u + x\frac{du}{dx}$
3. 代入原方程，化为可分离变量方程：$u + x\frac{du}{dx} = f(u)$
4. 分离变量：$\frac{du}{f(u) - u} = \frac{dx}{x}$
5. 积分后回代 $u = \frac{y}{x}$

**例 4.2.2** 求解微分方程 $\frac{dy}{dx} = \frac{y}{x} + \tan\left(\frac{y}{x}\right)$。

**解**：令 $u = \frac{y}{x}$，则 $y = ux$，$\frac{dy}{dx} = u + x\frac{du}{dx}$，代入得：
$$u + x\frac{du}{dx} = u + \tan u \implies x\frac{du}{dx} = \tan u$$
分离变量：
$$\cot u \, du = \frac{dx}{x}$$
积分得：
$$\ln|\sin u| = \ln|x| + C \implies \sin u = Cx$$
回代得通解：
$$\sin\left(\frac{y}{x}\right) = Cx$$

### 4.2.3 一阶线性微分方程

**定义 4.2.3** 形如
$$\frac{dy}{dx} + P(x)y = Q(x)$$
的微分方程称为**一阶线性微分方程**。当 $Q(x) \equiv 0$ 时称为**齐次线性方程**，否则称为**非齐次线性方程**。

**齐次线性方程解法**：可分离变量，通解为：
$$y = C e^{-\int P(x)dx}$$

**非齐次线性方程解法——常数变易法**：
1. 先求齐次方程通解 $y = C e^{-\int P(x)dx}$
2. 将常数 $C$ 换为函数 $C(x)$，即设 $y = C(x) e^{-\int P(x)dx}$
3. 求导代入原方程得：$C'(x) = Q(x) e^{\int P(x)dx}$
4. 积分得 $C(x) = \int Q(x) e^{\int P(x)dx} dx + C$
5. 通解为：
$$y = e^{-\int P(x)dx} \left( \int Q(x) e^{\int P(x)dx} dx + C \right)$$

**例 4.2.3** 求解微分方程 $\frac{dy}{dx} + \frac{1}{x}y = \frac{\sin x}{x}$。

**解**：此为一阶线性方程，$P(x) = \frac{1}{x}$，$Q(x) = \frac{\sin x}{x}$。
计算：
$$\int P(x)dx = \int \frac{1}{x}dx = \ln|x|$$
$$e^{\int P(x)dx} = x, \quad e^{-\int P(x)dx} = \frac{1}{x}$$
代入通解公式：
$$y = \frac{1}{x} \left( \int \frac{\sin x}{x} \cdot x \, dx + C \right) = \frac{1}{x} \left( -\cos x + C \right)$$

### 4.2.4 伯努利方程

**定义 4.2.4** 形如
$$\frac{dy}{dx} + P(x)y = Q(x)y^n \quad (n \neq 0, 1)$$
的微分方程称为**伯努利方程**。

**解法步骤**：
1. 两边除以 $y^n$：$y^{-n}\frac{dy}{dx} + P(x)y^{1-n} = Q(x)$
2. 令 $z = y^{1-n}$，则 $\frac{dz}{dx} = (1-n)y^{-n}\frac{dy}{dx}$
3. 化为一阶线性方程：$\frac{1}{1-n}\frac{dz}{dx} + P(x)z = Q(x)$
4. 解出 $z$ 后回代

**例 4.2.4** 求解微分方程 $\frac{dy}{dx} + \frac{1}{x}y = x^2 y^6$。

**解**：两边除以 $y^6$：
$$y^{-6}\frac{dy}{dx} + \frac{1}{x}y^{-5} = x^2$$
令 $z = y^{-5}$，则 $\frac{dz}{dx} = -5y^{-6}\frac{dy}{dx}$，代入得：
$$-\frac{1}{5}\frac{dz}{dx} + \frac{1}{x}z = x^2 \implies \frac{dz}{dx} - \frac{5}{x}z = -5x^2$$
这是一阶线性方程，解得：
$$z = x^5 \left( -\frac{5}{2}x^{-2} + C \right) = -\frac{5}{2}x^3 + C x^5$$
回代得通解：
$$y^{-5} = -\frac{5}{2}x^3 + C x^5 \implies y = \left( -\frac{5}{2}x^3 + C x^5 \right)^{-1/5}$$

### 4.2.5 全微分方程

**定义 4.2.5** 如果微分方程
$$P(x, y)dx + Q(x, y)dy = 0$$
的左端是某个函数 $u(x, y)$ 的全微分，即 $du = Pdx + Qdy$，则称其为**全微分方程**。

**判别条件**：在单连通区域内，方程为全微分方程当且仅当
$$\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$$

**解法**：求原函数 $u(x, y)$，通解为 $u(x, y) = C$。求 $u(x, y)$ 的方法：
1. 曲线积分法：$u(x, y) = \int_{x_0}^x P(x, y_0)dx + \int_{y_0}^y Q(x, y)dy$
2. 不定积分法

**例 4.2.5** 求解 $(3x^2 + 6xy^2)dx + (6x^2y + 4y^3)dy = 0$。

**解**：验证：$\frac{\partial P}{\partial y} = 12xy = \frac{\partial Q}{\partial x}$，故为全微分方程。
求原函数：
$$u(x, y) = \int_0^x 3x^2 dx + \int_0^y (6x^2y + 4y^3)dy = x^3 + 3x^2y^2 + y^4$$
通解为 $x^3 + 3x^2y^2 + y^4 = C$。

## 4.3 可降阶的高阶微分方程

### 4.3.1 $y^{(n)} = f(x)$ 型

**解法**：连续积分n次。

**例 4.3.1** 求解 $y''' = e^{2x} - \cos x$。

**解**：第一次积分：
$$y'' = \frac{1}{2}e^{2x} - \sin x + C_1$$
第二次积分：
$$y' = \frac{1}{4}e^{2x} + \cos x + C_1 x + C_2$$
第三次积分：
$$y = \frac{1}{8}e^{2x} + \sin x + \frac{C_1}{2}x^2 + C_2 x + C_3$$

### 4.3.2 $y'' = f(x, y')$ 型

**特点**：不显含y。

**解法**：令 $p = y'$，则 $y'' = p'$，方程化为一阶方程 $p' = f(x, p)$。

**例 4.3.2** 求解 $(1 + x^2)y'' = 2xy'$。

**解**：令 $p = y'$，则 $p' = y''$，方程化为：
$$(1 + x^2)p' = 2xp$$
分离变量积分得：
$$\ln|p| = \ln(1 + x^2) + C \implies p = C_1(1 + x^2)$$
即 $y' = C_1(1 + x^2)$，再积分得：
$$y = C_1\left(x + \frac{1}{3}x^3\right) + C_2$$

### 4.3.3 $y'' = f(y, y')$ 型

**特点**：不显含x。

**解法**：令 $p = y'$，则 $y'' = p\frac{dp}{dy}$，方程化为一阶方程 $p\frac{dp}{dy} = f(y, p)$。

**例 4.3.3** 求解 $y y'' - (y')^2 = 0$。

**解**：令 $p = y'$，则 $y'' = p\frac{dp}{dy}$，方程化为：
$$y p \frac{dp}{dy} - p^2 = 0$$
当 $p \neq 0$ 时，约去 $p$ 得：
$$y \frac{dp}{dy} = p$$
分离变量积分得：
$$\ln|p| = \ln|y| + C \implies p = C_1 y$$
即 $y' = C_1 y$，解得 $y = C_2 e^{C_1 x}$。
当 $p = 0$ 时，$y = C$ 也是解，包含在通解中（$C_1 = 0$）。

## 4.4 线性微分方程解的结构

### 4.4.1 n阶线性微分方程

**定义 4.4.1** n阶线性微分方程的一般形式为：
$$y^{(n)} + P_1(x)y^{(n-1)} + \dots + P_{n-1}(x)y' + P_n(x)y = Q(x)$$
当 $Q(x) \equiv 0$ 时称为**齐次线性方程**，否则称为**非齐次线性方程**。

### 4.4.2 函数的线性相关性

**定义 4.4.2** 设函数 $y_1(x), y_2(x), \dots, y_n(x)$ 在区间 $I$ 上有定义，如果存在不全为零的常数 $k_1, k_2, \dots, k_n$，使得
$$k_1 y_1(x) + k_2 y_2(x) + \dots + k_n y_n(x) \equiv 0, \quad x \in I$$
则称这n个函数在 $I$ 上**线性相关**，否则称为**线性无关**。

**朗斯基行列式**：对于n个n-1阶可导函数，定义
$$W(x) = \begin{vmatrix}
y_1 & y_2 & \dots & y_n \\
y_1' & y_2' & \dots & y_n' \\
\vdots & \vdots & & \vdots \\
y_1^{(n-1)} & y_2^{(n-1)} & \dots & y_n^{(n-1)}
\end{vmatrix}$$
如果 $W(x) \not\equiv 0$，则函数组线性无关。

### 4.4.3 齐次线性方程解的结构

**定理 4.4.1**（叠加原理）如果 $y_1, y_2$ 是齐次线性方程的解，则它们的线性组合 $y = C_1 y_1 + C_2 y_2$ 也是解。

**定理 4.4.2** n阶齐次线性方程必有n个线性无关的解。如果 $y_1, y_2, \dots, y_n$ 是n个线性无关的解，则通解为
$$y = C_1 y_1 + C_2 y_2 + \dots + C_n y_n$$

### 4.4.4 非齐次线性方程解的结构

**定理 4.4.3** 如果 $y^*$ 是非齐次线性方程的一个特解，$Y$ 是对应齐次方程的通解，则非齐次方程的通解为
$$y = Y + y^*$$

**定理 4.4.4**（叠加原理）如果 $y_1^*$ 是方程 $y^{(n)} + \dots = Q_1(x)$ 的特解，$y_2^*$ 是方程 $y^{(n)} + \dots = Q_2(x)$ 的特解，则 $y_1^* + y_2^*$ 是方程 $y^{(n)} + \dots = Q_1(x) + Q_2(x)$ 的特解。

## 4.5 二阶常系数线性微分方程解法

### 4.5.1 二阶常系数齐次线性微分方程

**一般形式**：
$$y'' + p y' + q y = 0$$
其中 $p, q$ 为常数。

**特征方程法**：
1. 写出特征方程：$r^2 + p r + q = 0$
2. 求解特征根 $r_1, r_2$

**分三种情况讨论**：

**情形1** 两个不相等的实根 $r_1 \neq r_2$
通解为：
$$y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$$

**情形2** 两个相等的实根 $r_1 = r_2 = r$
通解为：
$$y = (C_1 + C_2 x) e^{r x}$$

**情形3** 一对共轭复根 $r_{1,2} = \alpha \pm i\beta$
通解为：
$$y = e^{\alpha x} (C_1 \cos \beta x + C_2 \sin \beta x)$$

**例 4.5.1** 求解 $y'' - 2y' - 3y = 0$。

**解**：特征方程 $r^2 - 2r - 3 = 0$，根为 $r_1 = 3, r_2 = -1$，通解为：
$$y = C_1 e^{3x} + C_2 e^{-x}$$

**例 4.5.2** 求解 $y'' + 2y' + y = 0$。

**解**：特征方程 $r^2 + 2r + 1 = 0$，根为 $r_1 = r_2 = -1$，通解为：
$$y = (C_1 + C_2 x) e^{-x}$$

**例 4.5.3** 求解 $y'' + 4y = 0$。

**解**：特征方程 $r^2 + 4 = 0$，根为 $r_{1,2} = \pm 2i$，通解为：
$$y = C_1 \cos 2x + C_2 \sin 2x$$

### 4.5.2 二阶常系数非齐次线性微分方程

**一般形式**：
$$y'' + p y' + q y = f(x)$$

**解法**：通解 = 对应齐次方程通解 + 非齐次方程特解。求特解常用**待定系数法**，根据 $f(x)$ 的形式设特解形式：

**类型1** $f(x) = P_m(x) e^{\lambda x}$
设特解为 $y^* = x^k Q_m(x) e^{\lambda x}$，其中
- $k = 0$，若 $\lambda$ 不是特征根
- $k = 1$，若 $\lambda$ 是单特征根
- $k = 2$，若 $\lambda$ 是重特征根
$Q_m(x)$ 为与 $P_m(x)$ 同次的多项式。

**例 4.5.4** 求解 $y'' - 2y' - 3y = 3x + 1$。

**解**：齐次通解为 $Y = C_1 e^{3x} + C_2 e^{-x}$。设特解 $y^* = ax + b$，代入得：
$$-2a - 3(ax + b) = 3x + 1 \implies -3a = 3, -2a - 3b = 1$$
解得 $a = -1, b = \frac{1}{3}$，故 $y^* = -x + \frac{1}{3}$，通解为：
$$y = C_1 e^{3x} + C_2 e^{-x} - x + \frac{1}{3}$$

**类型2** $f(x) = e^{\alpha x} [P_l(x) \cos \beta x + Q_n(x) \sin \beta x]$
设特解为 $y^* = x^k e^{\alpha x} [R_m^{(1)}(x) \cos \beta x + R_m^{(2)}(x) \sin \beta x]$，其中 $m = \max(l, n)$，
- $k = 0$，若 $\alpha \pm i\beta$ 不是特征根
- $k = 1$，若 $\alpha \pm i\beta$ 是特征根

**例 4.5.5** 求解 $y'' + 4y = x \cos 2x$。

**解**：齐次通解为 $Y = C_1 \cos 2x + C_2 \sin 2x$。由于 $\pm 2i$ 是特征根，设特解：
$$y^* = x [(ax + b) \cos 2x + (cx + d) \sin 2x]$$
代入方程比较系数，求得特解后通解为：
$$y = C_1 \cos 2x + C_2 \sin 2x + \frac{x^2}{8} \cos 2x + \frac{x}{16} \sin 2x$$

## 4.6 微分方程在AI中的应用

### 4.6.1 梯度流

**定义** 设 $L(\theta)$ 是损失函数，参数更新的梯度流方程为：
$$\frac{d\theta}{dt} = -\nabla L(\theta)$$
离散化后得到梯度下降算法：
$$\theta_{t+1} = \theta_t - \eta_t \nabla L(\theta_t)$$
其中 $\eta_t$ 为学习率。

**连续时间分析** 对于强凸函数，梯度流指数收敛到最优解。设 $\mu$-强凸，即 $\nabla^2 L \succeq \mu I$，则有：
$$\frac{d}{dt} \|\theta(t) - \theta^*\|^2 \leq -2\mu \|\theta(t) - \theta^*\|^2$$
因此 $\|\theta(t) - \theta^*\| \leq \|\theta(0) - \theta^*\| e^{-\mu t}$。

### 4.6.2 扩散模型与随机微分方程

**扩散过程** 扩散模型的前向过程由随机微分方程（SDE）描述：
$$dx = -\frac{\beta(t)}{2} x dt + \sqrt{\beta(t)} dw$$
其中 $\beta(t)$ 为噪声调度，$w$ 为维纳过程。

**逆向过程** 生成过程是逆向SDE：
$$dx = \left[ -\frac{\beta(t)}{2} x - \beta(t) \nabla_x \log p_t(x) \right] dt + \sqrt{\beta(t)} dw$$

**概率流ODE** 对应于SDE的确定性常微分方程：
$$\frac{dx}{dt} = -\frac{\beta(t)}{2} x - \frac{\beta(t)}{2} \nabla_x \log p_t(x)$$
通过数值求解该ODE可以从高斯噪声生成数据。

### 4.6.3 物理约束神经网络（PINNs）

**基本思想** 训练神经网络同时拟合数据和满足物理定律（微分方程）。

**损失函数** 设神经网络 $u_\theta(x, t)$ 为解的近似，损失函数为：
$$L(\theta) = L_{\text{data}} + L_{\text{PDE}} + L_{\text{BC/IC}}$$
其中：
- $L_{\text{data}} = \sum \|u_\theta(x_i, t_i) - u_i\|^2$ 为数据拟合损失
- $L_{\text{PDE}} = \sum \|F(x_j, t_j, u_\theta, \nabla u_\theta, \nabla^2 u_\theta)\|^2$ 为PDE残差
- $L_{\text{BC/IC}}$ 为边界/初始条件损失

**自动微分** 利用自动微分计算 $u_\theta$ 对 $x, t$ 的导数，无需数值微分。

**应用领域** 流体力学、电磁学、量子力学等工程和科学计算问题，特别适用于高维偏微分方程求解。
