🧠 注意力机制 (Attention Mechanism)

核心思想：注意力机制允许模型在处理序列数据时，自动学习关注输入的不同部分。 通过计算Query、Key、Value的相似度，模型可以动态地分配"注意力"权重。

Attention(Q, K, V) = softmax(QK^T / √d) × V
Q、K、V 分别表示查询、键、值向量 | d 是向量维度 | 通过点积计算相似度，经过Softmax归一化

📊 Scaled Dot-Product Attention

score(q, k) = q · k^T / √d

使用点积计算注意力分数，除以√d防止梯度消失

📈 Softmax 归一化

αᵢ = exp(scoreᵢ) / Σⱼexp(scoreⱼ)

将分数转换为概率分布，所有权重和为1

🔗 Multi-Head Attention

MultiHead = Concat(head₁,...,headₕ)W⁰

多个注意力头并行学习不同类型的依赖关系

📐 位置编码 (Positional Encoding)

PE(pos,2i) = sin(pos/100002i/d)
PE(pos,2i+1) = cos(pos/100002i/d)

使用正弦和余弦函数编码位置信息，支持任意长度的序列

🔧 Layer Normalization

LN(x) = γ ⊙ (x-μ)/√(σ²+ε) + β

对每一层的输出进行归一化，稳定训练过程

📉 梯度下降优化

核心思想：梯度下降通过迭代优化，在损失函数的负梯度方向上更新参数， 逐步逼近全局或局部最优解。学习率和优化策略的选择对收敛速度和最终性能至关重要。
学习率: 0.1

🎯 参数更新规则

θ = θ - α · ∇J(θ)

α是学习率，∇J(θ)是损失函数的梯度

⚡ Adam优化器

mt = β₁mt-1 + (1-β₁)gt
θt+1 = θt - α·m̂t/(√v̂t+ε)

自适应学习率优化器，结合动量和二阶矩估计

🔄 扩散模型 (Diffusion Model)

核心思想：扩散模型通过一个前向过程逐步向数据添加噪声， 然后学习逆向过程从噪声中恢复原始数据。扩散模型已成为图像生成的主流方法。

➕ 前向过程

q(xt|xt-1) = 𝒩(√(1-βt)xt-1, βtI)

逐步向数据添加高斯噪声，最终变为纯噪声

➖ 逆向过程

pθ(xt-1|xt) = 𝒩(μθ(xt,t), Σθ(xt,t))

学习从噪声恢复数据的过程

🎭 MoE混合专家架构

核心思想：混合专家模型通过门控网络动态选择激活的专家子集， 在保持大量参数的同时实现稀疏激活，大幅提升计算效率。
Top-K: 2

🚪 门控网络

G(x) = softmax(Wgx + bg)

计算每个专家的激活权重

🔀 稀疏激活

y = Σi∈TopK(G(x)) G(x)i · Ei(x)

只激活权重最高的K个专家
