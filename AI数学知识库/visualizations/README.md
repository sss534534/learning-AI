## 🎨 可视化模块

### 1. 注意力机制可视化

**核心内容：**
- QKV计算流程
- Scaled Dot-Product Attention
- Softmax归一化
- Multi-Head Attention并行结构

**关键公式：**
```
Attention(Q,K,V) = softmax(QK^T / √d) × V
```

**交互功能：**
- 点击token查看注意力权重
- 热力图展示注意力分布

---

### 2. Transformer架构可视化

**核心内容：**
- 编码器结构（Input Embedding → MHA → FFN → Output）
- 解码器结构（Masked MHA → Cross Attention → FFN）
- 残差连接与层归一化

**关键公式：**
```
PE(pos,2i) = sin(pos / 10000^(2i/d))
LN(x) = γ ⊙ (x - μ) / √(σ² + ε) + β
```

---

### 3. 梯度下降可视化

**核心内容：**
- 不同学习率的影响（过小/适中/过大）
- 优化器收敛速度对比
- Adam优化器更新公式

**关键公式：**
```
θ_{t+1} = θ_t - α · ∇J(θ_t)  (SGD)
m_t = β₁m_{t-1} + (1-β₁)g_t   (Adam)
```

**交互功能：**
- 滑块调节学习率
- 实时动画展示优化轨迹

---

### 4. 扩散模型可视化

**核心内容：**
- 前向扩散过程（逐步添加噪声）
- 逆向去噪过程（逐步恢复数据）
- 噪声调度对比（线性/余弦/Sigmoid）
- DDPM训练-采样流程

**关键公式：**
```
q(x_t | x_{t-1}) = N(√(1-β_t)x_{t-1}, β_tI)
p_θ(x_{t-1}|x_t) = N(μ_θ(x_t,t), Σ_θ(x_t,t))
```

**交互功能：**
- 观察噪声逐渐增加/去除的效果
- 对比不同噪声调度策略

---

### 5. MoE架构可视化

**核心内容：**
- 稀疏激活机制
- 门控网络路由
- 专家特化现象
- 负载均衡重要性

**关键公式：**
```
G(x) = softmax(W_g · x + b_g)
y = Σ_{i∈TopK(G(x))} G(x)_i · E_i(x)
```

**交互功能：**
- 调节Top-K参数
- 观察专家激活状态

---

### 6. 对比学习可视化

**核心内容：**
- InfoNCE损失函数
- 正负样本分布
- 嵌入空间可视化
- CLIP图文对齐

**关键公式：**
```
L = -log[exp(sim(q,k⁺)/τ) / Σ_j exp(sim(q,k_j)/τ)]
```

**交互功能：**
- 观察正负样本分布
- 理解温度参数影响

## 🛠️ 使用方法

### 方法一：直接打开HTML

```bash
# 在浏览器中直接打开
open index.html
# 或
python -m http.server 8000
# 然后访问 http://localhost:8000
```

### 方法二：生成PNG图表

```bash
# 需要安装依赖
pip install numpy matplotlib

# 运行生成脚本
python generate_visualizations.py

# 生成的图表将保存在当前目录
```
