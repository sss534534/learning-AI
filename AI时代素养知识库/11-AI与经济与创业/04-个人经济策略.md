### 三层收入结构

```
                    ┌──────────────────────┐
                    │  核心收入 (Core)      │  ← 基础保障，覆盖生活成本

                    │  × AI增强效率         │
                    │  (自动化30-50%工作流)  │
                    └──────────┬───────────┘
                               │
                    ┌──────────▼───────────┐
                    │  组合收入 (Portfolio) │  ← 增长引擎，净自由
                    │  ├─ 咨询/培训        │     权重：20-30%
                    │  ├─ 数字产品(模板/课程)│
                    │  ├─ 内容变现          │
                    │  └─ 微型SaaS/工具     │
```

### 关键推论

```
AI时代个人投资优先级:
1️⃣ 人力资本（AI技能） >> 2️⃣ 收入多元化 >> 3️⃣ 传统资产配置

理由:
- AI正在重塑所有行业的价值分配，谁更会用AI，谁就获得更多份额
- 传统资产的回报率正在下降（利率下行+AI冲击），而AI技能的溢价在上升
- 人力资本是唯一可以产生"主动复利"的资产（技能叠加产生指数效应）
- 算力是一种新资产类别，类似90年代的"带宽"，早期投入红利巨大
```

### 核心风险管理原则

```
1. 逆摩尔定律避险
   摩尔定律使算力每18月翻倍 → 你的AI技能必须每18月重新评估。
   半衰期超过2年的技能，视为"防御型"，不能作为唯一筹码。

2. 对冲原则
   任何单一押注（公司/工具/平台/技能）都不超过总"资产"的40%。
   AI时代变化速度使传统"长期持有"策略失效，需动态再平衡。

3. 期权思维
   用最小成本获取未来可能高价值的选择权：
   - 花10h学一个新AI工具 → 获取"未来能用它高效工作"的期权
   - 花¥1000买个AI课程 → 获取"进入一个新领域"的期权
   - 花周末做个MVP → 获取"验证一个创业想法"的期权
   
4. 尾部风险防范
   小概率但毁灭性事件：
   - AI能力奇点式跃升 → 你所在的岗位突然消失
   - 单一AI平台垄断 → 你依赖的技能栈一夜贬值
   - 数据隐私泄露 → 你的数字分身被滥用
   
   应对：保持流动性（现金+时间余量），不要过度杠杆

5. 反脆弱配置
   从波动中受益而非受损：
   - 建立"AI x 你的领域"的独特组合 → 变化越大，你的价值越高
   - 公开构建（Building in Public） → 积累的受众是波动中的资产
   - 多项目并行 → 大多数失败，但幸存者收益覆盖所有损失
```
