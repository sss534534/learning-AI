# 深度伪造与真实性验证

## Deepfake 的现状

| 模态 | 代表技术 | 检测准确率 | 对人类欺骗率 |
|------|---------|-----------|------------|
| 文本 | GPT-4/Claude/Llama | 50-70%（接近随机） | > 80%（不看来源） |
| 图像 | Midjourney/Stable Diffusion/DALL·E | ~60-80%（新模型持续降低） | > 90%（普通人） |
| 音频 | 实时语音克隆（11Labs/PlayHT） | ~70-85% | > 80%（短音频） |
| 视频 | FaceSwap/Wav2Lip/视频生成 | ~60-75% | > 70%（非对口型场景） |

### 关键趋势

- **检测技术永远落后于生成技术**：生成 SOTA 迭代周期 ~3 个月，检测 SOTA 迭代周期 ~6-12 个月
- **跨模态伪造**：文字描述 → 图像 → 语音 → 视频，全链条可在 5 分钟内完成
- **个性化定制**：用目标人物的 30 秒语音即可克隆其声音，60 秒视频即可重演其面部

## "说谎者红利"（Liar's Dividend）

### 定义

当 AI 可以伪造一切时，说真话的人也可以声称"这是 AI 伪造的"。

### 运行机制

```
真实事件发生 → 负面证据曝光 → "这是 AI 伪造的" → 证据有效性被质疑
                      ↑
                这就是"说谎者红利"
```

### 典型案例场景

| 场景 | 真实事件 | AI 伪造的"便利" |
|------|---------|----------------|
| 政治丑闻 | 确凿录音/视频证据 | 当事人声称"这是 AI 伪造的" |
| 新闻事件 | 目击者拍摄的视频 | 被质疑"太像 AI 生成的了" |
| 法律证据 | 关键聊天记录/邮件 | 对方声称对话是 AI 生成的 |
| 学术争议 | 论文数据真实性 | 作者声称数据是 AI 误处理 |

### 影响

- 事实本身的地位被动摇 → 人们不再相信任何东西
- "真相后"时代：不是真相不存在，而是**信任真相的机制被破坏了**
- 长期后果：共识丧失、社会对话崩解、极端观点盛行

## 个人验证框架（四步验证法）

```
L1 来源追溯
   ┃ 谁发布的？原始来源在哪里？是否有可信的发布历史？
   ┃ 找到"最初发布者"，而不是"转述者"
   ▼
L2 多方交叉
   ┃ 至少 3 个独立来源能否确认同一事实？
   ┃ 确认这些来源之间"不是互相引用的"
   ▼
L3 逻辑校验
   ┃ 内容内部逻辑是否自洽？与已知事实是否冲突？
   ┃ 如果"太好"或"太坏"，暂停一下
   ▼
L4 工具辅助
   ┃ 用 AI 检测工具检查（但不要过度信任它们）
   ┃ 工具只是辅助，不是最终判断依据
```

### 各层级的具体操作

| 层级 | 具体操作 | 耗时 | 可靠性 |
|------|---------|------|-------|
| L1 | 查域名 WHOIS、查作者历史、查账号创建时间 | 1-3 分钟 | 中等 |
| L2 | 谷歌/百度搜索关键词、交叉对比来源 | 3-10 分钟 | 高 |
| L3 | 检查逻辑漏洞、联想已知事实、寻找异常 | 2-5 分钟 | 中等 |
| L4 | 使用 GPTZero/Originality.ai 等检测器 | 1 分钟 | 低-中 |

## 可信度评分卡（实操工具）

| 评估维度 | 评分 (1-5) | 说明 |
|---------|----------|------|
| 来源可信度 | | 发布者的历史记录、声誉、一贯性 |
| 独立验证 | | 其他来源的支持程度（非互相引用） |
| 内部一致性 | | 内容逻辑是否自洽、时间线是否合理 |
| 与已知事实一致 | | 不与已确认的事实冲突 |
| 动机分析 | | 发布者是否有 bias、利益冲突 |

### 评分总表

| 总分 | 判断 | 行动建议 |
|------|------|---------|
| 20-25 | 基本可信 | 可以引用，但保持跟踪 |
| 15-19 | 较可信 | 可参考，建议关注更新 |
| 10-14 | 存疑 | 参考但不要转发/引用，需要更多验证 |
| 5-9 | 高度怀疑 | 大概率不可信，建议忽略 |
| < 5 | 极不可信 | 可能是伪造，可作为训练案例 |

### 使用技巧

- 不要一次性打出所有分数，逐项评估
- 对"动机分析"保持敏感——这是大多数人忽略的维度
- 评分是参考，不是绝对标准——20 分的内容也可能是假的
- 习惯化：遇到"与你观点一致且情绪化"的内容时，**自动触发评分流程**

**核心信条**：AI 时代，不是"看到就不相信"，而是"确认之前不轻信"。
