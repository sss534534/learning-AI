# 技术选型思维框架

## 核心原则

**不是"哪个模型最好"，是"哪个模型最适合这个任务"。**

- 就像你不会用瑞士军刀去砍树，也不会用伐木锯去开红酒
- AI 模型之间是"工具差异"，不是"好坏差异"
- 选型的目标是：**性价比最高的好结果**

## 选型决策树

```
🗺️ 任务是什么类型？
│
├── 📝 文本生成/对话
│   ├── 日常使用（邮件、会议记录、脑暴）
│   │   └── GPT-4o mini / Claude Haiku / DeepSeek ✅（低成本，快速）
│   └── 专业写作/分析（报告、论文、策略）
│       └── Claude 4 / GPT-4o / o3 ✅（高质量，严谨）
│
├── 💻 编程
│   ├── Python / 通用 / 前端 → Claude 3.5/4 Sonnet ✅
│   ├── 大型项目重构 → Claude + 全项目索引 ✅
│   └── 特定框架（React/Spring Boot 等）→ 加 RAG + 框架文档 ✅
│
├── 🧮 推理/数学/逻辑
│   ├── 简单逻辑 → Claude / GPT-4o 即可 ✅
│   └── 复杂推理/证明 → o1/o3 / Claude 推理模式 ✅（但慢，成本高）
│
├── 🎨 图像生成
│   ├── 设计/艺术 → Midjourney ✅（质量最高）
│   ├── 写实/产品图 → DALL-E 3 / Flux ✅
│   └── 批量/可控 → Stable Diffusion ✅（开源，可定制）
│
└── 👁️ 多模态理解
    └── GPT-4o / Gemini ✅（图像、PDF、图表、视频分析）
```

## 选型考虑因素表

| 因素 | 说明 | 问自己的问题 |
|------|------|-------------|
| **能力匹配** | 模型能否胜任这个任务 | 它在该领域的 benchmark 排名如何？有没有已知的弱点？ |
| **成本** | API 调用费用或订阅费 | 每天调用多少次？每次用多少 token？免费额度够用吗？ |
| **延迟** | 响应速度要求 | 需要实时对话还是可以等 10 秒？推理模型（o1）比普通模型慢 5-10 倍 |
| **隐私** | 数据是否涉及敏感信息 | 数据能上传到云端吗？是否需要本地部署？公司政策允许吗？ |
| **上下文长度** | 需要处理多少输入信息 | 任务需要读 10 页文档还是 200 页？长上下文模型更贵但可能省事 |
| **生态** | 周边工具/社区支持 | 有好的 IDE 插件吗？API SDK 完善吗？中文社区活跃吗？ |


## 四个常见选型陷阱

| 陷阱 | 表现 | 正确做法 |
|------|------|---------|
| 🕳️ **瑞士军刀幻觉** | 试图用一个模型做所有事 | 不同任务用不同模型，混搭最划算 |
| 🕳️ **唯 Benchmark 论** | 只看评分不看实际场景 | Benchmark 仅供参考，最终用实际任务测试 |
| 🕳️ **忽视成本** | 全用量产旗舰模型 | 白天旗舰 + 晚上/批量用低成本模型 |
| 🕳️ **一选定终身** | 选了一个模型就不再看其他 | 每季度重新评估，这个领域变化极快 |

## 什么时候选择"不够好"的模型

**"够用"原则：不要为 95% 的场景优化那 5% 的差异。**

考虑用低成本模型的场景：
- ✅ 内部工具/原型验证（先跑起来再说）
- ✅ 翻译、摘要、分类等结构化任务（不需要创造力）
- ✅ 大量批量处理（成本敏感）
- ✅ 用户不会直接看到输出的场景（后台处理）

坚持用旗舰模型的场景：
- ❌ 客户面对的产品（质量直接影响口碑）
- ❌ 高风险的决策支持（医疗、法律、金融）
- ❌ 需要深度推理、多步分析的任务
- ❌ 创意类工作（文案、广告、品牌）

### 混搭策略示例

```
一个客服系统的 AI 层：
├── 80% 的简单咨询 → GPT-4o mini（每次 $0.0002）
├── 15% 的中等复杂 → Claude Sonnet（每次 $0.004）
└── 5% 的复杂投诉 → o1 / Claude 4（每次 $0.015）

平均每次成本：$0.0002×0.8 + $0.004×0.15 + $0.015×0.05 = $0.0015
相比全部用旗舰（$0.015）：成本降低 90%，用户体验几乎没有差异
```

## 快速选型清单

决定前问自己这 5 个问题：

- [ ] 这个任务对**准确性**的要求有多高？（关键场景必须用旗舰）
- [ ] **延迟**容忍度是多少？（实时还是异步？）
- [ ] **预算**是什么量级？（每月几十还是几万？）
- [ ] **数据隐私**的要求？（能否上云？是否需要私有部署？）
- [ ] **需要频繁切换模型**吗？（还是固定一个就行？）

## 总结

1. **工具思维，而非崇拜思维**——模型是工具，选适合任务的
2. **混搭降低成本**——旗舰模型处理关键任务，小型模型处理日常任务
3. **警惕过度优化**——"够用"比"最好"更适合大多数场景
4. **保持更新**——AI 领域每 6 个月格局大变一次
