# 技能投资策略

## 技能投资组合理论

将技能视为投资资产，按风险收益特征配置：

| 类别 | 类比 | 定义 | 配置比例 | 预期回报 | 风险 |
|------|------|------|---------|---------|------|
| **核心技能** Core | 蓝筹股+国债 | 高壁垒、低 AI 替代、长期积累 | 50% | 稳健增长、复利 | 低 |
| **工具技能** Tool | 成长股 | 高杠杆、随 AI 迭代 | 30% | 短期高回报、需持续投入 | 中高 |
| **选修技能** Explore | 风险投资 | 拓宽视野、跨领域连接 | 20% | 不确定、但可能爆发 | 高 |

### 核心技能（50% 投资）

- **特征**：需要长期积累，隐含大量隐性知识，AI 难以替代
- **典型**：系统设计能力、领域医学知识、法律判断、数学/统计基础、产品思维、销售/谈判
- **投资方式**：系统学习 + 实践项目 + 导师指导 + 反思总结
- **复利效应**：每多投入 1 年，不仅技能提升，还能建立更复杂的知识连接

### 工具技能（30% 投资）

- **特征**：杠杆率高，但半衰期短（6-18 个月），随 AI 版本迭代
- **典型**：Prompt 工程、AI Agent 编排、特定 AI 框架/工具、AI 安全基础
- **投资方式**：官方文档 + 实践 + 社区跟进，不必深究原理
- **切换策略**：当出现新的范式（如从 Prompt 工程→Agent 编排→MCP 协议），果断切换

### 选修技能（20% 投资）

- **特征**：与主业不直接相关，但可能产生跨领域创新
- **典型**：心理学、生物学、经济学、哲学、艺术史、人类学
- **投资方式**：阅读 + 线上课程 + 兴趣项目
- **价值**：AI 擅长在已知模式中优化，跨领域连接是人类创造力的核心来源

## 2 年半衰期的应对策略

AI 时代，工具技能的有效半衰期约为 2 年（部分框架/工具甚至只有 6 个月）。这意味着：

### 何时深耕

当技能满足以下条件时，值得长期投入：

| 条件 | 例子 |
|------|------|
| 有复利效应（知识积累使后续学习更快） | 数学、系统设计、领域知识 |
| 隐性知识含量高（"知道怎么做" ≠ "会做"） | 手术、谈判、产品判断 |
| 人际信任依赖度大（客户选人而非选工具） | 咨询、心理治疗、高端服务 |
| 法律/制度壁垒（需要资质、认证、牌照） | 律师、医生、注册会计师 |

### 何时切换

当出现以下信号时，需要果断切换：

| 信号 | 例子 |
|------|------|
| 新范式出现，旧技能不再必要 | Prompt 精细调优 → Agent 自主编排 |
| AI 突然突破某技能领域 | GPT-4o 实时翻译 → 专业口译价格崩塌 |
| 该技能的市场需求增速明显放缓 | 纯数据分析 → 数据产品设计 |
| 入门级 AI 工具即可达到 80% 效果 | 基础文案 → 内容策略 |

### 评估矩阵

```
市场需求增速
    ↑
  高 │  深耕+工具化     │  全力投入
     │  (核心技能)      │  (高价值工具技能)
     │                  │
  低 │  放弃/维持最低   │  选修/观察
     │  (夕阳技能)      │  (新兴领域)
     └──────────────────┼────→ AI 替代速度
      低                高
```

### 完成示例

```markdown
## Q2 2026 技能审计

| 技能 | 类型 | 当前水平(1-5) | 市场趋势 | AI替代风险 | 下季度计划 |
|------|------|-------------|---------|-----------|----------|
| 系统架构设计 | Core | 4 | ↑ 持续增长 | 低（AI 辅助人类） | 完成 1 个高并发系统设计文档 + 读 2 篇架构论文 |
| Python 编程 | Core | 4 | → 稳定 | 中（低级编码） | 转向 AI 辅助架构 + Code Review 能力 |
| Agent 编排 | Tool | 2 | ↑↑ 快速增长 | 低（新领域） | 完成 LangGraph/MCP 实践项目 3 个 |
| Prompt 工程 | Tool | 3 | → 成熟 | 中（Agent 化） | 维持，关注 Agent 化替代趋势 |
| 行为经济学 | Explore | 1 | → 稳定 | 低 | 读完《思考快与慢》+ 写 1 篇总结 |
| 数据可视化 | Tool | 2 | → 稳定 | 高（AI 自动生成） | 降级为按需使用，不再专项学习 |
```

### 审计流程

1. **列出**：当前所有花费时间的技能（包括主业、副业、兴趣）
2. **分类**：Core / Tool / Explore
3. **评估**：每项打分（诚实面对自己）
4. **定位**：放在评估矩阵上看位置
5. **决策**：
   - Core 区：加大投入（+10% 时间）
   - Tool 高增长区：维持或加大
   - Tool 成熟/衰退区：削减
   - Explore 区：维持好奇但不过度投入

## 个人 OKR 与技能投资对齐

### 对齐逻辑

```
目标 (Objective)         关键结果 (Key Results)
  │                           │
  ▼                           ▼
长期职业方向             可量化的产出里程碑
  │                           │
  ▼                           ▼
技能投资决策             核心技能 → 完成项目
确定 Core/Tool/Explore   工具技能 → 掌握新工具
                         选修技能 → 产出内容
```

### 示例：AI 架构师路径

```
O: 成为 AI 架构领域 Top 10%

KR1: 每季度完成 3 个 AI 项目（含 1 个端到端生产级）
KR2: 每季度建立 1 个知识库模块（沉淀可复用经验）
KR3: 每季度输出 2 篇深度文章（含至少 1 篇被行业社区推荐）
KR4: 每季度参加 1 次行业会议/活动（建立人脉网络）
```

### 示例：AI 内容创作者路径

```
O: 建立可持续的独立创作者业务

KR1: 月度发布 8 篇高质量文章 + 4 条视频（AI 辅助产出）
KR2: 6 个月内积累 10000 订阅者
KR3: Q3 前建立一个 AI 辅助内容生产 SOP
KR4: 每季度测试 2 个新内容形式/平台
```

### 常见错误

| 错误 | 表现 | 纠正 |
|------|------|------|
| 工具沉迷 | 90% 时间学新 AI 工具，没有核心产出 | 严格限制工具学习 ≤ 30% 时间 |
| 固守旧领域 | 明知技能在被 AI 替代还继续深耕 | 每季度检查 AI替代风险，果断切割 |
| 没有输出 | 只学不输出，知识无法沉淀 | 每个技能学习后必须有一个产出物 |
| 忽视身体 | 只投资技能，不投资健康 | 纳入 OKR：每周 3 次运动，7 小时睡眠 |
| 完美主义 | 等"准备好"才行动 | 最小可行产品先行，迭代优化 |
