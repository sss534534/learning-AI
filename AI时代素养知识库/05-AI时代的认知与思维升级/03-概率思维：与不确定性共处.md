# 概率思维：与不确定性共处

## 为什么需要概率思维

AI 的输出天生是概率性的：

| AI 系统要素 | 不确定性来源 |
|------------|------------|
| Temperature > 0 | 每次输出不同，同一 prompt 可能产生不同结果 |
| 采样随机性 | 解码策略（top-k, top-p）引入随机选择 |
| 模型置信度 | 模型无法准确知道"自己不知道什么" |
| 知识边界 | 训练数据截止后的信息只能靠外推 |

同时，商业和技术决策也天然充满不确定性。**确定性思维是 AI 时代的障碍。**

| 确定性思维 | 概率思维 |
|-----------|---------|
| "这是对的/错的" | "这有 70% 概率正确，其中事实部分 95%，推理部分 60%" |
| "这个模型好/差" | "这个模型在 A 任务 90 分，B 任务 60 分" |
| "这个方案可行/不可行" | "这个方案在场景 X 下 ROI 2.5x，场景 Y 下 0.8x" |
| "AI 可靠/不可靠" | "AI 在已知领域可靠（80%+），在新领域需验证（40-60%）" |

## 贝叶斯更新（直觉版）

核心思想：**信念不是固定的，而是随着新证据不断更新的。**

```
先验信念（Prior）× 新证据（Evidence）= 后验信念（Posterior）
```

### 案例：与 AI 协作时的信任更新

```
第一步：初始信念
  "这个 AI 模型在编程任务上可靠"
  先验可信度：80%（基于他人评价或初步体验）

第二步：新证据 1——AI 回答了 Python 语法问题，完全正确
  证据强度：中等（语法问题相对简单）
  后验可信度：82%（小幅上调）

第三步：新证据 2——AI 解释了复杂的设计模式，准确且深入
  证据强度：高（复杂任务表现好更有说服力）
  后验可信度：88%（明显上调）

第四步：新证据 3——AI 生成了一个看似正确但实际有安全漏洞的代码
  证据强度：高（安全漏洞是严重错误）
  后验可信度：70%（大幅下调，因为这是高风险领域）

第五步：新证据 4——AI 连续在 5 个简单任务上表现完美
  证据强度：低（简单任务不能完全修复信任）
  后验可信度：75%（小幅回调）
```

### 与 AI 协作的贝叶斯实践

每次 AI 的输出都是"新证据"，你需要持续更新对 AI 可信度的判断：

| 场景 | 证据强度 | 更新幅度 |
|------|---------|---------|
| 常识性问题回答正确 | 低 | 小幅上调 |
| 专业领域深度推理正确 | 高 | 大幅上调 |
| 犯了一个明显错误 | 中 | 中幅下调 |
| 犯了专业领域的关键错误 | 高 | 大幅下调 |
| 连续多次正确 | 累积 | 稳步上调但边际递减 |

**关键原则：** 极端证据才能极端改变信念，一个正确回答不证明 AI 可靠，一个错误回答也不证明 AI 无用。

## 从二元思维到概率梯度的转换

| 二元思维 | 概率思维 |
|---------|---------|
| 这个回答对/错 | 这个回答可信度 80%，其中事实部分 95%，推理部分 60% |
| 这个模型好/差 | 这个模型在 A 任务 90 分，B 任务 60 分 |
| 这个工具值得/不值得用 | 这个工具在场景 X 下 ROI 2.5x，场景 Y 下 0.8x |
| AI 会/不会取代我的工作 | AI 能自动化我 40% 的任务，增强 30%，30% 短期无法替代 |
| 这个方案应该/不应该实施 | 期望值 = 成功概率 × 收益 - 失败概率 × 成本 |

### 概率校准练习

**目标：** 减小你的置信度和实际准确率之间的差距。

```
Step 1：每次用 AI 输出后，给自己一个置信度评分（0-100%）
Step 2：记录实际结果（正确/部分正确/错误）
Step 3：每周回顾——你的置信度是否匹配实际准确率？

常见偏差：
  - 过度自信：你说 90% 正确，实际只有 60%
  - 不足自信：你说 60% 正确，实际有 85%
Step 4：根据偏差调整你的判断尺度
```

## 实操

### 1. 每次用 AI 输出时，给自己一个置信度评分

在 AI 输出后，问自己三个问题：
1. 这个答案涉及的领域我熟悉吗？（不熟悉 → 降低置信度）
2. AI 的推理过程我验证了吗？（未验证 → 降低置信度）
3. 这个任务 AI 通常表现好吗？（不擅长 → 降低置信度）

### 2. 关键决策时的概率清单

```
决策：是否采用 AI 提出的方案？

┌────────────────────────────────────────┐
│  AI 建议：XXX                           │
│                                         │
│  你的独立判断：XXX                       │
│                                         │
│  AI 建议的置信度：___%                   │
│  你判断的置信度：___%                    │
│                                         │
│  如果两者一致：综合置信度 = avg + 10%    │
│  如果两者冲突：debug 差异原因             │
│                                         │
│  最终决定：___（附置信度）               │
└────────────────────────────────────────┘
```

### 3. 定期校准

每月一次校准练习：
1. 回顾 10 次使用 AI 的记录
2. 对比你的置信度和实际结果
3. 计算校准曲线

```
置信度 80-100% → 实际准确率 ___%
置信度 60-79%  → 实际准确率 ___%
置信度 40-59%  → 实际准确率 ___%
置信度 <40%    → 实际准确率 ___%

如果 80-100% 区间的准确率 < 70%，你的过度自信需要干预。
```
