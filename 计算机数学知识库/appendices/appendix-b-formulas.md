## 1. 组合数学公式

### 1.1 阶乘
```
n! = n × (n-1) × (n-2) × ... × 2 × 1
0! = 1
```

### 1.2 排列
```
P(n, k) = n! / (n-k)!
```

### 1.3 组合（二项式系数）
```
C(n, k) = n! / (k! × (n-k)!)
C(n, 0) = C(n, n) = 1
C(n, k) = C(n, n-k)
C(n, k) = C(n-1, k-1) + C(n-1, k)    (帕斯卡恒等式)
```

### 1.4 二项式定理
```
(a + b)ⁿ = Σ_{k=0}^n C(n, k) a^{n-k} b^k
```

### 1.5 容斥原理
```
|A₁ ∪ A₂ ∪ ... ∪ Aₙ| = Σ|Aᵢ| - Σ|Aᵢ∩Aⱼ| + Σ|Aᵢ∩Aⱼ∩Aₖ| - ... + (-1)^{n+1}|A₁∩...∩Aₙ|
```

### 1.6 求和公式
```
Σ_{i=1}^n i = n(n+1)/2
Σ_{i=1}^n i² = n(n+1)(2n+1)/6
Σ_{i=1}^n i³ = [n(n+1)/2]²
Σ_{i=0}^n rⁱ = (r^{n+1}-1)/(r-1), r ≠ 1   (等比数列求和)
```

### 1.7 卡特兰数
```
Cₙ = (1/(n+1)) × C(2n, n)
递推：C₀=1, C_{n+1}=Σ_{i=0}^n C_i C_{n-i}
```

## 2. 数论公式

### 2.1 最大公约数（欧几里得算法）
```
gcd(a, b) = gcd(b, a mod b)
gcd(a, 0) = a
```

### 2.2 最小公倍数
```
lcm(a, b) = (a × b) / gcd(a, b)
```

### 2.3 贝祖等式
```
存在整数x,y使得：ax + by = gcd(a, b)
```

### 2.4 欧拉函数
```
φ(n) = n × Π_{p|n} (1-1/p), p是n的不同质因子
若n=Π p_i^{k_i}, 则φ(n)=Π p_i^{k_i-1}(p_i-1)
```

### 2.5 欧拉定理
```
若a与n互质，则a^φ(n) ≡ 1 mod n
```

### 2.6 费马小定理
```
若p是质数，a不被p整除，则a^{p-1} ≡ 1 mod p
```

### 2.7 中国剩余定理
```
若m₁,m₂,...,mₙ两两互质，求x满足：
x ≡ a₁ mod m₁
x ≡ a₂ mod m₂
...
x ≡ aₙ mod mₙ
解：x ≡ Σ a_i M_i y_i mod M, 其中M=Πm_i, M_i=M/m_i, y_i≡M_i^{-1} mod m_i
```

## 3. 线性代数公式

### 3.1 矩阵乘法
```
C = A × B
C_{ij} = Σ_{k=1}^n A_{ik} B_{kj}
A ∈ ℝ^{m×n}, B ∈ ℝ^{n×p} ⇒ C ∈ ℝ^{m×p}
```

### 3.2 矩阵转置
```
(A^T)_{ij} = A_{ji}
(AB)^T = B^T A^T
(A+B)^T = A^T + B^T
```

### 3.3 行列式（2×2）
```
det([[a, b], [c, d]]) = ad - bc
```

### 3.4 特征值与特征向量
```
A𝐯 = λ𝐯
det(A - λI) = 0    (特征方程)
```

### 3.5 向量运算
```
点积：𝐚·𝐛 = Σ a_i b_i = ||𝐚|| ||𝐛|| cosθ
叉积（3D）：𝐚×𝐛 = (a₂b₃-a₃b₂, a₃b₁-a₁b₃, a₁b₂-a₂b₁)
L₂范数：||𝐯||₂ = √(Σ v_i²)
```

### 3.6 奇异值分解（SVD）
```
A = UΣV^T
U: m×m正交矩阵
Σ: m×n对角矩阵
V^T: n×n正交矩阵
```

## 4. 微积分公式

### 4.1 常用导数
```
d/dx (c) = 0
d/dx (xⁿ) = n x^{n-1}
d/dx (eˣ) = eˣ
d/dx (ln x) = 1/x
d/dx (sin x) = cos x
d/dx (cos x) = -sin x
乘积法则：(fg)' = f'g + fg'
商法则：(f/g)' = (f'g - fg')/g²
链式法则：d/dx f(g(x)) = f'(g(x))g'(x)
```

### 4.2 偏导数与梯度
```
∇f = (∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ)
方向导数：D_𝐯 f = ∇f·𝐯
```

### 4.3 常用积分
```
∫xⁿ dx = x^{n+1}/(n+1) + C, n≠-1
∫eˣ dx = eˣ + C
∫1/x dx = ln|x| + C
∫sin x dx = -cos x + C
∫cos x dx = sin x + C
分部积分：∫u dv = uv - ∫v du
```

## 5. 概率与统计公式

### 5.1 基本概率
```
P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
P(A|B) = P(A ∩ B)/P(B)    (条件概率)
P(A ∩ B) = P(A|B)P(B)    (乘法法则)
```

### 5.2 贝叶斯定理
```
P(A|B) = P(B|A)P(A) / P(B)
```

### 5.3 期望与方差
```
期望：E[X] = Σ x P(X=x)    (离散)
方差：Var(X) = E[(X-E[X])²] = E[X²] - (E[X])²
标准差：σ = √Var(X)
```

### 5.4 重要概率分布

**伯努利分布**
```
P(X=1) = p, P(X=0) = 1-p
E[X] = p, Var(X) = p(1-p)
```

**二项分布**
```
P(X=k) = C(n, k) p^k (1-p)^{n-k}
E[X] = np, Var(X) = np(1-p)
```

**正态分布**
```
X ~ N(μ, σ²)
f(x) = (1/(σ√(2π))) exp(-(x-μ)²/(2σ²))
```

### 5.5 信息论
```
熵：H(X) = -Σ P(x) log₂ P(x)
交叉熵：H(P, Q) = -Σ P(x) log₂ Q(x)
KL散度：D_{KL}(P||Q) = H(P, Q) - H(P)
```

## 6. 算法与复杂度公式

### 6.1 主定理（Master Theorem）
```
T(n) = aT(n/b) + f(n)

情况1：f(n) = O(n^{log_b a - ε}) ⇒ T(n) = Θ(n^{log_b a})
情况2：f(n) = Θ(n^{log_b a} log^k n) ⇒ T(n) = Θ(n^{log_b a} log^{k+1} n)
情况3：f(n) = Ω(n^{log_b a + ε})且a f(n/b) ≤ c f(n) ⇒ T(n) = Θ(f(n))
```

### 6.2 常见递归关系解
```
T(n) = T(n-1) + O(1) ⇒ O(n)
T(n) = T(n-1) + O(n) ⇒ O(n²)
T(n) = 2T(n/2) + O(n) ⇒ O(n log n)    (归并排序)
T(n) = 2T(n/2) + O(1) ⇒ O(n)
T(n) = T(n/2) + O(1) ⇒ O(log n)    (二分查找)
```
