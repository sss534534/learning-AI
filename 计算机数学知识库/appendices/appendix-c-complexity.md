## 1. 排序算法

| 算法 | 平均时间 | 最坏时间 | 最好时间 | 空间 | 稳定性 |
|-----|---------|---------|---------|------|--------|
| 冒泡排序 | O(n²) | O(n²) | O(n) | O(1) | 稳定 |
| 选择排序 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 |
| 插入排序 | O(n²) | O(n²) | O(n) | O(1) | 稳定 |
| 希尔排序 | O(n log n) ~ O(n²) | O(n²) | O(n) | O(1) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |
| 快速排序 | O(n log n) | O(n²) | O(n log n) | O(log n) | 不稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 计数排序 | O(n + k) | O(n + k) | O(n + k) | O(k) | 稳定 |
| 基数排序 | O(d(n + k)) | O(d(n + k)) | O(d(n + k)) | O(n + k) | 稳定 |
| 桶排序 | O(n + k) | O(n²) | O(n + k) | O(n + k) | 稳定 |

## 3. 数据结构操作

### 3.1 数组
| 操作 | 时间 |
|-----|------|
| 读取 | O(1) |
| 插入 | O(n) |
| 删除 | O(n) |
| 查找 | O(n) |

### 3.2 链表
| 操作 | 时间（单链表） | 时间（双向链表） |
|-----|-------------|----------------|
| 读取 | O(n) | O(n) |
| 插入（已知位置） | O(1) | O(1) |
| 删除（已知位置） | O(1) | O(1) |
| 前置插入 | O(n) | O(1) |

### 3.3 栈（Stack）
| 操作 | 时间 |
|-----|------|
| 压入 | O(1) |
| 弹出 | O(1) |
| 查看栈顶 | O(1) |

### 3.4 队列（Queue）
| 操作 | 时间 |
|-----|------|
| 入队 | O(1) |
| 出队 | O(1) |
| 查看队首 | O(1) |

### 3.5 哈希表（Hash Table）
| 操作 | 平均时间 | 最坏时间 |
|-----|---------|---------|

| 删除 | O(1) | O(n) |
| 查找 | O(1) | O(n) |

### 3.6 二叉搜索树（BST）
| 操作 | 平均时间 | 最坏时间 |
|-----|---------|---------|
| 插入 | O(log n) | O(n) |
| 删除 | O(log n) | O(n) |
| 查找 | O(log n) | O(n) |

### 3.7 平衡树（AVL/红黑树）
| 操作 | 时间 |
|-----|------|
| 插入 | O(log n) |
| 删除 | O(log n) |
| 查找 | O(log n) |

### 3.8 堆（Heap）
| 操作 | 时间 |
|-----|------|
| 建堆 | O(n) |
| 插入 | O(log n) |
| 删除（根） | O(log n) |
| 获取极值 | O(1) |

### 3.9 并查集（Disjoint Set）
| 操作 | 时间 |
|-----|------|
| 查找 | O(α(n)) （近乎常数） |
| 合并 | O(α(n)) （近乎常数） |
| α是阿克曼函数的反函数 |

## 5. 复杂度比较

### 5.1 增长速度排序
```
O(1) < O(log log n) < O(log n) < O(√n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)
```

### 5.2 函数增长示例
| n | log n | n | n log n | n² | 2ⁿ |
|---|-------|---|---------|----|-----|
| 10 | 3.3 | 10 | 33 | 100 | 1024 |
| 100 | 6.6 | 100 | 660 | 10000 | 1e30 |
| 1000 | 9.9 | 1000 | 9900 | 1e6 | 1e300 |

## 6. 复杂度记忆技巧

### 6.1 时间复杂度分类
| 复杂度 | 名称 | 示例 |
|-------|------|------|
| O(1) | 常数时间 | 数组访问 |
| O(log n) | 对数时间 | 二分搜索 |
| O(n) | 线性时间 | 线性搜索 |
| O(n log n) | 线性对数时间 | 归并排序 |
| O(n²) | 平方时间 | 双重循环 |
| O(n³) | 立方时间 | 矩阵乘法 |
| O(2ⁿ) | 指数时间 | 子集生成 |
| O(n!) | 阶乘时间 | 全排列生成 |

### 6.2 空间复杂度分类
| 复杂度 | 说明 | 示例 |
|-------|------|------|
| O(1) | 常数空间 | 几个变量 |
| O(n) | 线性空间 | 辅助数组 |

## 7. 常用算法的时间复杂度速查

| 问题 | 最优算法 | 时间复杂度 |
|-----|---------|----------|
| 排序 | 比较排序（下界） | Ω(n log n) |
| 排序 | 计数排序（整数） | O(n + k) |
| 最短路径（单源，非负权） | Dijkstra | O(E log V) |
| 最短路径（单源，有负权） | Bellman-Ford | O(VE) |
| 最短路径（所有点对） | Floyd-Warshall | O(V³) |
| 最小生成树 | Prim/Kruskal | O(E log V) |
| 字符串匹配 | KMP | O(n + m) |
| 矩阵乘法 | Strassen | O(n².81) |
