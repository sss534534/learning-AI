## 📖 目录结构

### 第一部分：基础数学

- **[第一章：离散数学](./part1-foundations/ch01-discrete-math.md)**
  - 命题逻辑、谓词逻辑、证明方法
  - 集合论基础、关系与函数
  - 数学归纳法、递归

- **[第二章：组合数学](./part1-foundations/ch02-combinatorics.md)**
  - 计数原理、排列组合
  - 鸽巢原理、容斥原理
  - 生成函数、递推关系
  - 组合数学在算法中的应用

- **[第三章：数论基础](./part1-foundations/ch03-number-theory.md)**
  - 整除与素数、最大公约数
  - 模运算、同余、中国剩余定理
  - 费马小定理、欧拉定理
  - 数论在密码学中的应用

### 第二部分：算法数学

- **[第四章：算法分析](./part2-algorithms/ch04-algorithm-analysis.md)**
  - 时间复杂度分析（大O、大Ω、大Θ）
  - 空间复杂度分析
  - 摊销分析、最坏/平均/最好情况
  - Master定理、递归式求解

- **[第五章：计算复杂度理论](./part2-algorithms/ch05-complexity-theory.md)**
  - P与NP问题
  - NP完全性、NP难问题
  - 近似算法、随机算法
  - 复杂度类简介（PSPACE、EXPTIME等）

- **[第六章：图论与网络算法](./part2-algorithms/ch06-graph-theory.md)**
  - 图的表示、遍历算法（BFS/DFS）
  - 最短路径算法（Dijkstra、Bellman-Ford、Floyd-Warshall）
  - 最小生成树（Prim、Kruskal）
  - 网络流、二分图匹配

### 第三部分：数据结构数学

- **[第七章：集合与关系](./part3-data-structures/ch07-sets-relations.md)**

  - 格与布尔代数

- **[第八章：树与堆的数学](./part3-data-structures/ch08-trees-heaps.md)**

- **[第九章：哈希与查找](./part3-data-structures/ch09-hashing-search.md)**

  - 哈希表的复杂度分析
  - 布隆过滤器、Cuckoo哈希
  - 平衡树与哈希表的权衡

- **[第十章：概率数据结构](./part3-data-structures/ch10-probabilistic-ds.md)**

### 核心必备（所有程序员都应该掌握）

| 知识领域 | 重要程度 | 应用场景 |
|---------|---------|---------|
| 离散数学基础 | ⭐⭐⭐⭐⭐ | 逻辑推理、算法理解 |
| 组合数学 | ⭐⭐⭐⭐⭐ | 计数、算法分析 |
| 算法复杂度分析 | ⭐⭐⭐⭐⭐ | 性能优化、算法选择 |
| 图论基础 | ⭐⭐⭐⭐⭐ | 网络、路径规划 |
| 数据结构数学原理 | ⭐⭐⭐⭐⭐ | 系统设计、性能调优 |

### 专业方向（根据领域选择）

| 领域 | 核心数学知识 |
|-----|------------|
| **后端/系统开发** | 离散数学、算法分析、图论、数值计算 |
| **前端/游戏开发** | 线性代数、几何、数值计算 |
| **数据科学/ML** | 线性代数、微积分、概率统计、优化 |
| **密码学/安全** | 数论、抽象代数、密码学 |
| **AI/深度学习** | 线性代数、微积分、概率统计、信息论、优化 |
| **嵌入式/信号处理** | 信号处理、数值计算、线性代数 |

## 📊 学习路径建议

### 初级阶段（1-3个月）

1. 离散数学基础（命题逻辑、集合论）
2. 组合数学入门（计数原理）
3. 算法复杂度分析（大O记号）
4. 数据结构基础（数组、链表、树）

### 中级阶段（3-6个月）

1. 算法分析与设计
2. 图论与网络算法
3. 数论基础（密码学方向）
4. 线性代数（AI方向）
5. 概率统计（数据科学方向）

### 高级阶段（6个月以上）

1. 计算复杂度理论
2. 高级数值计算
3. 凸优化理论
4. 信息论与编码
5. 前沿方向（根据兴趣选择）
