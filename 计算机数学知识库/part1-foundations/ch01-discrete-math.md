## 1. 命题逻辑

### 1.1 命题与联结词

**命题（Proposition）** 是一个非真即假的陈述句。

```
例子：
- "2 + 2 = 4" 是真命题
- "3是偶数" 是假命题
- "今天天气好" 是命题（取决于实际天气）
- "x > 5" 不是命题（x的值未知）
```

**基本逻辑联结词：**

| 联结词 | 符号 | 名称 | 示例 | 说明 |
|-------|------|-----|------|------|
| 否定 | ¬ | NOT | ¬P | P为真则¬P为假，反之亦然 |
| 合取 | ∧ | AND | P ∧ Q | P和Q都为真时才为真 |
| 析取 | ∨ | OR | P ∨ Q | P或Q至少一个为真时为真 |
| 蕴含 | → | IMPLIES | P → Q | P为真且Q为假时才为假 |
| 等价 | ↔ | IFF | P ↔ Q | P和Q同真同假时为真 |

**真值表示例（P → Q）：**

| P | Q | P → Q |
|---|---|-------|
| T | T | T |
| T | F | F |
| F | T | T |
| F | F | T |

### 1.2 命题等价式

**常用逻辑等价式：**

| 名称 | 公式 |
|-----|------|
| 双重否定 | ¬¬P ↔ P |
| 德摩根定律 | ¬(P ∧ Q) ↔ ¬P ∨ ¬Q |
| | ¬(P ∨ Q) ↔ ¬P ∧ ¬Q |
| 交换律 | P ∧ Q ↔ Q ∧ P |
| | P ∨ Q ↔ Q ∨ P |
| 结合律 | (P ∧ Q) ∧ R ↔ P ∧ (Q ∧ R) |
| | (P ∨ Q) ∨ R ↔ P ∨ (Q ∨ R) |
| 分配律 | P ∧ (Q ∨ R) ↔ (P ∧ Q) ∨ (P ∧ R) |
| | P ∨ (Q ∧ R) ↔ (P ∨ Q) ∧ (P ∨ R) |
| 蕴含等价 | P → Q ↔ ¬P ∨ Q |
| 逆否命题 | P → Q ↔ ¬Q → ¬P |

### 1.3 范式

**合取范式（CNF）：** 多个析取式的合取

```
示例：(P ∨ Q) ∧ (¬P ∨ R) ∧ (Q ∨ ¬R)
```

**析取范式（DNF）：** 多个合取式的析取

```
示例：(P ∧ Q) ∨ (¬P ∧ R) ∨ (Q ∧ ¬R)
```

**Python示例：逻辑表达式化简**

```python
from sympy import symbols, And, Or, Not, simplify_logic

P, Q, R = symbols('P Q R')

# 定义逻辑表达式
expr = And(Or(P, Q), Or(Not(P), R))
print("原始表达式:", expr)

# 化简
simplified = simplify_logic(expr)
print("化简后:", simplified)
```

## 2. 谓词逻辑

### 2.1 谓词与量词

**谓词（Predicate）** 表示对象的性质或关系：

```
- P(x): "x大于3"
- Q(x, y): "x等于y"
```

**量词：**

- **全称量词** ∀（For All）：∀x P(x) 表示"所有x都满足P(x)"
- **存在量词** ∃（There Exists）：∃x P(x) 表示"存在x满足P(x)"

**示例：**

```
∀x ∃y (x < y)：对于任意x，存在y使得x < y（在实数域中为真）
∃x ∀y (x ≤ y)：存在x，使得对于所有y，x ≤ y（在自然数中为真，x=0）
```

### 2.2 量词的否定

```
¬∀x P(x) ↔ ∃x ¬P(x)
¬∃x P(x) ↔ ∀x ¬P(x)
```

## 3. 证明方法

### 3.1 直接证明

**思路：** 假设P为真，通过推理证明Q为真，从而证明P → Q。

**示例：证明如果n是偶数，则n²也是偶数**

```
证明：
假设n是偶数，则n = 2k，其中k是整数。
则n² = (2k)² = 4k² = 2(2k²)
这表明n²是2的倍数，因此n²是偶数。
```

### 3.2 反证法（归谬法）

**思路：** 假设¬Q为真，推导出矛盾，从而证明P → Q。

**示例：证明√2是无理数**

```
证明：
假设√2是有理数，则√2 = a/b，其中a、b是互质整数。
平方得2 = a²/b² → a² = 2b² → a²是偶数 → a是偶数
设a = 2c，则(2c)² = 2b² → 4c² = 2b² → 2c² = b² → b²是偶数 → b是偶数
但a和b都为偶数与它们互质矛盾！
因此√2是无理数。
```

## 4. 集合论基础

### 4.1 集合的表示

**集合的定义：** 由确定的、互不相同的对象组成的整体。

**表示方法：**

```
列举法：A = {1, 2, 3, 4, 5}
描述法：B = {x | x是正整数且x < 6}
```

**特殊集合：**

| 符号 | 名称 | 说明 |
|-----|------|------|
| ∅ | 空集 | 不含任何元素 |
| ℕ | 自然数集 | {0, 1, 2, 3, ...} |
| ℤ | 整数集 | {..., -2, -1, 0, 1, 2, ...} |
| ℚ | 有理数集 | 整数和分数 |
| ℝ | 实数集 | 有理数和无理数 |

### 4.2 集合运算

| 运算 | 符号 | 定义 |
|-----|------|------|
| 并集 | A ∪ B | {x | x ∈ A 或 x ∈ B} |
| 交集 | A ∩ B | {x | x ∈ A 且 x ∈ B} |
| 差集 | A - B | {x | x ∈ A 且 x ∉ B} |
| 补集 | Aᶜ | {x | x ∉ A} |
| 对称差 | A ⊕ B | (A - B) ∪ (B - A) |

**Venn图示例：**

```
A ∪ B:        A ∩ B:       A - B:
  █████         █              █
███░░███       ██░░            █░░
  █████         █              █
```

**Python示例：集合运算**

```python
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

print("并集:", A | B)       # {1, 2, 3, 4, 5, 6}
print("交集:", A & B)       # {3, 4}
print("差集:", A - B)       # {1, 2}
print("对称差:", A ^ B)     # {1, 2, 5, 6}
```

### 4.3 幂集与笛卡尔积

**幂集（Power Set）：** 集合A的所有子集构成的集合，记为P(A)

```
若A = {1, 2}，则P(A) = {∅, {1}, {2}, {1, 2}}
| P(A) | = 2^|A|
```

**笛卡尔积（Cartesian Product）：**

```
A × B = {(a, b) | a ∈ A, b ∈ B}
```

## 5. 关系与函数

### 5.1 关系

**定义：** 集合A和B的二元关系R是A×B的子集，记为R ⊆ A×B

**关系的性质：**

| 性质 | 定义 |
|-----|------|
| 自反 | ∀x ∈ A, (x, x) ∈ R |
| 反自反 | ∀x ∈ A, (x, x) ∉ R |
| 对称 | (x, y) ∈ R → (y, x) ∈ R |
| 反对称 | (x, y) ∈ R 且 (y, x) ∈ R → x = y |
| 传递 | (x, y) ∈ R 且 (y, z) ∈ R → (x, z) ∈ R |

### 5.2 等价关系

**定义：** 同时满足自反、对称、传递的关系称为等价关系。

**示例：** 整数集中的"同余模n"关系是等价关系。

### 5.3 偏序关系

**定义：** 同时满足自反、反对称、传递的关系称为偏序关系。

**示例：** 整数集中的"≤"关系是偏序关系。

### 5.4 函数

**函数定义：** 函数f: A→B是一个关系，满足每个x∈A对应唯一的y∈B。

**函数类型：**

| 类型 | 定义 |
|-----|------|
| 单射（Injective） | f(x₁) = f(x₂) → x₁ = x₂ |
| 满射（Surjective） | ∀y ∈ B, ∃x ∈ A, f(x) = y |
| 双射（Bijective） | 同时是单射和满射 |

## 6. 数学归纳法与递归

### 6.1 数学归纳法

**第一数学归纳法：**

```
1. 基础步骤：证明P(0)为真
2. 归纳步骤：假设P(k)为真，证明P(k+1)为真
结论：∀n ≥ 0, P(n)为真
```

**示例：证明∑_{i=0}^n i = n(n+1)/2**

```
证明：
1. 基础步骤：n = 0时，左边 = 0，右边 = 0(0+1)/2 = 0，成立。

2. 归纳步骤：
   假设对于n = k，∑_{i=0}^k i = k(k+1)/2成立。
   则对于n = k+1：
   ∑_{i=0}^{k+1} i = ∑_{i=0}^k i + (k+1)
                  = k(k+1)/2 + (k+1)
                  = (k+1)(k/2 + 1)
                  = (k+1)(k+2)/2
   成立。

由数学归纳法，对所有n ≥ 0成立。
```

### 6.2 强数学归纳法

```
1. 基础步骤：证明P(0)为真
2. 归纳步骤：假设P(0), P(1), ..., P(k)都为真，证明P(k+1)为真
结论：∀n ≥ 0, P(n)为真
```

### 6.3 递归与递推关系

**斐波那契数列：**

```
F(0) = 0
F(1) = 1
F(n) = F(n-1) + F(n-2)  for n ≥ 2
```

**Python示例：**

```python
# 递归版（有指数时间复杂度）
def fib_recursive(n):
    if n <= 1:
        return n
    return fib_recursive(n-1) + fib_recursive(n-2)

# 迭代版（线性时间）
def fib_iterative(n):
    if n <= 1:
        return n
    a, b = 0, 1
    for _ in range(2, n+1):
        a, b = b, a + b
    return b

# 矩阵快速幂（对数时间）
def fib_matrix(n):
    if n <= 1:
        return n
    def multiply(a, b):
        return [
            [a[0][0]*b[0][0] + a[0][1]*b[1][0],
             a[0][0]*b[0][1] + a[0][1]*b[1][1]],
            [a[1][0]*b[0][0] + a[1][1]*b[1][0],
             a[1][0]*b[0][1] + a[1][1]*b[1][1]]
        ]
    def matrix_pow(mat, power):
        result = [[1, 0], [0, 1]]
        while power > 0:
            if power % 2 == 1:
                result = multiply(result, mat)
            mat = multiply(mat, mat)
            power = power // 2
        return result
    mat = [[1, 1], [1, 0]]
    return matrix_pow(mat, n-1)[0][0]
```
