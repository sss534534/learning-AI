## 1. 计数原理

### 1.1 加法原理

**加法原理：** 如果完成一件事有n类方法，第i类有m_i种方法，则总方法数为：

```
m₁ + m₂ + ... + mₙ
```

**示例：** 从北京到上海，可以乘飞机（5班）、火车（10班）、汽车（8班），共有5+10+8=23种选择。

### 1.2 乘法原理

**乘法原理：** 如果完成一件事需要n个步骤，第i步有m_i种方法，则总方法数为：

```
m₁ × m₂ × ... × mₙ
```

**示例：** 从3件上衣和2条裤子中搭配，共有3×2=6种搭配方式。

### 1.3 应用示例

**Python示例：计数密码组合数**

```python
# 8位密码，包含大小写字母和数字
letters = 52  # 26大写 + 26小写
digits = 10
total_chars = letters + digits

# 每位有total_chars种选择，共8位
combinations = total_chars ** 8
print(f"8位密码组合数: {combinations:,}")  # 约218万亿
```

## 2. 排列与组合

### 2.1 排列

**排列（Permutation）：** 从n个不同元素中取出k个元素排成一列的方式数。

```
P(n, k) = n! / (n - k)!
```

**全排列：** k = n时，P(n, n) = n!

**示例：** 从5人中选3人排成一列，P(5, 3) = 5×4×3 = 60。

### 2.2 组合

**组合（Combination）：** 从n个不同元素中取出k个元素的方式数（不考虑顺序）。

```
C(n, k) = n! / (k! × (n - k)!)
```

**组合数性质：**

```
C(n, k) = C(n, n - k)
C(n, k) = C(n - 1, k - 1) + C(n - 1, k) （帕斯卡恒等式）
```

**示例：** 从5人中选3人组队，C(5, 3) = 10。

### 2.3 二项式定理

```
(a + b)ⁿ = Σ_{k=0}^n C(n, k) a^{n-k} b^k
```

**Python示例：计算排列组合**

```python
import math
from itertools import permutations, combinations

def permutation(n, k):
    return math.factorial(n) // math.factorial(n - k)

def combination(n, k):
    return math.factorial(n) // (math.factorial(k) * math.factorial(n - k))

print(f"P(5, 3) = {permutation(5, 3)}")  # 60
print(f"C(5, 3) = {combination(5, 3)}")  # 10

# 使用itertools生成所有排列组合
items = ['A', 'B', 'C', 'D', 'E']
print("排列示例:")
for p in permutations(items, 3):
    print(p)  # ('A','B','C'), ('A','B','D'), ...

print("\n组合示例:")
for c in combinations(items, 3):
    print(c)  # ('A','B','C'), ('A','B','D'), ...
```

### 2.4 可重复的排列与组合

**可重复排列：** 从n个元素中可重复地选k个排列，有n^k种。

**可重复组合：** 从n个元素中可重复地选k个组合，有C(n + k - 1, k)种。

**示例：** 将10个相同的球分给3个盒子（可空），有C(10 + 3 - 1, 10) = 66种。

## 3. 鸽巢原理与容斥原理

### 3.1 鸽巢原理（抽屉原理）

**基本形式：** 如果n+1个鸽子放入n个鸽巢，则至少有一个鸽巢有多个鸽子。

**示例：** 任意367人中，至少有2人生日相同。

**加强形式：** 如果m个鸽子放入n个鸽巢，则至少有一个鸽巢有⌈m/n⌉个鸽子。

**示例：** 证明在任意11个整数中，必有两个数的差是10的倍数。

### 3.2 容斥原理

**两个集合：**

```
|A ∪ B| = |A| + |B| - |A ∩ B|
```

**三个集合：**

```
|A ∪ B ∪ C| = |A| + |B| + |C| - |A∩B| - |A∩C| - |B∩C| + |A∩B∩C|
```

**一般形式：**

```
|∪A_i| = Σ|A_i| - Σ|A_i∩A_j| + Σ|A_i∩A_j∩A_k| - ... + (-1)^{m+1}|∩A_i|
```

**Python示例：容斥原理求1-100中被2或3或5整除的数**

```python
def count_divisible(n, divisors):
    count = 0
    # 生成所有非空子集
    from itertools import combinations
    for k in range(1, len(divisors) + 1):
        for subset in combinations(divisors, k):
            # 计算最小公倍数
            lcm = 1
            for d in subset:
                lcm = lcm * d // math.gcd(lcm, d)
            # 容斥符号
            sign = (-1) ** (k + 1)
            count += sign * (n // lcm)
    return count

result = count_divisible(100, [2, 3, 5])
print(f"1-100中被2、3或5整除的数: {result}个")
```

## 4. 生成函数

### 4.1 生成函数定义

**普通生成函数：** 序列a₀, a₁, a₂, ... 的生成函数为：

```
G(x) = a₀ + a₁x + a₂x² + a₃x³ + ...
```

**示例：** 序列1, 1, 1, 1, ... 的生成函数是1/(1 - x)。

### 4.2 生成函数的应用

**示例：** 用生成函数求斐波那契数列的通项公式。

### 4.3 指数生成函数

**指数生成函数：**

```
G(x) = a₀ + a₁x/1! + a₂x²/2! + a₃x³/3! + ...
```

## 5. 递推关系

### 5.1 线性齐次递推关系

**形式：**

```
aₙ + c₁a_{n-1} + c₂a_{n-2} + ... + c_k a_{n-k} = 0
```

**特征方程法：**

```
rᵏ + c₁r^{k-1} + ... + c_k = 0
```

### 5.2 斐波那契数列的求解

**递推关系：** Fₙ = F_{n-1} + F_{n-2}

**特征方程：** r² - r - 1 = 0

**解：**

```
Fₙ = (φⁿ - ψⁿ) / √5
其中φ = (1 + √5)/2，ψ = (1 - √5)/2
```

### 5.3 卡特兰数

**递推关系：**

```
C₀ = 1
Cₙ₊₁ = Σ_{i=0}^n C_i C_{n-i}
```

**通项公式：**

```
Cₙ = (1/(n+1)) × C(2n, n)
```

**应用场景：**
- 合法括号序列数
- 二叉搜索树数目
- 凸多边形三角划分方式

### 6.3 组合搜索与剪枝

**Python示例：求n个元素的所有子集（回溯法）**

```python
def subsets(nums):
    result = []
    def backtrack(path, start):
        result.append(path[:])
        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(path, i + 1)
            path.pop()
    backtrack([], 0)
    return result

print(subsets([1, 2, 3]))
# [[], [1], [1,2], [1,2,3], [1,3], [2], [2,3], [3]]
```
