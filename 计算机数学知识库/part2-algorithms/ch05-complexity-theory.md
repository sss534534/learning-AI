## 1. 复杂度基础

### 1.1 问题与实例
```
问题：一类计算任务的抽象描述，如排序问题。
实例：问题的具体输入，如对数组[3,1,4,2]排序。
```

### 1.2 判定问题与优化问题
```
判定问题：答案是"是"或"否"的问题。
    例：给定图G和k，G中是否存在大小为k的团？

优化问题：找到最优解的问题。
    例：给定图G，找到最大团的大小。
```

### 1.3 复杂度的度量
```
时间复杂度：算法解决问题所需的计算步数。
空间复杂度：算法所需的存储空间。
```

---

## 2. 时间复杂度类

### 2.1 多项式时间
```
若存在常数k，使得算法的时间复杂度为O(n^k)，则称算法为多项式时间算法。
多项式时间算法被认为是"高效"的算法。
```

### 2.2 常见的时间复杂度类
```
O(1) - 常数时间
O(log n) - 对数时间
O(n) - 线性时间
O(n log n) - 线性对数时间
O(n^2) - 平方时间
O(n^k) - 多项式时间
O(2^n) - 指数时间
O(n!) - 阶乘时间
```

## 3. P与NP问题

### 3.1 P类
```
P类：所有可以在多项式时间内解决的判定问题的集合。
    P = {L | 存在多项式时间算法判定L}

P类问题的例子：
- 排序问题
- 最短路径问题（Dijkstra算法）
- 最大流问题
- 线性规划（使用椭球法或内点法）
```

### 3.2 NP类
```
NP类：所有可以在多项式时间内验证解的正确性的判定问题的集合。
    NP = {L | 存在多项式时间验证算法}

NP类问题的例子：
- 布尔可满足性问题（SAT）
- 旅行商问题（TSP）- 判定版本
- 最大团问题 - 判定版本
- 图着色问题
```

### 3.3 P与NP的关系
```
P ⊆ NP （若能在多项式时间内解决，则也能在多项式时间内验证）

P = NP ？ 这是计算机科学中最重要的未解决问题之一。
若P = NP，则所有NP问题都有多项式时间算法。
若P ≠ NP，则存在NP问题没有多项式时间算法。
```

## 4. NP完全性

### 4.1 多项式时间归约
```
问题A可多项式时间归约到问题B（A ≤p B）：
存在多项式时间算法将A的实例转换为B的实例，
使得A的答案为"是"当且仅当B的答案为"是"。
```

### 4.2 NP完全问题
```
问题L是NP完全的（NPC）当且仅当：
1. L ∈ NP
2. 对所有L' ∈ NP，有L' ≤p L

NP完全问题是NP类中"最难"的问题。
若任何一个NP完全问题能在多项式时间内解决，
则所有NP问题都能在多项式时间内解决（P = NP）。
```

### 4.3 第一个NP完全问题：SAT
```
Cook-Levin定理（1971）：SAT问题是NP完全的。

SAT问题：给定一个布尔公式，是否存在变量的赋值使得公式为真？
```

### 4.4 经典NP完全问题
```
1. SAT（布尔可满足性）
2. 3-SAT（每个子句最多3个文字）
3. 独立集问题
4. 顶点覆盖问题
5. 哈密顿回路问题
6. 旅行商问题（TSP）
7. 子集和问题
8. 图着色问题
9. 背包问题（判定版本）
```

## 5. NP难问题

### 5.1 NP难问题的定义
```
问题L是NP难的，若对所有L' ∈ NP，有L' ≤p L。
NP难问题不一定在NP中。

NP难问题的例子：
- 旅行商问题（优化版本）
- 最大团问题（优化版本）
- 布尔逻辑极小化问题
```

### 5.2 NP完全与NP难的关系
```
NPC = NP ∩ NP-hard

NP完全问题既是NP的，又是NP难的。
NP难问题可能不在NP中。
```

## 6. 近似算法

### 6.1 近似算法的动机
```
对于NP完全问题，不太可能存在精确的多项式时间算法。
因此需要研究近似算法，在多项式时间内找到"足够好"的解。
```

### 6.2 近似比
```
最小化问题：
算法解的代价 / 最优解的代价 ≤ ρ

最大化问题：
最优解的代价 / 算法解的代价 ≤ ρ

ρ称为近似比。
```

### 6.3 经典近似算法示例

#### 顶点覆盖问题的近似算法
```python
def vertex_cover_approx(graph):
    """顶点覆盖问题的2-近似算法"""
    cover = set()
    edges = set()
    # 收集所有边
    for u in graph:
        for v in graph[u]:
            if u < v:
                edges.add((u, v))
    
    while edges:
        u, v = edges.pop()
        cover.add(u)
        cover.add(v)
        # 移除与u或v关联的边
        to_remove = []
        for a, b in edges:
            if a == u or a == v or b == u or b == v:
                to_remove.append((a, b))
        for e in to_remove:
            edges.remove(e)
    return cover
```

## 7. 随机算法

### 7.1 随机算法的类型
```
Monte Carlo算法：
- 可能出错，但出错概率有界
- 运行时间是确定的

Las Vegas算法：
- 总是给出正确答案
- 运行时间是随机变量
```

### 7.2 复杂度类
```
RP（随机多项式时间）：
- 若答案为"是"，接受概率≥1/2
- 若答案为"否"，拒绝概率为1

co-RP：
- 若答案为"否"，拒绝概率≥1/2
- 若答案为"是"，接受概率为1

BPP（有界错误概率多项式时间）：
- 接受错误概率≤1/3
- 拒绝错误概率≤1/3

ZPP（零错误概率多项式时间）：
- RP ∩ co-RP
```

### 7.3 素性测试的随机算法
```
Miller-Rabin素性测试是一个经典的随机算法，
属于co-RP类（若输入是合数，则检测出来的概率≥1/2）。
```

## 8. 其他复杂度类

### 8.1 空间复杂度类
```
L（对数空间）：确定性图灵机，对数空间
NL（非确定对数空间）：非确定图灵机，对数空间
PSPACE（多项式空间）：多项式空间

L ⊆ NL ⊆ P ⊆ NP ⊆ PSPACE
```

### 8.2 指数时间
```
EXP（指数时间）：2^poly(n)时间
NEXP（非确定指数时间）：非确定指数时间
```

### 8.3 多项式层次
```
Σ_k^P, Π_k^P, Δ_k^P：多项式层次的第k层
P = Σ_0^P = Π_0^P
NP = Σ_1^P, co-NP = Π_1^P
```

### 8.4 复杂度类图
```
L ⊆ NL ⊆ P ⊆ NP ⊆ PSPACE ⊆ EXP ⊆ NEXP
     ⊆ co-NP ⊆
```
