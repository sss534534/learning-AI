## 2. 渐近记号

### 2.1 大O记号（O）

**定义：** f(n) = O(g(n)) 表示存在常数c, n₀ > 0，使得对于所有n ≥ n₀，有0 ≤ f(n) ≤ c·g(n)

**含义：** 上界，f(n)增长不超过g(n)

**常见大O复杂度（从快到慢）：**

```
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)
```

### 2.2 大Ω记号（Ω）

**定义：** f(n) = Ω(g(n)) 表示存在常数c, n₀ > 0，使得对于所有n ≥ n₀，有0 ≤ c·g(n) ≤ f(n)

**含义：** 下界，f(n)增长至少和g(n)一样快

### 2.3 大Θ记号（Θ）

**定义：** f(n) = Θ(g(n)) 当且仅当f(n) = O(g(n)) 且 f(n) = Ω(g(n))

**含义：** 紧确界，f(n)和g(n)同阶增长

### 2.4 小o记号（o）

**定义：** f(n) = o(g(n)) 表示对于任意常数c > 0，存在n₀ > 0，使得对于所有n ≥ n₀，有0 ≤ f(n) < c·g(n)

**含义：** 非紧上界

### 2.5 小ω记号（ω）

**定义：** f(n) = ω(g(n)) 表示对于任意常数c > 0，存在n₀ > 0，使得对于所有n ≥ n₀，有0 ≤ c·g(n) < f(n)

**含义：** 非紧下界

## 3. 时间复杂度分析

### 3.1 最坏、平均、最好情况

| 情况 | 说明 | 常用度 |
|-----|------|------|
| 最坏情况 | 最大运行时间 | ✅ 最常用 |
| 平均情况 | 期望运行时间 | ⚠️ 需概率假设 |
| 最好情况 | 最小运行时间 | ❌ 不常用 |

### 3.2 示例分析

**示例1：线性搜索**

```python
def linear_search(arr, target):
    for i in range(len(arr)):
        if arr[i] == target:
            return i
    return -1
```

- 最好情况：O(1)
- 最坏情况：O(n)
- 平均情况：O(n)

**示例2：插入排序**

```python
def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key
```

- 最好情况：O(n)（已排序）
- 最坏情况：O(n²)（逆序）
- 平均情况：O(n²)

### 3.3 常见算法复杂度

| 复杂度 | 算法示例 |
|-------|--------|
| O(1) | 数组访问、哈希表查询 |
| O(log n) | 二分查找、平衡二叉树操作 |
| O(n) | 线性搜索、简单遍历 |
| O(n log n) | 快速排序（平均）、归并排序 |
| O(n²) | 插入排序、选择排序 |
| O(n³) | 矩阵乘法 |
| O(2ⁿ) | 子集生成、暴力TSP |

## 4. 空间复杂度分析

### 4.1 空间复杂度定义

算法运行过程中临时占用的存储空间大小。

### 4.2 辅助空间

除输入输出外额外使用的空间。

**Python示例：分析空间复杂度

```python
# O(1) 空间
def sum_array(arr):
    total = 0
    for num in arr:
        total += num
    return total

# O(n) 空间（递归）
def factorial_recursive(n):
    if n <= 1:
        return 1
    return n * factorial_recursive(n - 1)

# O(n) 空间（辅助数组）
def copy_array(arr):
    new_arr = arr.copy()
    return new_arr
```

## 6. 递归式求解与Master定理

### 6.1 递归式形式

```
T(n) = aT(n/b) + f(n)
```

其中：
- a ≥ 1：子问题数
- b > 1：子问题规模缩减因子
- f(n)：分解/合并代价

### 6.2 Master定理

**情况1：** f(n) = O(n^{log_b a - ε})，则T(n) = Θ(n^{log_b a})

**情况2：** f(n) = Θ(n^{log_b a} log^k n)，则T(n) = Θ(n^{log_b a} log^{k+1} n)

**情况3：** f(n) = Ω(n^{log_b a + ε})，且a f(n/b) ≤ c f(n)，则T(n) = Θ(f(n))

### 6.3 示例

**示例1：** T(n) = 2T(n/2) + n

- log_b a = 1
- f(n) = n，情况2
- 结果：T(n) = Θ(n log n)（归并排序）

**示例2：** T(n) = T(n/2) + O(1)

- log_b a = 0
- f(n) = O(1)，情况1
- 结果：T(n) = Θ(log n)（二分查找）

**示例3：** T(n) = 3T(n/4) + n²

- log_b a = log_4 3 ≈ 0.79
- f(n) = n²，情况3
- 结果：T(n) = Θ(n²)

### 6.4 Python示例：递归式分析

```python
import math

def master_theorem(a, b, f_type, k=0):
    """
    应用Master定理
    a: 子问题数
    b: 子问题规模缩减因子
    f_type: 'polynomial', 'logarithmic', 'exponential'
    k: log的次数（f(n) = n^c log^k n）
    """
    log_b_a = math.log(a, b)
    
    print(f"T(n) = {a}T(n/{b}) + f(n)")
    print(f"log_{b}({a}) = {log_b_a}")
    
    if f_type == 'polynomial':
        c = float(input("请输入f(n) = n^c中的c: "))
        if c < log_b_a - 0.0001:
            print("情况1：T(n) = Θ(n^{log_b_a})")
        elif abs(c - log_b_a) < 0.0001:
            print(f"情况2：T(n) = Θ(n^{log_b_a} log^{k+1} n)")
        else:
            print(f"情况3：T(n) = Θ(n^{c})")
    elif f_type == 'logarithmic':
        print(f"情况2：T(n) = Θ(n^{log_b_a} log^{k+1} n)")

# 测试：归并排序
master_theorem(2, 2, 'polynomial')
```
