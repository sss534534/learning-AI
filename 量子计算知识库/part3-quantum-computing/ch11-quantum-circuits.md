## 1. 量子电路模型

### 1.1 电路表示

```
|0⟩ ─── H ─── ● ─── H ─── M ───
              │
|0⟩ ─── H ─── X ─── H ─── M ───
```

每根线表示一个量子比特，从左到右是时间顺序。

### 1.2 电路 vs 经典电路

| 特性 | 经典电路 | 量子电路 |
|------|---------|---------|
| 比特 | 0或1 | 叠加态 |
| 门 | 不可逆（AND/OR） | 可逆（酉变换） |
| 扇入 | 允许多输入 | 禁止（no-cloning） |
| 测量 | 不改变状态 | 坍缩叠加态 |
| 并行 | 有限 | 指数级并行（纠缠） |

## 2. 量子电路的组成

### 2.1 基本元素

| 符号 | 名称 | 作用 |
|------|------|------|
| ── | 量子线 | 量子比特传输 |
| ══ | 经典线 | 测量结果传输 |
| ▭ | 量子门 | 酉变换 |
| M | 测量 | 量子→经典 |
| ●─X | CNOT | 受控非门 |

### 2.2 初始化和测量

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(2, 2)  # 2量子比特，2经典比特

# 初始化到 |0⟩（默认）
# 单比特门
qc.h(0)          # Hadamard门
qc.x(1)          # Pauli-X门

# 两比特门
qc.cx(0, 1)      # CNOT：控制比特0，目标比特1

# 测量
qc.measure([0, 1], [0, 1])  # 量子比特→经典比特
```

## 3. 常用量子电路模板

### 3.1 Bell态制备

```
|0⟩ ─── H ─── ● ─────
              │
|0⟩ ───────── X ─────
```

输出：$\frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)$

### 3.2 量子隐形传态电路

```
发送方: |ψ⟩ ─── ● ─── H ─── M ──── ═══[经典通道]═══
               │
Bell态: |0⟩ ─── X ─── H ─── ● ───────── X ───── M ────
                             │              │
接收方: |0⟩ ───────────────── X ──────────── ● ──── |ψ⟩
```

### 3.3 Grover迭代（Oracle + 扩散）

```
|0⟩ ─── H ─── [Oracle] ─── H ─── X ─── [控制Z] ─── X ─── H ───
```

## 4. 量子电路的等价变换

### 4.1 门化简规则

| 规则 | 等价 |
|------|------|
| 相邻逆门抵消 | $XX = I$, $HH = I$ |
| CNOT反演 | $(CX_{01})^{-1} = CX_{01}$ |
| Hadamard共轭 | $HXH = Z$, $HZH = X$ |

### 4.2 电路优化

```python
# Qiskit电路优化
from qiskit.transpiler import PassManager
from qiskit.transpiler.passes import Optimize1qGates

pm = PassManager([Optimize1qGates()])
optimized = pm.run(qc)
```

### 4.3 通用性

任何 $n$ 量子比特酉操作可以由CNOT和单比特门构成。
