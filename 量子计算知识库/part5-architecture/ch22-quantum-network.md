## 1. 量子密钥分发

### 1.1 BB84协议

Charles Bennett 和 Gilles Brassard 于1984年提出的第一个量子密钥分发协议。

```
Alice                          Bob
  |                              |
  |--- 随机基矢编码比特 --------->|
  |<--- 公布使用基矢 ------------|
  |--- 比对基矢，保留匹配位 ---->|
  |                              |
  密钥 = 基矢匹配时的比特值
```

### 1.2 E91协议

基于纠缠的QKD协议（Ekert 1991）：

- 分发Bell对给Alice和Bob
- 各自随机选择测量基
- 比对基矢生成密钥
- 用Bell不等式检测窃听

### 1.3 QKD安全性

| 窃听策略 | 可检测性 | BB84应对 |
|---------|---------|----------|
| 拦截-重发 | ✅ | 误码率上升 |
| 纠缠-测量 | ✅ | 纠缠破坏相关 |
| 无偏基测量 | ✅ | 量子不可克隆 |

## 2. 量子隐形传态

### 2.1 协议

```
发送方                            接收方
  |                                 |
  |--- Bell态共享 ----------------->|
  |--- Bell测量 (未知态+一半Bell态) |
  |--- 经典通信 2比特 ------------->|
  |                                 | 应用纠正门 → 重建态
```

**关键：** 量子隐形传态不超光速（需要经典信道辅助），不复制量子态（No-cloning定理）。

### 2.2 实验进展

| 里程碑 | 年份 | 距离 |
|--------|------|------|
| 首次实验 | 1997 | 数米 |
| 城际隐形传态 | 2016 | 143km |
| 星地隐形传态 | 2017 (墨子号) | 1200km |

## 3. 量子中继器

解决量子信号在光纤中的指数级衰减问题：

```
Alice ── [纠缠生成] ── [纠缠交换] ── [纠缠纯化] ── Bob
```

- **纠缠生成**：相邻节点生成Bell对
- **纠缠交换**：连接远距离纠缠
- **纠缠纯化**：提升保真度

## 4. 量子互联网

### 4.1 分层架构

| 层 | 功能 | 协议 |
|------|------|------|
| 物理层 | 纠缠分发 | 光子传输 |
| 链路层 | 纠缠生成 | 纠缠协议 |
| 网络层 | 路由 | 量子路由 |
| 传输层 | 端到端 | 量子TCP |
| 应用层 | QKD/分布式QC | 应用协议 |

### 4.2 当前进展

- 量子网络正在从实验室走向城域试验（2024-2026）
- 主要障碍：量子存储时间、纠缠生成率、误码率
