# AI应用评估与测试

> 构建可靠的AI应用质量保障体系

## 1. 评估体系概述

### 1.1 AI应用评估维度

```
                    AI应用质量
                   /    |    \
                /      |      \
           功能性    非功能性   安全性
           /  |  \    |   |    |   \
         准确 相关 完整 延迟 成本 隐私 注入 合规
         性   性   性
```

| 维度 | 指标 | 评估方式 |
|------|------|----------|
| **准确性** | 答案正确率 | 人工标注+自动评估 |
| **相关性** | 答案与问题匹配度 | LLM-as-Judge |
| **完整性** | 信息覆盖度 | 人工评估 |
| **延迟** | TTFT/TPOT | 自动化测试 |
| **成本** | Token费用/请求 | 监控系统 |
| **安全性** | 注入/泄露检测 | 自动化扫描 |

## 2. 自动化评估

### 2.1 RAG评估指标

**RAGAS框架：**
```python
from ragas import evaluate
from ragas.metrics import (
    faithfulness,          # 忠实度：答案是否基于上下文
    answer_relevancy,     # 相关性：答案是否回答问题
    context_precision,     # 上下文精确率
    context_recall,        # 上下文召回率
    answer_correctness,    # 答案正确性
)

# 准备评估数据
eval_dataset = {
    "question": ["问题1", "问题2", ...],
    "answer": ["答案1", "答案2", ...],
    "contexts": [["上下文1-1", "上下文1-2"], ["上下文2-1", ...]],
    "ground_truth": ["标准答案1", "标准答案2", ...]
}

# 执行评估
result = evaluate(
    eval_dataset,
    metrics=[
        faithfulness,
        answer_relevancy,
        context_precision,
        context_recall,
    ]
)

# 输出结果
print(result)
# faithfulness: 0.85
# answer_relevancy: 0.92
# context_precision: 0.78
# context_recall: 0.65
```

**指标详解：**

| 指标 | 计算方式 | 目标值 |
|------|----------|--------|
| **Faithfulness** | 答案中的声明有多少能被上下文支持 | > 0.8 |
| **Answer Relevancy** | 答案与问题的语义相似度 | > 0.8 |
| **Context Precision** | 检索到的上下文中有多少是相关的 | > 0.7 |
| **Context Recall** | 相关上下文被检索到的比例 | > 0.6 |
| **Answer Correctness** | 与标准答案的相似度 | > 0.7 |

### 2.2 LLM-as-Judge

**用强模型评估弱模型：**
```python
JUDGE_PROMPT = """
你是一个专业的评估员。请评估以下AI回答的质量。

用户问题：{question}
AI回答：{answer}
标准答案：{ground_truth}

请从以下维度评分（1-5分）：
1. 准确性：信息是否正确
2. 完整性：是否回答了所有方面
3. 相关性：是否切题
4. 可读性：表达是否清晰

请以JSON格式输出：
{
  "accuracy": 1-5,
  "completeness": 1-5,
  "relevance": 1-5,
  "readability": 1-5,
  "overall": 1-5,
  "reason": "评分理由"
}
"""

def llm_judge(question, answer, ground_truth, judge_model):
    """使用LLM评估回答质量"""
    response = judge_model.invoke(
        JUDGE_PROMPT.format(
            question=question,
            answer=answer,
            ground_truth=ground_truth
        )
    )
    return json.loads(response.content)
```

### 2.3 自定义评估指标

**关键词匹配：**
```python
def keyword_match(answer, expected_keywords):
    """检查答案是否包含期望关键词"""
    found = []
    missing = []
    
    for keyword in expected_keywords:
        if keyword in answer:
            found.append(keyword)
        else:
            missing.append(keyword)
    
    score = len(found) / len(expected_keywords)
    return {
        "score": score,
        "found": found,
        "missing": missing
    }
```

**格式合规检查：**
```python
def format_check(answer, expected_format="json"):
    """检查输出格式是否合规"""
    try:
        if expected_format == "json":
            json.loads(answer)
            return {"valid": True, "score": 1.0}
        elif expected_format == "markdown_table":
            # 检查是否包含表格
            if "|" in answer and "---" in answer:
                return {"valid": True, "score": 1.0}
    except:
        pass
    return {"valid": False, "score": 0.0}
```

## 4. 性能测试

### 4.1 延迟测试

```python
import time
import statistics

class PerformanceTest:
    
    def test_ttft(self, service, test_queries, warmup=3):
        """测试首Token延迟（Time To First Token）"""
        times = []
        
        # 预热
        for q in test_queries[:warmup]:
            list(service.chat_stream("test", q))
        
        # 正式测试
        for query in test_queries[warmup:]:
            start = time.time()
            first_token = None
            
            for chunk in service.chat_stream("test", query):
                if first_token is None:
                    first_token = time.time()
                    times.append(first_token - start)
                    break
        
        return {
            "metric": "TTFT",
            "mean": statistics.mean(times),
            "p50": statistics.median(times),
            "p95": sorted(times)[int(len(times) * 0.95)],
            "p99": sorted(times)[int(len(times) * 0.99)],
            "samples": len(times)
        }
    
    def test_throughput(self, service, test_queries, concurrency=10):
        """测试并发吞吐量"""
        import asyncio
        
        async def single_query(query):
            start = time.time()
            await service.chat_async("test", query)
            return time.time() - start
        
        async def run_concurrent():
            tasks = [single_query(q) for q in test_queries[:concurrency]]
            times = await asyncio.gather(*tasks)
            return times
        
        times = asyncio.run(run_concurrent())
        
        return {
            "metric": "Throughput",
            "concurrency": concurrency,
            "avg_latency": statistics.mean(times),
            "p95_latency": sorted(times)[int(len(times) * 0.95)],
            "qps": concurrency / sum(times)
        }
```

## 5. 回归测试

### 5.1 评估基准

```python
class RegressionTest:
    """回归测试：确保更新不降低质量"""
    
    def __init__(self, eval_dataset, baseline_scores):
        self.dataset = eval_dataset
        self.baseline = baseline_scores
    
    def run(self, service):
        """运行回归测试"""
        results = []
        
        for sample in self.dataset:
            answer = service.query(sample.question)
            
            # 自动评估
            score = self._evaluate(answer, sample)
            baseline = self.baseline.get(sample.question, 0)
            
            results.append({
                "question": sample.question,
                "score": score,
                "baseline": baseline,
                "delta": score - baseline,
                "regression": score < baseline - 0.1  # 下降超过0.1视为回归
            })
        
        # 汇总
        regressions = [r for r in results if r["regression"]]
        
        return {
            "total": len(results),
            "regressions": len(regressions),
            "avg_score": statistics.mean([r["score"] for r in results]),
            "avg_baseline": statistics.mean([r["baseline"] for r in results]),
            "details": regressions  # 只返回有回归的
        }
```

## 6. 监控与告警

### 6.1 在线监控指标

| 指标 | 说明 | 告警阈值 |
|------|------|----------|
| **请求成功率** | 非错误响应比例 | < 99% |
| **平均延迟** | 平均响应时间 | > 5s |
| **P99延迟** | 99分位延迟 | > 15s |
| **Token用量** | 每日Token消耗 | > 预算120% |
| **用户满意度** | 👍/👎比例 | < 80% |
| **幻觉率** | 生成不实内容比例 | > 5% |

### 6.2 监控实现

```python
class AIMetricsCollector:
    """AI指标收集器"""
    
    def __init__(self, metrics_client):
        self.metrics = metrics_client
    
    def record_query(self, session_id, query, response_time, tokens_used, model):
        """记录查询指标"""
        self.metrics.histogram(
            "ai.response_time",
            response_time,
            tags={"model": model}
        )
        self.metrics.histogram(
            "ai.tokens_used",
            tokens_used,
            tags={"model": model, "type": "total"}
        )
        self.metrics.increment("ai.queries.total")
    
    def record_feedback(self, session_id, feedback):
        """记录用户反馈"""
        self.metrics.increment(
            f"ai.feedback.{feedback}"  # thumbs_up / thumbs_down
        )
    
    def record_error(self, error_type, error_message):
        """记录错误"""
        self.metrics.increment(f"ai.errors.{error_type}")
```

**陷阱1：评估集太小**
- 问题：评估结果不可靠
- 解决：至少50条，覆盖不同场景

**陷阱2：只测正常路径**
- 问题：异常情况未覆盖
- 解决：添加边界测试和错误注入

**陷阱3：忽视回归**
- 问题：更新后质量下降
- 解决：建立评估基准，每次更新前回归测试
