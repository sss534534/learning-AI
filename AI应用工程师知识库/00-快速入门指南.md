## 1. 什么是AI应用？

### 2.3 第一个Python AI应用

#### 版本1：最简单版本（10行代码）

```python
# hello_world.py
from langchain_openai import ChatOpenAI
import os

# 设置API Key
os.environ["OPENAI_API_KEY"] = "your-api-key"

# 创建LLM实例
llm = ChatOpenAI(model="gpt-4o")

# 调用LLM
response = llm.invoke("你好，请介绍一下你自己")
print(response.content)
```

**运行结果：**
```
你好！我是ChatGPT，一个由OpenAI训练的大型语言模型...
```

#### 版本2：带对话历史

```python
# chat_with_memory.py
from langchain_openai import ChatOpenAI
from langchain.memory import ConversationBufferMemory
from langchain.chains import LLMChain
from langchain.prompts import PromptTemplate

# 1. 创建内存组件
memory = ConversationBufferMemory(memory_key="chat_history", return_messages=True)

# 2. 定义Prompt模板
template = """你是一个友好的AI助手。
当前对话历史：
{chat_history}

用户: {user_input}
AI助手: """

prompt = PromptTemplate(template=template, input_variables=["user_input", "chat_history"])

# 3. 创建链
llm = ChatOpenAI(model="gpt-4o")
chain = LLMChain(llm=llm, prompt=prompt, memory=memory)

# 4. 对话
while True:
    user_input = input("你: ")
    if user_input.lower() in ["exit", "quit"]:
        break
    response = chain.invoke({"user_input": user_input})
    print(f"AI: {response['text']}")
```

#### 版本3：流式输出

```python
# streaming_chat.py
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o", stream=True)

print("AI: ", end="", flush=True)
for chunk in llm.stream("写一首关于春天的诗"):
    if chunk.content:
        print(chunk.content, end="", flush=True)
print()  # 换行
```

### 2.4 第一个Java AI应用

```java
// HelloWorldApplication.java
package com.example.ai;

import org.springframework.ai.openai.OpenAiChatClient;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@SpringBootApplication
public class HelloWorldApplication {
    
    public static void main(String[] args) {
        SpringApplication.run(HelloWorldApplication.class, args);
    }
    
    @RestController
    static class ChatController {
        
        @Autowired
        private OpenAiChatClient chatClient;
        
        @GetMapping("/chat")
        public String chat(@RequestParam String message) {
            return chatClient.call(message);
        }
    }
}
```

```yaml
# application.yml
spring:
  ai:
    openai:
      api-key: ${OPENAI_API_KEY}
      chat:
        options:
          model: gpt-4o
          temperature: 0.7
```

**启动并测试：**
```bash
# 启动应用
mvn spring-boot:run

# 测试API
curl "http://localhost:8080/chat?message=你好"
```

## 5. 常见问题FAQ

### Q1: 需要GPU吗？

**简单回答**：开发阶段不需要GPU。

- **纯API调用**：完全不需要GPU，云服务处理
- **本地模型**：需要GPU（如Ollama跑7B模型）
- **生产部署**：通常用云服务API，无需自建GPU集群

### Q2: API调用费用高吗？

**个人开发者**：月均 $10-50 可以完成大部分开发和测试。

**成本优化策略**：
- 开发用小模型（gpt-4o-mini）
- 生产缓存热点问题
- 敏感数据用本地模型

### Q3: Python还是Java？

**选择建议**：
- **快速学习/原型** → Python
- **企业Java系统** → Java
- **长期项目** → 根据团队技术栈决定

### Q4: 如何选择LLM？

| 维度 | 推荐模型 |
|------|----------|
| 综合能力最强 | GPT-4o |
| 性价比最高 | DeepSeek V3 |
| 中文场景 | 智谱GLM-4 / Qwen |
| 长上下文 | Claude-3.5 / Kimi |
| 开源私有部署 | Qwen-72B / Llama-3 |

### Q5: RAG还是Fine-tuning？

| 场景 | 推荐方案 |
|------|----------|
| 知识库问答 | RAG ✅ |
| 特定风格 | Prompt优化 |
| 特定任务 | Fine-tuning |
| 最新信息 | RAG ✅ |
| 私有领域 | RAG / Fine-tuning |
