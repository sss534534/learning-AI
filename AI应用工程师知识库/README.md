## 🛠️ 技术栈速查

### Python生态

| 技术领域 | 推荐方案 | 备选方案 |
|---------|---------|----------|
| **LLM框架** | LangChain / LangGraph | LlamaIndex / CrewAI |
| **Agent框架** | LangGraph | CrewAI / AutoGen |
| **向量数据库** | Milvus / Chroma | pgvector / Pinecone |
| **Embedding** | text-embedding-3 | BGE-M3 / Jina |
| **Web框架** | FastAPI | Streamlit / Gradio |
| **评估工具** | RAGAS / DeepEval | 自研 |

### Java生态

| 技术领域 | 推荐方案 | 备选方案 |
|---------|---------|----------|
| **LLM框架** | Spring AI | LangChain4j |
| **向量数据库** | Milvus | pgvector |
| **Embedding** | OpenAI / BGE-M3 | 自托管 |
| **Web框架** | Spring Boot | - |

### 技术选型建议

| 场景 | 推荐技术栈 | 成本 |
|------|-----------|------|
| 快速原型 | Python + LangChain + Chroma | 低 |
| 生产RAG系统 | Python + LangGraph + Milvus | 中 |
| 企业Java系统 | Java + Spring AI + pgvector | 中 |
| 多Agent协作 | Python + CrewAI / LangGraph | 中 |
| 成本敏感 | DeepSeek / Qwen + 缓存优化 | 低 |
