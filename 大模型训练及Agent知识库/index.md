# 大模型训练及Agent系统知识库

> 本知识库系统梳理了大型语言模型（LLM）的完整训练流程以及基于LLM的Agent系统设计与实现。内容涵盖从预训练到对齐的全流程技术，以及Agent架构、工具调用、记忆系统、多Agent协作等核心概念。

## 学习路径建议

### 路径一：大模型训练工程师

1. **基础阶段**：深度学习基础、Transformer架构
2. **预训练阶段**：数据工程、分布式训练、显存优化
3. **对齐阶段**：SFT、LoRA、RLHF/DPO
4. **部署阶段**：量化、推理优化、服务化

### 路径二：Agent系统开发者

1. **基础阶段**：Prompt Engineering、Function Calling
2. **架构阶段**：ReAct、Plan-and-Execute、记忆系统设计
3. **工具阶段**：工具定义、API集成、错误处理
4. **高级阶段**：多Agent协作、框架应用

### 路径三：全栈AI工程师

结合以上两条路径，掌握从模型训练到Agent应用的全流程。
