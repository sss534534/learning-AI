## 1. 为什么AI合规是架构师的必修课

2025-2026年，全球AI监管从"建议"变成了"法律"。不遵守合规要求不再是"违规"，而是"违法"——罚款可达全球年营收的7% (EU AI Act) 或5000万元 (中国)。

> 合规不是法务部门的事——架构选择直接决定了系统能否合规。

**三大司法管辖区的监管强度**:
```
              欧盟          中国          美国
监管模式      风险分级      全链条监管    行业+自愿
立法状态      已生效        已生效        行政令+州法
最高罚款      3500万€/7%   5000万¥       暂无统一
关键法规      AI Act       生成式AI办法   EO 14110
生效时间      2024-2026     2023.8        2023.10
覆盖范围      所有AI系统    生成式AI      联邦机构
```

### 3.2 生成式AI合规核心义务

```yaml
中国生成式AI合规义务清单:

  算法备案 (必须):
    - 向网信办完成算法备案
    - 公开算法基本原理、目的意图、运行机制
    - 备案信息变更时更新
    - 时限: 提供服务前完成，存量服务有过渡期
  
  内容安全 (必须):
    - 不得生成违法违规内容
    - 不得生成颠覆国家政权、分裂国家内容
    - 不得生成恐怖主义、极端主义内容
    - 不得生成民族仇恨、民族歧视内容
    - 不得生成暴力、淫秽、色情内容
    - 不得生成虚假有害信息
    - 建立内容过滤和应急处置机制
  
  训练数据合规 (必须):
    - 使用合法来源数据
    - 不得侵害知识产权
    - 数据中包含个人信息需经同意或匿名化
    - 提高训练数据的真实性、准确性、多样性
  
  标注规范 (必须):
    - 制定清晰、具体、可操作的标注规则
    - 对标注人员进行必要培训
    - 抽样核验标注内容质量
  
  用户权益保护 (必须):
    - 提供防沉迷措施
    - 设置未成年人保护模式
    - 保障用户申诉、投诉渠道
    - 不得进行算法歧视
  
  透明度义务 (必须):
    - 标识AI生成内容 (水印/标注)
    - 告知用户服务由AI提供
    - 说明服务局限性和潜在风险
```

## 6. 隐私合规

### 6.1 AI系统的隐私全景

```
AI系统数据流中的隐私风险点:

数据收集 → 数据存储 → 模型训练 → 模型推理 → 输出生成
   ↓          ↓          ↓          ↓          ↓
[PII采集]  [加密存]   [PII记忆]  [推理侧]   [PII泄露]
[同意获取] [最小化]   [差分隐私] [分析攻击] [输出过滤]
[匿名化]   [访问控]   [联邦学习] [模型提取] [事后审查]

关键隐私法规要求:
GDPR: 目的限制、数据最小化、遗忘权、DPIA
PIPL: 告知-同意、敏感信息保护、跨境传输评估
CCPA/CPRA: opt-out权、删除权、自动化决策说明
```

### 6.2 技术实现 — 差分隐私 + 联邦学习

```python
# 差分隐私训练（确保单个样本不影响模型输出）
import torch
from opacus import PrivacyEngine

def train_with_dp(model, train_loader, target_epsilon=8.0, target_delta=1e-5):
    """
    (ε, δ)-差分隐私训练
    
    ε (epsilon): 隐私预算，越小越私密 (通常 1-10)
    δ (delta): 失败概率，通常 1/数据集大小
    """
    privacy_engine = PrivacyEngine()
    
    model, optimizer, train_loader = privacy_engine.make_private(
        module=model,
        optimizer=optimizer,
        data_loader=train_loader,
        noise_multiplier=1.0,
        max_grad_norm=1.0,  # 梯度裁剪阈值
    )
    
    for epoch in range(epochs):
        for batch in train_loader:
            optimizer.zero_grad()
            loss = model(batch)
            loss.backward()
            optimizer.step()  # Opacus自动添加噪声 + 裁剪
        
        epsilon = privacy_engine.get_epsilon(delta=target_delta)
        print(f"Epoch {epoch}: ε = {epsilon:.2f}")
        
        if epsilon > target_epsilon:
            break  # 隐私预算耗尽
    
    return model

# PII检测和脱敏
from presidio_analyzer import AnalyzerEngine
from presidio_anonymizer import AnonymizerEngine

def sanitize_training_data(text: str) -> str:
    """训练数据PII脱敏"""
    analyzer = AnalyzerEngine()
    anonymizer = AnonymizerEngine()
    
    # 检测PII实体
    results = analyzer.analyze(
        text=text,
        entities=["PERSON", "PHONE_NUMBER", "EMAIL_ADDRESS", 
                  "CREDIT_CARD", "LOCATION", "ID_NUMBER"],
        language="zh"
    )
    
    # 脱敏处理
    anonymized = anonymizer.anonymize(
        text=text,
        analyzer_results=results,
        operators={
            "PERSON": {"type": "replace", "new_value": "[姓名]"},
            "PHONE_NUMBER": {"type": "mask", "masking_char": "*", "chars_to_mask": 7},
            "EMAIL_ADDRESS": {"type": "replace", "new_value": "[邮箱]"},
        }
    )
    
    return anonymized.text
```

### 8.1 合规即代码

```python
# 合规要求编码为自动化检查
class ComplianceGateway:
    """
    将合规要求嵌入到AI系统的CICD和运行流程中
    """
    
    def pre_deployment_check(self, model_artifact: ModelArtifact) -> ComplianceReport:
        """部署前合规检查"""
        
        checks = {
            "content_filter_configured": self._check_content_filter(model_artifact),
            "safety_eval_completed": self._check_safety_eval(model_artifact),
            "model_card_exists": self._check_model_card(model_artifact),
            "bias_audit_passed": self._check_bias_audit(model_artifact),
            "data_governance_verified": self._check_data_governance(model_artifact),
            "age_verification_configured": self._check_age_verification(model_artifact),
            "output_watermark_enabled": self._check_output_watermark(model_artifact),
            "logging_audit_trail": self._check_audit_logging(model_artifact),
            "incident_response_plan": self._check_incident_plan(model_artifact),
        }
        
        failed = [name for name, passed in checks.items() if not passed]
        
        return ComplianceReport(
            passed=len(failed) == 0,
            failed_checks=failed,
            recommendations=[self._get_recommendation(f) for f in failed]
        )
    
    def runtime_compliance_monitor(self, request: AIRequest, response: AIResponse):
        """运行时合规监控"""
        
        # 1. 记录审计日志 (不可变)
        self.audit_log.append({
            "timestamp": datetime.now().isoformat(),
            "request_id": request.id,
            "user_id": request.user_id_hashed,  # 哈希脱敏
            "model": request.model,
            "prompt_length": len(request.content),
            "output_length": len(response.content),
            "safety_flags": response.safety_flags,
        })
        
        # 2. 实时合规检查
        violations = []
        
        # 检查输出内容
        if response.toxicity_score > self.toxicity_threshold:
            violations.append("toxicity_exceeded")
        
        # 检查PII泄露
        if self._contains_pii(response.content):
            violations.append("pii_in_output")
        
        # 检查年龄限制
        if request.user_age and request.user_age < self.min_age:
            violations.append("underage_user")
        
        # 处理违规
        if violations:
            self._handle_violations(request, violations)
```

### 8.2 合规审计证据链

```python
# 不可变的合规审计链
class AuditTrail:
    """
    基于区块链或WAL的不可变审计日志
    
    关键属性:
    - 不可篡改
    - 时间戳不可回退
    - 完整事件链
    """
    
    def record_decision(self, decision: AIDecision) -> AuditEntry:
        """记录AI决策过程，形成审计证据链"""
        entry = AuditEntry(
            entry_id=uuid.uuid4(),
            timestamp=datetime.now(timezone.utc),
            decision_type=decision.type,  # "content_filter", "model_route", ...
            input_hash=hashlib.sha256(decision.input.encode()).hexdigest(),
            output_hash=hashlib.sha256(decision.output.encode()).hexdigest(),
            model_version=decision.model_version,
            policy_version=decision.policy_version,
            rationale=decision.rationale,  # 为什么做这个决策
            human_review=decision.requires_human_review,
            previous_entry_hash=self.last_hash,  # 链式哈希
        )
        
        # 计算本条哈希
        entry.hash = self._compute_hash(entry)
        self.last_hash = entry.hash
        
        # 写入不可变存储
        self.wal.append(entry)
        
        return entry
    
    def verify_chain(self) -> bool:
        """验证审计链完整性"""
        for i in range(1, len(self.wal)):
            if self.wal[i].previous_entry_hash != self.wal[i-1].hash:
                return False
        return True
```
