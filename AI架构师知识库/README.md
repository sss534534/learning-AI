### 学习路径建议

**按背景选择路径：**

```
后端/微服务转AI:
  01(LLM基础) → 02(模型工程化) → 05(基础设施) → 03(RAG) → 06(LLMOps) → 04(Agent) → 07(案例) → 08(模式)
  利用现有分布式/微服务经验，优先补GPU调度和模型服务

算法/ML工程转AI架构:
  01(LLM基础) → 02(模型工程化) → 03(RAG) → 05(基础设施) → 04(Agent) → 06(LLMOps) → 08(模式) → 07(案例)
  优先补推理优化和系统架构，算法背景理解模型原理更快

全栈/创业/产品转AI:
  03(RAG) → 04(Agent) → 07(案例) → 09(框架生态) → 01(LLM基础) → 08(模式) → 02(模型工程化)
  优先出活，再补深度
```

**通用路径（不分背景，按6个月规划）：**

| 阶段 | 模块 | 目标 | 时间 |
|------|------|------|------|
| **基础夯实** | 01-LLM基础理论 → 03-RAG架构设计 | 理解Transformer、推理模型、RAG核心模式 | 第1-2月 |

| **贯穿全程** | 07-架构案例 → 08-架构模式 | 案例中验证模式，模式下指导案例 | 持续 |
