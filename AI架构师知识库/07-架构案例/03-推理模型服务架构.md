# 案例五：推理模型服务架构

> 推理模型（Reasoning Model）生产级服务架构：双阶段流式输出、推理预算路由、混合推理协同

## 1. 项目背景

### 1.1 业务需求

**场景：** AI平台服务商，同时提供标准LLM与推理模型服务

**痛点：**
- 推理模型thinking tokens不可预测，成本爆炸风险高
- 80%请求不需要深度推理，但缺乏智能路由机制
- thinking阶段长延迟导致用户体验差（黑屏等待）
- 推理模型与标准模型各自独立，无法协同工作
- KV Cache峰值是标准模型的10-50倍，GPU资源规划困难

**目标：**
- 智能路由：简单问题走快速模型，复杂问题走推理模型，整体成本降低60%
- 双阶段流式输出：thinking阶段实时可见，消除黑屏等待
- 混合推理：推理模型规划 + 标准模型执行，成本降低50%同时保持质量
- 生产级部署：vLLM/SGLang推理模型部署、监控、成本控制一体化

### 1.2 技术约束

| 约束 | 要求 |
|------|------|
| 推理模型 | DeepSeek R1-671B / QwQ-32B / OpenAI o4-mini |
| 标准模型 | Qwen2.5-72B / GPT-4o-mini |
| 延迟 | 简单问题 < 2s，推理问题 < 60s |
| 可用性 | 99.9% |
| 成本 | 推理模型请求占比 < 20% |
| 流式输出 | SSE协议，thinking/answer双阶段分离 |

### 2.2 核心设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 推理框架 | vLLM + SGLang | vLLM生态成熟，SGLang原生支持thinking token |
| 路由策略 | 分类器+规则混合 | 纯规则精度不足，纯分类器延迟高 |
| 流式协议 | SSE双事件类型 | thinking/answer分离，前端可差异化渲染 |
| 混合编排 | 推理模型规划+快速模型执行 | 兼顾推理深度与执行效率 |
| 成本控制 | 多层防护（请求级+用户级+系统级） | thinking tokens不可预测，需多级保障 |

### 2.3 推理模型 vs 标准模型的服务差异

```
标准LLM服务模式：
  请求 ──► [Prefill] ──► [Decode] ──► 响应
            ~100ms       ~1-5s       总延迟: 1-5s

推理模型服务模式：
  请求 ──► [Prefill] ──► [Thinking Decode] ──► [Output Decode] ──► 响应
            ~100ms         ~5-120s              ~1-5s            总延迟: 5-120s
```

| 维度 | 标准LLM | 推理模型 |
|------|---------|----------|
| 典型延迟 | 1-5秒 | 5-120秒 |
| 延迟方差 | 小（±1s） | 大（±30s+） |
| 输出token数 | 100-2000 | 1000-100000+ |
| KV Cache峰值 | 1x | 10-50x |
| GPU显存占用 | 稳定 | 波动大 |
| 超时风险 | 低 | 高 |
| 流式需求 | 可选 | 必须 |
| 成本可控性 | 高 | 低（thinking tokens不可预测） |
| 请求并发 | 高吞吐 | 低吞吐（长连接占用） |

## 3. 双阶段流式输出

### 3.1 Thinking/Answer分离输出架构

推理模型的输出天然分为两个阶段：thinking阶段（思维链推理）和answer阶段（最终答案）。分离输出是提升用户体验和实现精细化控制的基础。

```
┌──────────────────────────────────────────────────────────────────┐
│                    双阶段流式输出架构                               │
│                                                                  │
│  模型推理引擎                                                     │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  Token Stream: [think_start] [t1][t2]...[tn] [think_end] │   │
│  │                              [a1][a2]...[am] [eos]       │   │
│  └──────────────────────┬───────────────────────────────────┘   │
│                         ↓                                        │
│  Token分类器                                                      │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  状态机:                                                  │   │
│  │  IDLE ──► THINKING ──► ANSWERING ──► DONE                │   │
│  │    │          │            │           │                   │   │
│  │    │ <think()>  </think()>  <eos>      │                   │   │
│  │    │          │            │           │                   │   │
│  │    ↓          ↓            ↓           ↓                   │   │
│  │  丢弃      thinking流    answer流     完成                 │   │
│  └──────────────────────┬───────────────────────────────────┘   │
│                         ↓                                        │
│  SSE编码器                                                        │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  event: thinking  →  thinking tokens实时推送              │   │
│  │  event: thinking_done  →  thinking阶段结束                │   │
│  │  event: answer  →  answer tokens实时推送                  │   │
│  │  event: done  →  全部完成，附带token统计                   │   │
│  └──────────────────────┬───────────────────────────────────┘   │
│                         ↓                                        │
│  ┌──────────┐                              ┌──────────┐         │
│  │ 前端渲染  │  ←── SSE事件流 ──────────►  │ 前端渲染  │         │
│  │ Thinking │                              │ Answer   │         │
│  │ 折叠面板  │                              │ 主内容区  │         │
│  └──────────┘                              └──────────┘         │
└──────────────────────────────────────────────────────────────────┘
```

### 3.3 后端流式输出实现

```python
import asyncio
import json
import time
from enum import Enum
from dataclasses import dataclass, field
from typing import AsyncIterator


class Phase(str, Enum):
    IDLE = "idle"
    THINKING = "thinking"
    ANSWER = "answer"
    DONE = "done"


@dataclass
class StreamState:
    phase: Phase = Phase.IDLE
    thinking_tokens: int = 0
    answer_tokens: int = 0
    thinking_start_time: float = 0.0
    answer_start_time: float = 0.0
    budget_remaining: int = 0


class DualPhaseStreamProcessor:
    """双阶段流式处理器"""

    THINK_START_MARKERS = ["<think()>", "<think >", "<|think_start|>"]
    THINK_END_MARKERS = ["</think()>", "</think >", "<|think_end|>"]

    def __init__(self, max_thinking_tokens: int = 10000):
        self.max_thinking_tokens = max_thinking_tokens
        self.state = StreamState(budget_remaining=max_thinking_tokens)

    async def process_stream(
        self, token_stream: AsyncIterator[str], request_id: str, model: str
    ) -> AsyncIterator[str]:
        self.state.thinking_start_time = time.time()

        async for token in token_stream:
            if self._is_think_start(token):
                self.state.phase = Phase.THINKING
                continue

            if self._is_think_end(token):
                yield self._format_thinking_done()
                self.state.phase = Phase.ANSWER
                self.state.answer_start_time = time.time()
                continue

            if self.state.phase == Phase.THINKING:
                self.state.thinking_tokens += 1
                self.state.budget_remaining -= 1

                if self.state.thinking_tokens >= self.max_thinking_tokens:
                    yield self._format_thinking_done()
                    self.state.phase = Phase.ANSWER
                    self.state.answer_start_time = time.time()
                    continue

                yield self._format_thinking_event(token)

            elif self.state.phase == Phase.ANSWER:
                self.state.answer_tokens += 1
                yield self._format_answer_event(token)

        yield self._format_answer_done()
        yield self._format_done(request_id, model)

    def _is_think_start(self, token: str) -> bool:
        return any(marker in token for marker in self.THINK_START_MARKERS)

    def _is_think_end(self, token: str) -> bool:
        return any(marker in token for marker in self.THINK_END_MARKERS)

    def _format_thinking_event(self, token: str) -> str:
        data = {
            "token": token,
            "index": self.state.thinking_tokens - 1,
            "accumulated_tokens": self.state.thinking_tokens,
            "budget_remaining": self.state.budget_remaining,
        }
        return f"event: thinking\ndata: {json.dumps(data, ensure_ascii=False)}\n\n"

    def _format_thinking_done(self) -> str:
        duration_ms = int((time.time() - self.state.thinking_start_time) * 1000)
        budget_pct = (
            self.state.thinking_tokens / self.max_thinking_tokens * 100
            if self.max_thinking_tokens > 0
            else 0
        )
        data = {
            "total_thinking_tokens": self.state.thinking_tokens,
            "thinking_duration_ms": duration_ms,
            "budget_used_percent": round(budget_pct, 1),
        }
        return f"event: thinking_done\ndata: {json.dumps(data)}\n\n"

    def _format_answer_event(self, token: str) -> str:
        data = {
            "token": token,
            "index": self.state.answer_tokens - 1,
        }
        return f"event: answer\ndata: {json.dumps(data, ensure_ascii=False)}\n\n"

    def _format_answer_done(self) -> str:
        data = {"total_answer_tokens": self.state.answer_tokens}
        return f"event: answer_done\ndata: {json.dumps(data)}\n\n"

    def _format_done(self, request_id: str, model: str) -> str:
        total_duration_ms = int(
            (time.time() - self.state.thinking_start_time) * 1000
        )
        data = {
            "request_id": request_id,
            "model": model,
            "thinking_tokens": self.state.thinking_tokens,
            "answer_tokens": self.state.answer_tokens,
            "total_tokens": self.state.thinking_tokens + self.state.answer_tokens,
            "total_duration_ms": total_duration_ms,
            "estimated_cost": self._estimate_cost(),
        }
        return f"event: done\ndata: {json.dumps(data)}\n\n"

    def _estimate_cost(self) -> float:
        pricing = MODEL_PRICING.get(self.state.phase, {})
        input_cost = 0
        thinking_cost = self.state.thinking_tokens * pricing.get("thinking_per_m", 0) / 1_000_000
        output_cost = self.state.answer_tokens * pricing.get("output_per_m", 0) / 1_000_000
        return round(input_cost + thinking_cost + output_cost, 6)


MODEL_PRICING = {
    Phase.THINKING: {"thinking_per_m": 2.0, "output_per_m": 8.0},
    Phase.ANSWER: {"thinking_per_m": 2.0, "output_per_m": 8.0},
}
```

### 3.4 前端渲染方案

**React组件实现：**

```tsx
import React, { useState, useEffect, useRef } from "react";

interface ThinkingAnswerRendererProps {
  sseUrl: string;
  requestId: string;
}

interface StreamState {
  thinkingContent: string;
  answerContent: string;
  phase: "thinking" | "thinking_done" | "answer" | "done";
  thinkingTokens: number;
  thinkingDurationMs: number;
  budgetUsedPercent: number;
}

export function ThinkingAnswerRenderer({
  sseUrl,
  requestId,
}: ThinkingAnswerRendererProps) {
  const [state, setState] = useState<StreamState>({
    thinkingContent: "",
    answerContent: "",
    phase: "thinking",
    thinkingTokens: 0,
    thinkingDurationMs: 0,
    budgetUsedPercent: 0,
  });

  const [showThinking, setShowThinking] = useState(false);
  const answerRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const eventSource = new EventSource(`${sseUrl}?request_id=${requestId}`);

    eventSource.addEventListener("thinking", (e) => {
      const data = JSON.parse(e.data);
      setState((prev) => ({
        ...prev,
        phase: "thinking",
        thinkingContent: prev.thinkingContent + data.token,
        thinkingTokens: data.accumulated_tokens,
      }));
    });

    eventSource.addEventListener("thinking_done", (e) => {
      const data = JSON.parse(e.data);
      setState((prev) => ({
        ...prev,
        phase: "thinking_done",
        thinkingTokens: data.total_thinking_tokens,
        thinkingDurationMs: data.thinking_duration_ms,
        budgetUsedPercent: data.budget_used_percent,
      }));
    });

    eventSource.addEventListener("answer", (e) => {
      const data = JSON.parse(e.data);
      setState((prev) => ({
        ...prev,
        phase: "answer",
        answerContent: prev.answerContent + data.token,
      }));
      answerRef.current?.scrollIntoView({ behavior: "smooth" });
    });

    eventSource.addEventListener("done", () => {
      setState((prev) => ({ ...prev, phase: "done" }));
      eventSource.close();
    });

    return () => eventSource.close();
  }, [sseUrl, requestId]);

  return (
    <div className="reasoning-output">
      {state.phase === "thinking" && (
        <div className="thinking-indicator">
          <span className="pulse-dot" />
          <span>深度思考中...</span>
          <span className="token-count">{state.thinkingTokens} tokens</span>
        </div>
      )}

      <div className="thinking-section">
        <button
          className="thinking-toggle"
          onClick={() => setShowThinking(!showThinking)}
        >
          {showThinking ? "▼" : "▶"} 思考过程
          {state.thinkingTokens > 0 && (
            <span className="thinking-meta">
              {state.thinkingTokens} tokens · {(state.thinkingDurationMs / 1000).toFixed(1)}s
            </span>
          )}
        </button>

        {showThinking && (
          <div className="thinking-content">
            <pre>{state.thinkingContent}</pre>
          </div>
        )}
      </div>

      <div className="answer-section" ref={answerRef}>
        <div className="answer-content">
          {state.answerContent || (
            state.phase === "thinking" ? "" : "等待回答..."
          )}
        </div>
      </div>
    </div>
  );
}
```

### 3.5 流式输出策略对比

| 策略 | 用户体验 | 实现复杂度 | Token开销 | 适用场景 |
|------|----------|-----------|----------|----------|
| 全量等待 | 差（黑屏10-120s） | 低 | 无额外 | 批处理、后台任务 |

### 4.2 问题复杂度分类器

```python
import re
from dataclasses import dataclass
from enum import Enum
from typing import Optional


class Complexity(str, Enum):
    SIMPLE = "simple"
    MEDIUM = "medium"
    COMPLEX = "complex"


@dataclass
class RoutingDecision:
    complexity: Complexity
    model: str
    max_thinking_tokens: int
    reasoning_effort: str
    estimated_cost_multiplier: float
    estimated_latency_s: float
    route_reason: str


class ComplexityClassifier:
    """问题复杂度分类器"""

    COMPLEXITY_KEYWORDS = {
        Complexity.COMPLEX: [
            "证明", "推导", "优化", "设计一个", "架构",
            "分析", "比较", "评估", "为什么", "如何实现",
            "debug", "optimize", "prove", "design", "architect",
            "analyze", "compare", "evaluate", "implement",
        ],
        Complexity.MEDIUM: [
            "解释", "计算", "编写", "实现", "翻译",
            "总结", "归纳", "explain", "calculate", "write",
            "implement", "summarize",
        ],
        Complexity.SIMPLE: [
            "什么是", "定义", "翻译", "格式化", "列表",
            "what is", "define", "translate", "format", "list",
        ],
    }

    MATH_PATTERNS = [
        r"∫|∑|∏|∂|∇|lim|sin|cos|log|√",
        r"方程|不等式|矩阵|概率|统计",
        r"integral|derivative|equation|matrix|probability",
    ]

    CODE_PATTERNS = [
        r"def |class |function |import |return ",
        r"算法|排序|搜索|递归|动态规划",
        r"algorithm|sort|search|recursion|dp",
    ]

    def classify(self, query: str, context: dict = None) -> Complexity:
        scores = {c: 0 for c in Complexity}

        for complexity, keywords in self.COMPLEXITY_KEYWORDS.items():
            for kw in keywords:
                if kw.lower() in query.lower():
                    scores[complexity] += 1

        if any(re.search(p, query) for p in self.MATH_PATTERNS):
            scores[Complexity.COMPLEX] += 3

        if any(re.search(p, query) for p in self.CODE_PATTERNS):
            scores[Complexity.MEDIUM] += 2

        query_len = len(query)
        if query_len > 500:
            scores[Complexity.COMPLEX] += 2
        elif query_len > 200:
            scores[Complexity.MEDIUM] += 1

        if context:
            if context.get("has_attachments"):
                scores[Complexity.COMPLEX] += 1
            if context.get("multi_step"):
                scores[Complexity.COMPLEX] += 2
            if context.get("requires_verification"):
                scores[Complexity.MEDIUM] += 1

        if scores[Complexity.COMPLEX] >= 3:
            return Complexity.COMPLEX
        elif scores[Complexity.MEDIUM] >= 2:
            return Complexity.MEDIUM
        else:
            return Complexity.SIMPLE


class ReasoningBudgetRouter:
    """推理预算路由器"""

    ROUTING_TABLE = {
        Complexity.SIMPLE: {
            "model": "qwen2.5-72b",
            "max_thinking_tokens": 0,
            "reasoning_effort": "none",
            "cost_multiplier": 1.0,
            "latency_s": 2.0,
        },
        Complexity.MEDIUM: {
            "model": "deepseek-r1-671b",
            "max_thinking_tokens": 5000,
            "reasoning_effort": "low",
            "cost_multiplier": 5.0,
            "latency_s": 25.0,
        },
        Complexity.COMPLEX: {
            "model": "deepseek-r1-671b",
            "max_thinking_tokens": 30000,
            "reasoning_effort": "high",
            "cost_multiplier": 20.0,
            "latency_s": 90.0,
        },
    }

    def __init__(self):
        self.classifier = ComplexityClassifier()
        self.rule_engine = RuleEngine()
        self.user_overrides: dict = {}

    def route(self, query: str, context: dict = None) -> RoutingDecision:
        rule_result = self.rule_engine.match(query, context)
        if rule_result:
            return rule_result

        user_id = (context or {}).get("user_id")
        if user_id and user_id in self.user_overrides:
            complexity = self.user_overrides[user_id]
        else:
            complexity = self.classifier.classify(query, context)

        config = self.ROUTING_TABLE[complexity]

        return RoutingDecision(
            complexity=complexity,
            model=config["model"],
            max_thinking_tokens=config["max_thinking_tokens"],
            reasoning_effort=config["reasoning_effort"],
            estimated_cost_multiplier=config["cost_multiplier"],
            estimated_latency_s=config["latency_s"],
            route_reason=f"complexity={complexity.value}",
        )


class RuleEngine:
    """规则引擎"""

    RULES = [
        {
            "name": "sensitive_data",
            "condition": lambda q, c: c and c.get("contains_sensitive", False),
            "decision": RoutingDecision(
                complexity=Complexity.SIMPLE,
                model="self-hosted-qwen-72b",
                max_thinking_tokens=0,
                reasoning_effort="none",
                estimated_cost_multiplier=1.0,
                estimated_latency_s=2.0,
                route_reason="rule:sensitive_data",
            ),
        },
        {
            "name": "math_competition",
            "condition": lambda q, c: any(
                kw in q for kw in ["竞赛", "competition", "IMO", "ACM"]
            ),
            "decision": RoutingDecision(
                complexity=Complexity.COMPLEX,
                model="deepseek-r1-671b",
                max_thinking_tokens=50000,
                reasoning_effort="high",
                estimated_cost_multiplier=25.0,
                estimated_latency_s=120.0,
                route_reason="rule:math_competition",
            ),
        },
        {
            "name": "simple_qa",
            "condition": lambda q, c: len(q) < 20 and any(
                kw in q for kw in ["是什么", "什么是", "what is"]
            ),
            "decision": RoutingDecision(
                complexity=Complexity.SIMPLE,
                model="qwen2.5-72b",
                max_thinking_tokens=0,
                reasoning_effort="none",
                estimated_cost_multiplier=1.0,
                estimated_latency_s=1.5,
                route_reason="rule:simple_qa",
            ),
        },
    ]

    def match(self, query: str, context: dict = None) -> Optional[RoutingDecision]:
        for rule in self.RULES:
            if rule["condition"](query, context):
                return rule["decision"]
        return None

### 4.3 自适应预算调整

```python
class AdaptiveBudgetController:
    """自适应推理预算控制器"""

    def __init__(self):
        self.confidence_threshold_high = 0.9
        self.confidence_threshold_low = 0.5
        self.early_stop_patience = 50

    def should_stop_thinking(
        self,
        thinking_tokens_so_far: int,
        min_thinking_tokens: int,
        confidence_scores: list[float],
    ) -> dict:
        if thinking_tokens_so_far < min_thinking_tokens:
            return {"should_stop": False, "reason": "below_minimum"}

        if not confidence_scores:
            return {"should_stop": False, "reason": "no_confidence_data"}

        recent_confidence = confidence_scores[-self.early_stop_patience:]

        if len(recent_confidence) >= 10:
            avg_recent = sum(recent_confidence[-10:]) / 10
            if avg_recent > self.confidence_threshold_high:
                return {
                    "should_stop": True,
                    "reason": "high_confidence_early_stop",
                    "confidence": avg_recent,
                }

        if len(recent_confidence) >= 20:
            first_half = recent_confidence[:10]
            second_half = recent_confidence[10:20]
            avg_first = sum(first_half) / len(first_half)
            avg_second = sum(second_half) / len(second_half)
            if avg_second <= avg_first * 1.01:
                return {
                    "should_stop": True,
                    "reason": "diminishing_returns",
                    "confidence": avg_second,
                }

        return {"should_stop": False, "reason": "continuing"}
```

### 5.2 混合推理编排器

```python
import json
from dataclasses import dataclass
from enum import Enum
from typing import Any, Optional


class TaskPhase(str, Enum):
    PLAN = "plan"
    EXECUTE = "execute"
    VERIFY = "verify"


@dataclass
class PlanResult:
    plan: str
    structured_plan: dict
    thinking_tokens: int
    plan_tokens: int


@dataclass
class ExecutionResult:
    output: str
    execution_tokens: int


@dataclass
class VerificationResult:
    passed: bool
    issues: list[str]
    verification_tokens: int


@dataclass
class HybridInferenceResult:
    plan: str
    structured_plan: dict
    execution_output: str
    verification: Optional[VerificationResult]
    total_thinking_tokens: int
    total_execution_tokens: int
    total_cost: float
    total_latency_ms: int


class HybridInferenceOrchestrator:
    """混合推理编排器"""

    PLAN_PROMPT_TEMPLATE = """你是一个系统架构师。请对以下任务进行深度分析和规划。

任务: {task}

请输出结构化的规划方案，包含:
1. 分析: 问题的核心挑战
2. 方案: 推荐的解决方案
3. 步骤: 具体执行步骤
4. 注意事项: 关键风险和约束

请以JSON格式输出规划方案。"""

    EXECUTE_PROMPT_TEMPLATE = """根据以下规划方案，执行具体实现。

规划方案:
{plan}

请按照规划步骤，完成具体实现。要求:
- 代码完整可运行
- 包含必要注释
- 遵循最佳实践"""

    VERIFY_PROMPT_TEMPLATE = """请验证以下实现是否正确完成了规划方案。

规划方案:
{plan}

实现内容:
{execution}

请检查:
1. 是否覆盖了所有规划步骤
2. 是否存在逻辑错误
3. 是否遗漏了关键约束
输出JSON: {{"passed": bool, "issues": [...]}}"""

    def __init__(
        self,
        reasoning_model_client: Any,
        standard_model_client: Any,
        enable_verification: bool = True,
    ):
        self.reasoning_model = reasoning_model_client
        self.standard_model = standard_model_client
        self.enable_verification = enable_verification

    async def execute(self, task: str, context: dict = None) -> HybridInferenceResult:
        import time
        start_time = time.time()

        plan_result = await self._plan_phase(task, context)

        execution_result = await self._execute_phase(
            plan_result.plan, plan_result.structured_plan, context
        )

        verification_result = None
        if self.enable_verification:
            verification_result = await self._verify_phase(
                plan_result.plan, execution_result.output, context
            )

            if not verification_result.passed and verification_result.issues:
                execution_result = await self._execute_phase(
                    plan_result.plan
                    + f"\n\n需要修复的问题:\n"
                    + "\n".join(f"- {issue}" for issue in verification_result.issues),
                    plan_result.structured_plan,
                    context,
                )

        total_cost = self._calculate_cost(plan_result, execution_result, verification_result)

        return HybridInferenceResult(
            plan=plan_result.plan,
            structured_plan=plan_result.structured_plan,
            execution_output=execution_result.output,
            verification=verification_result,
            total_thinking_tokens=plan_result.thinking_tokens,
            total_execution_tokens=execution_result.execution_tokens,
            total_cost=total_cost,
            total_latency_ms=int((time.time() - start_time) * 1000),
        )

    async def _plan_phase(self, task: str, context: dict = None) -> PlanResult:
        prompt = self.PLAN_PROMPT_TEMPLATE.format(task=task)

        response = await self.reasoning_model.chat(
            messages=[{"role": "user", "content": prompt}],
            max_thinking_tokens=10000,
            reasoning_effort="high",
        )

        structured_plan = self._extract_json(response.content)

        return PlanResult(
            plan=response.content,
            structured_plan=structured_plan or {},
            thinking_tokens=response.thinking_tokens,
            plan_tokens=response.output_tokens,
        )

    async def _execute_phase(
        self, plan: str, structured_plan: dict, context: dict = None
    ) -> ExecutionResult:
        prompt = self.EXECUTE_PROMPT_TEMPLATE.format(plan=plan)

        response = await self.standard_model.chat(
            messages=[{"role": "user", "content": prompt}],
            temperature=0.3,
            max_tokens=4096,
        )

        return ExecutionResult(
            output=response.content,
            execution_tokens=response.total_tokens,
        )

    async def _verify_phase(
        self, plan: str, execution: str, context: dict = None
    ) -> VerificationResult:
        prompt = self.VERIFY_PROMPT_TEMPLATE.format(plan=plan, execution=execution)

        response = await self.standard_model.chat(
            messages=[{"role": "user", "content": prompt}],
            temperature=0.1,
            max_tokens=1024,
        )

        result = self._extract_json(response.content) or {}
        return VerificationResult(
            passed=result.get("passed", False),
            issues=result.get("issues", []),
            verification_tokens=response.total_tokens,
        )

    def _extract_json(self, text: str) -> Optional[dict]:
        try:
            json_match = text
            if "```json" in text:
                json_match = text.split("```json")[1].split("```")[0]
            elif "```" in text:
                json_match = text.split("```")[1].split("```")[0]
            return json.loads(json_match.strip())
        except (json.JSONDecodeError, IndexError):
            return None

    def _calculate_cost(
        self,
        plan: PlanResult,
        execution: ExecutionResult,
        verification: Optional[VerificationResult],
    ) -> float:
        REASONING_COST_PER_K = 0.008
        STANDARD_COST_PER_K = 0.001

        reasoning_cost = plan.thinking_tokens * REASONING_COST_PER_K / 1000
        execution_cost = execution.execution_tokens * STANDARD_COST_PER_K / 1000
        verification_cost = (
            verification.verification_tokens * STANDARD_COST_PER_K / 1000
            if verification
            else 0
        )

        return round(reasoning_cost + execution_cost + verification_cost, 6)
```

### 5.3 混合推理场景矩阵

| 场景 | 规划（推理模型） | 执行（标准模型） | 成本节省 | 质量影响 |
|------|-----------------|-----------------|----------|----------|
| 代码开发 | 架构设计+技术选型 | 代码生成+注释 | 60-70% | 几乎无 |
| 文档写作 | 大纲+逻辑框架 | 内容填充+润色 | 55-65% | 轻微下降 |
| 数据分析 | 分析策略+统计方法 | SQL/代码生成+图表 | 50-60% | 几乎无 |
| 客服问答 | 复杂问题分析 | 标准回复生成 | 70-80% | 无 |
| 翻译 | 术语+语境分析 | 翻译执行 | 40-50% | 无 |
| 数学求解 | 解题思路+验证 | 步骤书写 | 30-40% | 需验证环节 |

### 5.4 成本优化策略

```
成本优化策略全景
│
├── 策略1: 模型分级
│   ├── 推理模型仅用于规划阶段

│   └── 成本降低: 50-70%

├── 策略2: 推理缓存
│   ├── 相似问题的推理规划缓存

│   └── 成本降低: 20-40%（缓存命中时）

│   ├── 推理模型输出精简规划（限制output tokens）
│   ├── 仅传递关键决策点给执行模型
│   └── 成本降低: 15-25%

├── 策略4: 渐进式推理
│   ├── 先用标准模型尝试
│   ├── 质量不满足再升级推理模型
│   └── 成本降低: 30-50%

    ├── 相似任务批量规划

**vLLM推理模型调用示例：**

```python
import openai
import asyncio


class ReasoningModelClient:
    """推理模型客户端"""

    def __init__(self, base_url: str = "http://deepseek-r1-vllm-svc:8000/v1"):
        self.client = openai.AsyncOpenAI(base_url=base_url)

    async def chat_with_reasoning(
        self,
        messages: list[dict],
        max_thinking_tokens: int = 10000,
        temperature: float = 0.6,
    ) -> dict:
        response = await self.client.chat.completions.create(
            model="deepseek-ai/DeepSeek-R1",
            messages=messages,
            max_tokens=max_thinking_tokens + 4096,
            temperature=temperature,
            stream=True,
            extra_body={
                "chat_template_kwargs": {
                    "enable_thinking": True,
                },
            },
        )

        thinking_content = ""
        answer_content = ""
        phase = "thinking"

        async for chunk in response:
            if not chunk.choices:
                continue

            delta = chunk.choices[0].delta

            if hasattr(delta, "reasoning_content") and delta.reasoning_content:
                thinking_content += delta.reasoning_content

            if delta.content:
                if phase == "thinking":
                    phase = "answer"
                answer_content += delta.content

        return {
            "thinking": thinking_content,
            "answer": answer_content,
            "thinking_tokens": len(thinking_content) // 4,
            "answer_tokens": len(answer_content) // 4,
        }

    async def chat_with_budget_control(
        self,
        messages: list[dict],
        max_thinking_tokens: int = 5000,
        budget_controller: "AdaptiveBudgetController" = None,
    ) -> dict:
        response = await self.client.chat.completions.create(
            model="deepseek-ai/DeepSeek-R1",
            messages=messages,
            max_tokens=max_thinking_tokens + 2048,
            temperature=0.6,
            stream=True,
            extra_body={
                "chat_template_kwargs": {
                    "enable_thinking": True,
                },
            },
        )

        thinking_content = ""
        answer_content = ""
        thinking_tokens = 0
        phase = "thinking"

        async for chunk in response:
            if not chunk.choices:
                continue

            delta = chunk.choices[0].delta

            if hasattr(delta, "reasoning_content") and delta.reasoning_content:
                thinking_tokens += 1
                thinking_content += delta.reasoning_content

                if budget_controller and thinking_tokens >= 100:
                    stop_decision = budget_controller.should_stop_thinking(
                        thinking_tokens_so_far=thinking_tokens,
                        min_thinking_tokens=max(100, max_thinking_tokens // 5),
                        confidence_scores=[],
                    )
                    if stop_decision["should_stop"]:
                        break

            if delta.content:
                phase = "answer"
                answer_content += delta.content

        return {
            "thinking": thinking_content,
            "answer": answer_content,
            "thinking_tokens": thinking_tokens,
            "answer_tokens": len(answer_content) // 4,
            "budget_used": thinking_tokens / max_thinking_tokens,
        }

import httpx
import json


class SGLangReasoningClient:
    """SGLang推理模型客户端"""

    def __init__(self, base_url: str = "http://qwq-32b-sglang-svc:8000"):
        self.base_url = base_url

    async def chat_with_thinking(
        self,
        messages: list[dict],
        max_new_tokens: int = 8192,
    ) -> dict:
        async with httpx.AsyncClient(timeout=300) as client:
            resp = await client.post(
                f"{self.base_url}/v1/chat/completions",
                json={
                    "model": "Qwen/QwQ-32B",
                    "messages": messages,
                    "max_tokens": max_new_tokens,
                    "stream": True,
                    "separate_reasoning": True,
                },
            )

            thinking_content = ""
            answer_content = ""

            async for line in resp.aiter_lines():
                if not line.startswith("data: "):
                    continue
                data_str = line[6:]
                if data_str.strip() == "[DONE]":
                    break

                try:
                    data = json.loads(data_str)
                except json.JSONDecodeError:
                    continue

                choice = data.get("choices", [{}])[0]
                delta = choice.get("delta", {})

                reasoning = delta.get("reasoning_content", "")
                if reasoning:
                    thinking_content += reasoning

                content = delta.get("content", "")
                if content:
                    answer_content += content

            return {
                "thinking": thinking_content,
                "answer": answer_content,
                "thinking_tokens": len(thinking_content) // 4,
                "answer_tokens": len(answer_content) // 4,
            }

**成本控制配置：**

```python
from dataclasses import dataclass, field
from typing import Optional
import time


@dataclass
class UserBudget:
    user_id: str
    daily_thinking_token_limit: int = 500_000
    daily_cost_limit: float = 10.0
    max_single_request_thinking_tokens: int = 30_000
    used_thinking_tokens: int = 0
    used_cost: float = 0.0
    last_reset_date: str = ""


@dataclass
class SystemBudget:
    total_daily_thinking_token_limit: int = 50_000_000
    total_daily_cost_limit: float = 5000.0
    max_concurrent_reasoning_requests: int = 32
    used_thinking_tokens: int = 0
    used_cost: float = 0.0
    active_reasoning_requests: int = 0


class CostController:
    """推理模型成本控制器"""

    def __init__(self):
        self.user_budgets: dict[str, UserBudget] = {}
        self.system_budget = SystemBudget()
        self.circuit_breaker_threshold = 0.9

    def check_and_reserve(
        self,
        user_id: str,
        estimated_thinking_tokens: int,
        estimated_cost: float,
    ) -> dict:
        self._maybe_reset_budgets()

        user_budget = self._get_or_create_user_budget(user_id)

        if self.system_budget.active_reasoning_requests >= self.system_budget.max_concurrent_reasoning_requests:
            return {
                "allowed": False,
                "reason": "system_concurrency_limit",
                "fallback": "standard_model",
            }

        system_cost_ratio = self.system_budget.used_cost / self.system_budget.total_daily_cost_limit
        if system_cost_ratio > self.circuit_breaker_threshold:
            return {
                "allowed": False,
                "reason": "system_budget_circuit_breaker",
                "fallback": "standard_model",
                "system_budget_used_percent": round(system_cost_ratio * 100, 1),
            }

        if user_budget.used_thinking_tokens + estimated_thinking_tokens > user_budget.daily_thinking_token_limit:
            return {
                "allowed": False,
                "reason": "user_token_limit_exceeded",
                "fallback": "standard_model",
                "user_tokens_remaining": user_budget.daily_thinking_token_limit - user_budget.used_thinking_tokens,
            }

        if user_budget.used_cost + estimated_cost > user_budget.daily_cost_limit:
            return {
                "allowed": False,
                "reason": "user_cost_limit_exceeded",
                "fallback": "standard_model",
                "user_cost_remaining": round(user_budget.daily_cost_limit - user_budget.used_cost, 4),
            }

        if estimated_thinking_tokens > user_budget.max_single_request_thinking_tokens:
            capped_tokens = user_budget.max_single_request_thinking_tokens
            return {
                "allowed": True,
                "capped_thinking_tokens": capped_tokens,
                "reason": "single_request_cap_applied",
                "original_tokens": estimated_thinking_tokens,
            }

        self.system_budget.active_reasoning_requests += 1
        return {"allowed": True, "capped_thinking_tokens": estimated_thinking_tokens}

    def record_usage(
        self,
        user_id: str,
        actual_thinking_tokens: int,
        actual_cost: float,
    ):
        user_budget = self._get_or_create_user_budget(user_id)
        user_budget.used_thinking_tokens += actual_thinking_tokens
        user_budget.used_cost += actual_cost

        self.system_budget.used_thinking_tokens += actual_thinking_tokens
        self.system_budget.used_cost += actual_cost
        self.system_budget.active_reasoning_requests = max(
            0, self.system_budget.active_reasoning_requests - 1
        )

    def _get_or_create_user_budget(self, user_id: str) -> UserBudget:
        if user_id not in self.user_budgets:
            self.user_budgets[user_id] = UserBudget(user_id=user_id)
        return self.user_budgets[user_id]

    def _maybe_reset_budgets(self):
        today = time.strftime("%Y-%m-%d")
        if self.system_budget.last_reset_date != today:
            self.system_budget.used_thinking_tokens = 0
            self.system_budget.used_cost = 0.0
            self.system_budget.last_reset_date = today
            for budget in self.user_budgets.values():
                budget.used_thinking_tokens = 0
                budget.used_cost = 0.0
                budget.last_reset_date = today
```

### 6.5 GPU资源规划

```python
from fastapi import FastAPI, HTTPException, Header, Request
from fastapi.responses import StreamingResponse
from pydantic import BaseModel, Field
from typing import Optional
import uuid


app = FastAPI(title="Reasoning Model Service API")


class ReasoningRequest(BaseModel):
    messages: list[dict]
    model: str = Field(default="auto", description="auto=智能路由, 或指定模型")
    stream: bool = Field(default=True)
    max_thinking_tokens: Optional[int] = Field(default=None, description="推理预算上限")
    reasoning_effort: Optional[str] = Field(default=None, description="low/medium/high")
    enable_thinking_display: bool = Field(default=True, description="是否返回thinking内容")
    metadata: Optional[dict] = None


class ReasoningResponse(BaseModel):
    id: str
    model: str
    thinking: Optional[str] = None
    answer: str
    thinking_tokens: int = 0
    answer_tokens: int = 0
    total_tokens: int = 0
    routing: dict
    cost: dict


@app.post("/api/v1/reasoning/chat/completions")
async def reasoning_chat(
    request: ReasoningRequest,
    x_api_key: str = Header(...),
):
    user_context = authenticate_and_get_context(x_api_key)

    router = ReasoningBudgetRouter()
    decision = router.route(
        query=request.messages[-1]["content"],
        context={
            "user_id": user_context["user_id"],
            "user_tier": user_context["tier"],
            **(request.metadata or {}),
        },
    )

    cost_controller = CostController()
    estimated_tokens = decision.max_thinking_tokens or 5000
    estimated_cost = estimated_tokens * 0.008 / 1000

    budget_check = cost_controller.check_and_reserve(
        user_id=user_context["user_id"],
        estimated_thinking_tokens=estimated_tokens,
        estimated_cost=estimated_cost,
    )

    if not budget_check["allowed"]:
        if request.stream:
            return StreamingResponse(
                fallback_to_standard_model(request, budget_check["reason"]),
                media_type="text/event-stream",
            )
        raise HTTPException(status_code=429, detail=budget_check)

    actual_max_thinking = budget_check.get("capped_thinking_tokens", estimated_tokens)

    if request.stream:
        return StreamingResponse(
            stream_reasoning_response(
                request, decision, actual_max_thinking, user_context
            ),
            media_type="text/event-stream",
        )
    else:
        result = await execute_reasoning_request(
            request, decision, actual_max_thinking
        )
        cost_controller.record_usage(
            user_context["user_id"],
            result.thinking_tokens,
            result.cost.get("total", 0),
        )
        return result


async def stream_reasoning_response(request, decision, max_thinking, user_context):
    request_id = str(uuid.uuid4())
    processor = DualPhaseStreamProcessor(max_thinking_tokens=max_thinking)

    if decision.reasoning_effort == "none":
        model_client = get_standard_model_client(decision.model)
        token_stream = model_client.stream_chat(
            messages=request.messages,
            max_tokens=4096,
        )
    else:
        model_client = get_reasoning_model_client(decision.model)
        token_stream = model_client.stream_chat_with_reasoning(
            messages=request.messages,
            max_thinking_tokens=max_thinking,
            reasoning_effort=decision.reasoning_effort,
        )

    async for sse_event in processor.process_stream(
        token_stream, request_id, decision.model
    ):
        if not request.enable_thinking_display and sse_event.startswith("event: thinking"):
            continue
        yield sse_event

    cost_controller = CostController()
    cost_controller.record_usage(
        user_context["user_id"],
        processor.state.thinking_tokens,
        processor._estimate_cost(),
    )
```

## 8. 性能优化

### 8.1 KV Cache优化

推理模型的thinking tokens产生巨大KV Cache，是显存优化的核心目标。

```
KV Cache优化策略
│
├── PagedAttention (vLLM默认)
│   ├── 虚拟内存管理，避免显存碎片
│   ├── 按页分配KV Cache
│   └── 显存利用率: 85-95%
│
├── KV Cache量化
│   ├── FP8量化: 显存减半，精度损失<1%
│   ├── INT4量化: 显存1/4，精度损失2-3%
│   └── 推荐FP8，兼顾精度与效率
│
├── Thinking阶段低精度
│   ├── Thinking tokens用FP8 KV Cache
│   ├── Answer tokens用FP16 KV Cache
│   └── 整体显存节省30-40%
│
├── 前缀缓存复用
│   ├── System Prompt KV Cache复用
│   ├── 相同前缀的请求共享KV Cache
│   └── RadixAttention (SGLang) 更高效
│
└── Thinking Token压缩
    ├── 低注意力token跳过存储
    ├── 保留关键推理步骤的KV Cache
    └── 显存节省15-25%，质量损失<2%
```

### 8.2 推理吞吐优化

```python
class ReasoningThroughputOptimizer:
    """推理吞吐优化器"""

    BATCH_STRATEGIES = {
        "thinking_heavy": {
            "max_batch_size": 4,
            "max_waiting_time_ms": 200,
            "description": "thinking阶段，batch小避免显存溢出",
        },
        "answer_phase": {
            "max_batch_size": 16,
            "max_waiting_time_ms": 50,
            "description": "answer阶段，可增大batch提升吞吐",
        },
        "mixed": {
            "max_batch_size": 8,
            "max_waiting_time_ms": 100,
            "description": "混合阶段，平衡延迟与吞吐",
        },
    }

    def get_optimal_batch_config(self, active_requests: list[dict]) -> dict:
        thinking_count = sum(1 for r in active_requests if r["phase"] == "thinking")
        answer_count = sum(1 for r in active_requests if r["phase"] == "answer")

        if thinking_count > answer_count * 2:
            return self.BATCH_STRATEGIES["thinking_heavy"]
        elif answer_count > thinking_count * 2:
            return self.BATCH_STRATEGIES["answer_phase"]
        else:
            return self.BATCH_STRATEGIES["mixed"]
```

## 9. 经验总结

### 9.1 关键成功因素

1. **路由是核心**：80%请求不需要推理模型，智能路由是成本控制的第一道防线
2. **流式输出是必须**：推理模型10-120s的延迟，没有流式输出用户无法接受
3. **thinking/answer分离**：分离输出让前端可以差异化渲染，也便于成本统计和质量评估
4. **混合推理是趋势**：推理模型规划+标准模型执行，成本降低50%同时保持质量
5. **成本控制要前置**：thinking tokens不可预测，必须在请求前做预算检查和熔断

### 9.2 踩过的坑

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 成本爆炸 | thinking tokens不可预测 | 多层成本控制+硬上限+熔断 |
| 黑屏等待 | thinking阶段无输出 | 双阶段SSE流式输出 |
| 显存OOM | thinking KV Cache过大 | FP8量化+PagedAttention+动态batch |
| 简单问题用推理模型 | 缺乏路由机制 | 问题复杂度分类+路由决策 |
| 蒸馏模型性能不达预期 | 蒸馏≠真正推理能力 | 关键任务用RL训练模型，蒸馏模型用于中等任务 |
| 推理模型"过度思考" | 简单问题产生冗长推理链 | 置信度早停+预算硬上限 |
| 并发时延迟飙升 | thinking阶段占用GPU时间长 | 请求优先级队列+推理/标准模型资源隔离 |
